Nonlinear Least Squares: How Fast Did Greece Go Online?

  • Show All Code
  • Hide All Code
  • View Source
Nonlinear least squares in R with nls(), on the World Bank’s share of people in Greece who use the internet (1990-2024): logistic and Gompertz growth curves, Gauss-Newton by hand, starting values and what happens when they are bad, self-starting models, profile against Wald confidence intervals, the delta method, AIC for curves that are not nested, a forecast test from 2008, a comparison of three countries and APA reporting.

The question: a curve with a meaning

In 1995 fewer than one in a hundred people in Greece used the internet. Today nearly nine in ten do. New things usually spread like this: slowly at first, when few people have them and others hardly hear of them; then fast; then slowly again, when only a few people are left. The curve looks like an S.

This page fits S-curves to the data, to answer three questions:

  1. What is the ceiling, the share at which the curve will stop?
  2. When was the growth fastest?
  3. How fast was it?

A polynomial could follow the points (see polynomial regression), but it has no ceiling, and its coefficients answer none of the three questions. An S-curve has exactly three parameters, and they are the three answers. The price is that the curve is nonlinear in its parameters, so the formulas of linear regression do not apply, and the computer must search. Nonlinear least squares is that search.

3. The model step by step, with formulas

Step 1: what “nonlinear” means

\[y_i = f(t_i; \theta) + \varepsilon_i\]

A model is linear when its parameters only multiply things that are known and are added up: \(\beta_0 + \beta_1 t + \beta_2 t^2\) is linear, although it is a curve in \(t\). It is nonlinear when a parameter sits inside a function, in a denominator or an exponent.

Step 2: the logistic curve

\[y = \frac{A}{1 + e^{-(t - m)/s}}\]

  • \(A\) is the ceiling (the asymptote), in % of the population;
  • \(m\) is the midpoint, the time at which the curve is at \(A/2\) and grows fastest;
  • \(s\) is the scale, how stretched the S is: in \(s\) years the curve goes from 50% to 73% of the ceiling. The growth at the midpoint is \(A/(4s)\) points per year.

The story behind it: the growth is proportional to those who have it already (they spread it) and to those who do not have it yet (Geroski, 2000).

Step 3: the Gompertz curve

\[y = A\, e^{-e^{-(t - m)/s}}\]

The same three parameters, but the S is not symmetric. The growth is fastest at \(t = m\), when the curve has reached only \(A/e\) = 37% of the ceiling, and it is \(A/(e\,s)\) points per year there. The rest of the way is slow: a long tail of late adopters. (Winsor, 1932, compares the two curves.)

shape <- data.frame(t = seq(-15, 30, by = 0.1))

Step 4: least squares again, but without a formula

We still want the parameters with the smallest sum of squared residuals,

\[S(\theta) = \sum_i \left[ y_i - f(t_i; \theta) \right]^2\]

In linear regression, setting the derivatives to zero gives equations that can be solved. Here the equations cannot be solved, so we walk downhill from a starting guess.

Step 5: the Gauss–Newton method

Near the current guess, replace the curve by its tangent, which is linear in the parameters (Bates & Watts, 1988). With \(J\) the table of derivatives of the curve (one row per year, one column per parameter) and \(e\) the current residuals, the best step is an ordinary regression of \(e\) on \(J\):

\[\theta_{\text{new}} = \theta_{\text{old}} + (J^\top J)^{-1} J^\top e\]

Repeat until the step is tiny. For the logistic curve, with \(p = 1/(1 + e^{-(t-m)/s})\), the derivatives are

\[\frac{\partial f}{\partial A} = p, \qquad \frac{\partial f}{\partial m} = -\frac{A}{s}\, p(1-p), \qquad \frac{\partial f}{\partial s} = -\frac{A}{s}\cdot\frac{t - m}{s}\, p(1-p)\]

Code 
t_ <- greece$t
y_ <- greece$share
theta <- c(A = 90, m = 8, s = 4)            # the starting guess, read off the chart
walk  <- NULL
for (iteration in 0:8) {
  p <- 1 / (1 + exp(-(t_ - theta["m"]) / theta["s"]))
  e <- y_ - theta["A"] * p
  walk <- rbind(walk, c(iteration = iteration, theta, RSS = sum(e^2)))
  k <- theta["A"] / theta["s"] * p * (1 - p)
  J <- cbind(A = p, m = -k, s = -k * (t_ - theta["m"]) / theta["s"])
  theta <- theta + drop(solve(crossprod(J), crossprod(J, e)))
}

Step 6: the standard errors

At the minimum, the same tangent gives approximate standard errors, as if the model were the linear one:

\[\widehat{\text{Var}}(\hat\theta) \approx \hat\sigma^2 (J^\top J)^{-1}, \qquad \hat\sigma^2 = \frac{S(\hat\theta)}{n - p}\]

They are only as good as the tangent. Section 5 has a better interval.

  • Number of iterations and convergence tolerance: how the search ended. Our own Gauss–Newton steps gave the same estimates.

Starting values

The search needs to start in the right area. Three ways to find it:

  1. Read them off the chart. The ceiling is a bit above the last points, the midpoint is where the curve is at half of it, the scale is the time from 50% to 73%.
  2. Use a self-starting model, which finds its own: SSlogis() and SSgompertz() come with R.
  3. Make the problem linear to get a rough first answer: for a fixed ceiling, the logit of \(y/A\) is a straight line in \(t\).
Code 
self <- nls(share ~ SSlogis(t, A, m, s), data = greece)    # no starting values
rbind(own_start = cL, self_start = coef(self))
                  A        m        s
own_start  85.79398 9.242912 4.482017
self_start 85.79400 9.242914 4.482021

singular gradient is the most common error of nls(). It means that, at the current guess, changing some parameter does not change the curve (or two parameters change it in the same way), so there is no direction to walk in. With a midpoint in 2050, for example, the curve is flat zero over all the data. The remedy is almost always a better starting value, sometimes fewer parameters. minpack.lm::nlsLM() is a more patient search.

5. Confidence intervals, and quantities made from the parameters

Wald or profile?

The quick interval is the estimate \(\pm\) 2 standard errors (Wald). It trusts the tangent of step 6, and it is symmetric. The profile interval does not: it fixes one parameter at a value, fits all the others again, and keeps the values for which the fit does not become significantly worse (with an F test). confint() does it for nls fits:

Code 
wald <- coef(gompertz) +
  outer(summary(gompertz)$coefficients[, 2], c(-1, 1) * qt(0.975, df.residual(gompertz)))
profile_ci <- confint(gompertz)
cbind(estimate = cG, wald_low = wald[, 1], wald_high = wald[, 2],
      profile_low = profile_ci[, 1], profile_high = profile_ci[, 2])
   estimate  wald_low  wald_high profile_low profile_high
A 97.440435 94.453526 100.427344   94.601769   100.596375
m  7.372518  7.026204   7.718833    7.039667     7.737578
s  8.256362  7.787733   8.724991    7.806563     8.740581

Here they nearly agree, because the data cover the whole curve. When they do not agree, the profile is the one to trust. The next section shows such a case.

The year when half of the people were online

This is not a parameter, but it can be computed from them. Setting the Gompertz curve to 50 and solving for \(t\):

\[t_{50} = m - s \log\!\big({-\log(50/A)}\big)\]

Its standard error comes from the delta method: the derivatives of the formula with respect to the parameters, and the covariance matrix of the estimates \(V\), give \(\sqrt{g^\top V g}\).

Code 
t50   <- function(th) th[["m"]] - th[["s"]] * log(-log(50 / th[["A"]]))
slope <- function(th) th[["A"]] / (exp(1) * th[["s"]])          # the growth at the fastest moment
delta_se <- function(fun, fit, h = 1e-5) {
  th <- coef(fit)
  g  <- sapply(names(th), function(p) { up <- th; up[p] <- up[p] + h; (fun(up) - fun(th)) / h })
  sqrt(drop(t(g) %*% vcov(fit) %*% g))
}
derived <- rbind(t50        = c(estimate = t50(cG),   SE = delta_se(t50, gompertz)),
                 max_growth = c(estimate = slope(cG), SE = delta_se(slope, gompertz)))
derived <- cbind(
  derived,
  lower = derived[, 1] - 2 * derived[, 2],
  upper = derived[, 1] + 2 * derived[, 2]
)
derived
            estimate         SE     lower    upper
t50        10.713357 0.08768262 10.537992 10.88872
max_growth  4.341662 0.06687416  4.207914  4.47541

Half of the population was online 10.7 years after the start of 2000, that is around 2011. The growth was fastest around 2007, 4.3 points a year, 95% CI [4.2, 4.5].

The logistic curve, fitted to 2008, announced a ceiling of 50.5%, with a 95% confidence interval from 44.0 to 61.4. In 2024 the share was 86.3%. The Gompertz said 89.1%, and predicted the next 16 years with an error of 2.8 points, against 22.1.

Two lessons. First, the confidence interval is conditional on the curve. The interval of the logistic ceiling was honest about the noise and said nothing about being the wrong curve. Second, the ceiling is the hardest thing to estimate from an S-curve that has not yet bent: until 2008 the two curves fitted almost equally well (residual standard errors 1.0 and 0.9), and differed by 38.6 points about the future. The Gompertz was the better guess here. Nobody could have proved it in 2008. Forecasts of technology from early data are known to be this fragile (Meade & Islam, 2006).

8. Things to keep in mind

  • Choose the curve from what you know, not from a catalogue. Ceiling or no ceiling? Symmetric? Does it start at zero? A different curve is a different claim about the future.
  • Do not linearise by taking logs just to use lm(). A log changes the errors: it makes the relative errors equal, and it lets the years with 0.1% count as much as the years with 80%. Use it for starting values.
  • Local minima. The search stops at the bottom of a valley, which may not be the deepest. Start from several places, and look at the fitted curve.
  • The errors. Here they cannot be equally large everywhere: near 0 and near 100 there is no room for them. Residuals close to 0 in the first years, as in the chart of section 4, are the sign. Weights, or a model for proportions (a logistic GLM with a ceiling), would be the next step.
  • Time series. Years that follow each other are not independent. The standard errors assume they are. nlme::gnls() allows autocorrelated errors (compare generalized least squares).
  • Too many parameters. Each one needs data in the part of the curve that it describes. A ceiling needs points near the ceiling.
  • The measure changed from estimates to surveys, and the question of who counts as a user changed with it.

## The question: a curve with a meaning

In 1995 fewer than one in a hundred people in Greece used the internet. Today nearly nine in ten do. New things usually spread like this: slowly at first, when few people have them and others hardly hear of them; then fast; then slowly again, when only a few people are left. The curve looks like an **S**.

This page fits S-curves to the data, to answer three questions:

1. What is the **ceiling**, the share at which the curve will stop?
2. **When** was the growth fastest?
3. **How fast** was it?

A polynomial could follow the points (see [polynomial regression](EXAMPLE_POLYNOMIAL_REGRESSION.Rmd)), but it has no ceiling, and its coefficients answer none of the three questions. An S-curve has exactly three parameters, and they **are** the three answers. The price is that the curve is **nonlinear in its parameters**, so the formulas of linear regression do not apply, and the computer must search. **Nonlinear least squares** is that search.

## 3. The model step by step, with formulas

### Step 1: what "nonlinear" means

$$y_i = f(t_i; \theta) + \varepsilon_i$$

A model is **linear** when its parameters only multiply things that are known and are added up: $\beta_0 + \beta_1 t + \beta_2 t^2$ is linear, although it is a curve in $t$. It is **nonlinear** when a parameter sits inside a function, in a denominator or an exponent.

### Step 2: the logistic curve

$$y = \frac{A}{1 + e^{-(t - m)/s}}$$

- $A$ is the **ceiling** (the asymptote), in % of the population;
- $m$ is the **midpoint**, the time at which the curve is at $A/2$ and grows fastest;
- $s$ is the **scale**, how stretched the S is: in $s$ years the curve goes from 50% to 73% of the ceiling. The growth at the midpoint is $A/(4s)$ points per year.

The story behind it: the growth is proportional to those who have it already (they spread it) and to those who do not have it yet (Geroski, 2000).

### Step 3: the Gompertz curve

$$y = A\, e^{-e^{-(t - m)/s}}$$

The same three parameters, but the S is **not symmetric**. The growth is fastest at $t = m$, when the curve has reached only $A/e$ = 37% of the ceiling, and it is $A/(e\,s)$ points per year there. The rest of the way is slow: a long tail of late adopters. (Winsor, 1932, compares the two curves.)

### Step 4: least squares again, but without a formula

We still want the parameters with the smallest sum of squared residuals,

$$S(\theta) = \sum_i \left[ y_i - f(t_i; \theta) \right]^2$$

In linear regression, setting the derivatives to zero gives equations that can be solved. Here the equations cannot be solved, so we walk downhill from a starting guess.

### Step 5: the Gauss–Newton method

Near the current guess, replace the curve by its tangent, which is **linear** in the parameters (Bates & Watts, 1988). With $J$ the table of derivatives of the curve (one row per year, one column per parameter) and $e$ the current residuals, the best step is an ordinary regression of $e$ on $J$:

$$\theta_{\text{new}} = \theta_{\text{old}} + (J^\top J)^{-1} J^\top e$$

Repeat until the step is tiny. For the logistic curve, with $p = 1/(1 + e^{-(t-m)/s})$, the derivatives are

$$\frac{\partial f}{\partial A} = p, \qquad \frac{\partial f}{\partial m} = -\frac{A}{s}\, p(1-p), \qquad \frac{\partial f}{\partial s} = -\frac{A}{s}\cdot\frac{t - m}{s}\, p(1-p)$$

```{r gauss_newton}
t_ <- greece$t
y_ <- greece$share
theta <- c(A = 90, m = 8, s = 4)            # the starting guess, read off the chart
walk  <- NULL
for (iteration in 0:8) {
  p <- 1 / (1 + exp(-(t_ - theta["m"]) / theta["s"]))
  e <- y_ - theta["A"] * p
  walk <- rbind(walk, c(iteration = iteration, theta, RSS = sum(e^2)))
  k <- theta["A"] / theta["s"] * p * (1 - p)
  J <- cbind(A = p, m = -k, s = -k * (t_ - theta["m"]) / theta["s"])
  theta <- theta + drop(solve(crossprod(J), crossprod(J, e)))
}
round(walk, 4)
```

A handful of steps is enough. The sum of squares falls from `r num(round(walk[1, "RSS"], 1))` to `r num(round(walk[nrow(walk), "RSS"], 1))`.

### Step 6: the standard errors

At the minimum, the same tangent gives approximate standard errors, as if the model were the linear one:

$$\widehat{\text{Var}}(\hat\theta) \approx \hat\sigma^2 (J^\top J)^{-1}, \qquad \hat\sigma^2 = \frac{S(\hat\theta)}{n - p}$$

They are only as good as the tangent. Section 5 has a better interval.

## 4. Fitting the models and reading the output

### The logistic curve

`nls()` takes the formula of the curve and a list of starting values:

```{r logistic}
logistic <- nls(share ~ A / (1 + exp(-(t - m) / s)), data = greece,
                start = list(A = 90, m = 8, s = 4))
summary(logistic)
cL <- coef(logistic)
```

- **`A`** = `r f1(cL[["A"]])`: the curve stops at `r f1(cL[["A"]])`% of the population. But in `r max(greece$year)` the share was `r f1(tail(greece$share, 1))`%, **above** the ceiling, and still rising. Something is wrong with this curve.
- **`m`** = `r f2(cL[["m"]])`: the midpoint is about `r round(2000 + cL[["m"]])`.
- **`s`** = `r f2(cL[["s"]])`: at the midpoint the share grew by $A/(4s)$ = `r f1(cL[["A"]] / (4 * cL[["s"]]))` points a year.
- **`Residual standard error`**: the curve misses the points by about `r f1(sigma(logistic))` percentage points. There is no $R^2$: in nonlinear models it does not split the variation into two parts, it can mislead, and R does not print it (Spiess & Neumeyer, 2010).
- **`Number of iterations`** and **`convergence tolerance`**: how the search ended. Our own Gauss–Newton steps gave the same estimates.

### Starting values

The search needs to start in the right area. Three ways to find it:

1. **Read them off the chart.** The ceiling is a bit above the last points, the midpoint is where the curve is at half of it, the scale is the time from 50% to 73%.
2. **Use a self-starting model**, which finds its own: `SSlogis()` and `SSgompertz()` come with R.
3. **Make the problem linear** to get a rough first answer: for a fixed ceiling, the logit of $y/A$ is a straight line in $t$.

```{r self_start}

rbind(own_start = cL, self_start = coef(self))
```

## 5. Confidence intervals, and quantities made from the parameters

### Wald or profile?

The quick interval is the estimate $\pm$ 2 standard errors (Wald). It trusts the tangent of step 6, and it is symmetric. The **profile** interval does not: it fixes one parameter at a value, fits all the others again, and keeps the values for which the fit does not become significantly worse (with an *F* test). `confint()` does it for `nls` fits:

```{r intervals}
wald <- coef(gompertz) +
  outer(summary(gompertz)$coefficients[, 2], c(-1, 1) * qt(0.975, df.residual(gompertz)))
profile_ci <- confint(gompertz)
cbind(estimate = cG, wald_low = wald[, 1], wald_high = wald[, 2],
      profile_low = profile_ci[, 1], profile_high = profile_ci[, 2])
```

Here they nearly agree, because the data cover the whole curve. When they do not agree, the profile is the one to trust. The next section shows such a case.

### The year when half of the people were online

This is not a parameter, but it can be computed from them. Setting the Gompertz curve to 50 and solving for $t$:

$$t_{50} = m - s \log\!\big({-\log(50/A)}\big)$$

Its standard error comes from the **delta method**: the derivatives of the formula with respect to the parameters, and the covariance matrix of the estimates $V$, give $\sqrt{g^\top V g}$.

```{r delta}
t50   <- function(th) th[["m"]] - th[["s"]] * log(-log(50 / th[["A"]]))
slope <- function(th) th[["A"]] / (exp(1) * th[["s"]])          # the growth at the fastest moment
delta_se <- function(fun, fit, h = 1e-5) {
  th <- coef(fit)
  g  <- sapply(names(th), function(p) { up <- th; up[p] <- up[p] + h; (fun(up) - fun(th)) / h })
  sqrt(drop(t(g) %*% vcov(fit) %*% g))
}
derived <- rbind(t50        = c(estimate = t50(cG),   SE = delta_se(t50, gompertz)),
                 max_growth = c(estimate = slope(cG), SE = delta_se(slope, gompertz)))
derived <- cbind(
  derived,
  lower = derived[, 1] - 2 * derived[, 2],
  upper = derived[, 1] + 2 * derived[, 2]
)
derived
```

Half of the population was online `r f1(derived["t50", "estimate"])` years after the start of 2000, that is around `r round(2000 + derived["t50", "estimate"])`. The growth was fastest around `r round(2000 + cG[["m"]])`, `r f1(derived["max_growth", "estimate"])` points a year, 95% CI [`r f1(derived["max_growth", "lower"])`, `r f1(derived["max_growth", "upper"])`].

### The parameters are not independent

```{r parameter_correlation}
cov2cor(vcov(gompertz))
```

A higher ceiling can be traded for a later midpoint and a slower curve, with almost the same fit: the correlation of `A` with the other two is `r f2(cov2cor(vcov(gompertz))["A", "m"])` and `r f2(cov2cor(vcov(gompertz))["A", "s"])`. Near 1 in absolute value, the data cannot separate them, and the search fails.

## 6. The test: could we have known in 2008?

In 2008 the share was `r f1(greece$share[greece$year == 2008])`%. Fit both curves to the years until then, and let them say what comes next:

```{r forecast}
past   <- subset(greece, year <= 2008)
future <- subset(greece, year > 2008)
past_logistic <- nls(
  share ~ A / (1 + exp(-(t - m) / s)),
  data = past,
  start = list(A = 60, m = 5, s = 3)
)
past_gompertz <- nls(
  share ~ A * exp(-exp(-(t - m) / s)),
  data = past,
  start = list(A = 90, m = 7, s = 7)
)
early <- rbind(Logistic = coef(past_logistic), Gompertz = coef(past_gompertz))
early

rmse <- c(Logistic = sqrt(mean((future$share - predict(past_logistic, future))^2)),
          Gompertz = sqrt(mean((future$share - predict(past_gompertz, future))^2)))
rmse

ceiling_ci <- rbind(Logistic = confint(past_logistic)["A", ],      # profile intervals
                    Gompertz = confint(past_gompertz)["A", ])
ceiling_ci
```

The logistic curve, fitted to 2008, announced a ceiling of `r f1(early["Logistic", "A"])`%, with a 95% confidence interval from `r f1(ceiling_ci["Logistic", 1])` to `r f1(ceiling_ci["Logistic", 2])`. In `r max(greece$year)` the share was `r f1(tail(greece$share, 1))`%. The Gompertz said `r f1(early["Gompertz", "A"])`%, and predicted the next `r nrow(future)` years with an error of `r f1(rmse[["Gompertz"]])` points, against `r f1(rmse[["Logistic"]])`.

Two lessons. First, **the confidence interval is conditional on the curve**. The interval of the logistic ceiling was honest about the noise and said nothing about being the wrong curve. Second, the ceiling is the hardest thing to estimate from an S-curve that has not yet bent: until 2008 the two curves fitted almost equally well (residual standard errors `r f1(sigma(past_logistic))` and `r f1(sigma(past_gompertz))`), and differed by `r f1(abs(diff(early[, "A"])))` points about the future. The Gompertz was the better guess here. Nobody could have proved it in 2008. Forecasts of technology from early data are known to be this fragile (Meade & Islam, 2006).

This is also the case where the two kinds of interval disagree:

```{r gompertz_interval}
est_A  <- early["Gompertz", "A"]
se_A   <- summary(past_gompertz)$coefficients["A", "Std. Error"]
wald_A <- est_A + c(-1, 1) * qt(0.975, df.residual(past_gompertz)) * se_A
c(estimate = est_A, SE = se_A, wald_low = wald_A[1], wald_high = wald_A[2],
  profile_low = ceiling_ci["Gompertz", 1], profile_high = ceiling_ci["Gompertz", 2])
```

By the Wald interval, the Gompertz ceiling of 2008 was between `r f1(wald_A[1])` and `r f1(wald_A[2])`; by the profile, between `r f1(ceiling_ci["Gompertz", 1])` and `r f1(ceiling_ci["Gompertz", 2])`. The profile is **not symmetric**: the data could rule out a low ceiling, but not a high one. A ceiling above 100% is impossible, and the model does not know it. If a limit is known, fix it ($A = 100$), or use a curve that contains it.

## 8. Things to keep in mind

- **Choose the curve from what you know**, not from a catalogue. Ceiling or no ceiling? Symmetric? Does it start at zero? A different curve is a different claim about the future.
- **Do not linearise by taking logs just to use `lm()`.** A log changes the errors: it makes the relative errors equal, and it lets the years with 0.1% count as much as the years with 80%. Use it for starting values.
- **Local minima.** The search stops at the bottom of a valley, which may not be the deepest. Start from several places, and look at the fitted curve.
- **The errors.** Here they cannot be equally large everywhere: near 0 and near 100 there is no room for them. Residuals close to 0 in the first years, as in the chart of section 4, are the sign. Weights, or a model for proportions (a logistic GLM with a ceiling), would be the next step.
- **Time series.** Years that follow each other are not independent. The standard errors assume they are. `nlme::gnls()` allows autocorrelated errors (compare [generalized least squares](EXAMPLE_GENERALIZED_LEAST_SQUARES.Rmd)).
- **Too many parameters.** Each one needs data in the part of the curve that it describes. A ceiling needs points near the ceiling.
- **The measure changed** from estimates to surveys, and the question of who counts as a user changed with it.

## 10. Summary

| | |
|---|---|
| **When** | Theory gives a curve whose parameters mean something: growth, decay, saturation, dose and response |
| **Nonlinear** | A parameter sits inside a function; polynomials are linear |
| **How (R)** | `nls(y ~ A / (1 + exp(-(t - m)/s)), data, start = list(...))`, or self-starting: `nls(y ~ SSlogis(t, A, m, s), data)` |
| **The search** | Gauss–Newton: regress the residuals on the derivatives, step, repeat |
| **If it fails** | `singular gradient`: better starting values, fewer parameters, `minpack.lm::nlsLM()` |
| **Intervals** | `confint()` gives profile intervals; the delta method for quantities made from parameters |
| **Comparing curves** | Nested: `anova()`. Not nested: AIC, residual plots, forecasts |
| **Danger** | Extrapolation: the curve decides, not the data |
| **Related pages** | [Polynomial regression](EXAMPLE_POLYNOMIAL_REGRESSION.Rmd), [generalized least squares](EXAMPLE_GENERALIZED_LEAST_SQUARES.Rmd) |
