Bayesian Regression: Does the Economy Decide American Elections?

  • Show All Code
  • Hide All Code

Bayesian linear regression in R on 16 presidential elections: prior, likelihood and posterior on a grid, the closed-form posterior by hand, a Metropolis sampler by hand, the same answer from rstanarm, R-hat by hand, what the posterior lets you say and what it does not, forecasts with all the uncertainty, posterior predictive checks, leave-one-out by hand and with loo, errors with fat tails by changing the likelihood, how much the prior matters with sixteen rows, why Bayes factors depend on it even more, what calibrated means, and APA reporting.

The question: sixteen elections

When the economy grows, the party in the White House is said to win the next election. Douglas Hibbs (2000) made a model of it, “bread and peace”: the growth of personal income during the term predicts the vote. How strong is the connection, and what does it say about an election in which growth is 2%?

There is a difficulty: there have been few elections. With 16 rows an ordinary regression gives a line and a wide interval, and nothing else. A Bayesian regression does two things more.

  • It starts with a prior: a distribution that says what we consider possible before we see the data. (A growth of 1% does not move the vote by 40 points.) The data then change the prior into the posterior.
  • Its answers are probabilities of the things we want to know: the probability that the slope is above 2, or that the party keeps the White House. An ordinary confidence interval does not say that, although everybody reads it that way.

The price is that one has to state the prior, and to say what happens with another. This page writes everything by hand, and gets the same numbers from the package rstanarm.

3. The model step by step, with formulas

Step 1: Bayes’ rule

\[\underbrace{p(\theta \mid y)}_{\text{posterior}} \;\propto\; \underbrace{p(y \mid \theta)}_{\text{likelihood}} \times \underbrace{p(\theta)}_{\text{prior}}, \qquad y_i \sim N(\alpha + \beta\,(x_i - \bar x),\ \sigma^2)\]

The likelihood says how well values of the parameters explain the data. Multiplied with the prior, it gives the probability of the values after seeing the data. The sign \(\propto\) means “up to a constant that makes the total 1”.

Step 2: one parameter on a grid

To see how it works, pretend that \(\alpha\) and \(\sigma\) are known (the values of least squares), so that only the slope \(\beta\) is unknown. Take a prior that is sceptical: a normal distribution around 0 with SD 1. Compute the three curves at many values of \(\beta\):

The posterior lies between the prior and the data. For normal distributions its mean is the mean of the two, weighted with their precision (1/variance):

\[E(\beta \mid y) = \frac{\text{prec}_{\text{prior}} \cdot \text{prior mean} + \text{prec}_{\text{data}} \cdot \hat\beta}{\text{prec}_{\text{prior}} + \text{prec}_{\text{data}}}\]

The data weigh 2.1 here, the prior 1. So this prior counts as much as 7.8 further elections would, next to the 16 that we have.

Step 3: the whole model in closed form

For the linear model there is a prior with which everything can be computed with a formula: the normal–inverse-gamma prior, \(\beta \mid \sigma^2 \sim N(m_0, \sigma^2 V_0)\), \(\sigma^2 \sim IG(a_0, b_0)\). The posterior is of the same kind, with

\[V_n = (V_0^{-1} + X^\top X)^{-1}, \qquad m_n = V_n(V_0^{-1}m_0 + X^\top y),\]

\[a_n = a_0 + \tfrac n2, \qquad b_n = b_0 + \tfrac12\left(y^\top y + m_0^\top V_0^{-1}m_0 - m_n^\top V_n^{-1}m_n\right)\]

and each coefficient has a t distribution with \(2a_n\) degrees of freedom. With \(V_0^{-1} \to 0\), \(a_0 = -p/2\) and \(b_0 = 0\) (a flat prior) one gets the numbers of least squares:

Code 
nig <- function(X, y, m0, V0inv, a0, b0) {
  Vn <- solve(V0inv + crossprod(X))
  mn <- drop(Vn %*% (V0inv %*% m0 + crossprod(X, y)))
  an <- a0 + length(y) / 2
  bn <- b0 + (sum(y^2) + drop(t(m0) %*% V0inv %*% m0) - drop(t(mn) %*% solve(Vn, mn))) / 2
  data.frame(
    mean = mn,
    low = mn - qt(0.975, 2 * an) * sqrt(bn / an * diag(Vn)),
    high = mn + qt(0.975, 2 * an) * sqrt(bn / an * diag(Vn))
  )
}

Step 4: sampling

For most models there is no formula. Then one draws from the posterior. The oldest method (Metropolis et al., 1953) is a walk: propose a small random step; if the posterior is higher there, go; if it is lower, go with a probability equal to the ratio. The places visited are draws from the posterior, after a while. The constant in Bayes’ rule cancels in the ratio, so nobody needs to know it.

The priors (for the centred predictor):

  • \(\alpha \sim N(50, 5)\): with average growth the incumbent party gets about half of the votes, very probably between 40 and 60.
  • \(\beta \sim N(0, 5)\): 1% of growth changes the vote by less than 10 points, in an unknown direction. That is a weak statement, which is only to keep out absurd values.
  • \(\sigma \sim \text{Exponential}(1/5)\): elections deviate from the line by a few points, 5 on average.
Code 
log_posterior <- function(th, yy = y, xx = xc, prior_b = c(0, 5), t_errors = FALSE) {
  # th = (alpha, beta, log sigma)
  s <- exp(th[3])
  mu <- th[1] + th[2] * xx
  loglik <- if (t_errors) {
    sum(dt((yy - mu) / s, 4, log = TRUE) - log(s))
  } else {
    sum(dnorm(yy, mu, s, log = TRUE))
  }
  loglik +
    dnorm(th[1], 50, 5, log = TRUE) +
    dnorm(th[2], prior_b[1], prior_b[2], log = TRUE) +
    dexp(s, 1 / 5, log = TRUE) +
    th[3] # + th[3]: because we walk on log sigma
}
metropolis <- function(draws, start, step, logp, ...) {
  out <- matrix(0, draws, 3, dimnames = list(NULL, c("alpha", "beta", "sigma")))
  now <- start
  lp <- logp(now, ...)
  for (i in seq_len(draws)) {
    candidate <- now + step * rnorm(3)
    lp_new <- logp(candidate, ...)
    if (log(runif(1)) < lp_new - lp) {
      now <- candidate
      lp <- lp_new
    }
    out[i, ] <- now
  }
  out[, 3] <- exp(out[, 3])
  out
}

Did the chains arrive?

The check is the R-hat of Gelman and Rubin: the variance of all draws together, against the variance within each chain. If the chains are in different places the first is larger. By hand, with every chain cut in two halves, so that a drift within a chain also shows:

\[\hat R = \sqrt{\frac{\frac{m-1}{m}W + \frac 1m B}{W}}\]

(\(m\): length of a half; \(W\): mean of the variances within the halves; \(B\): \(m\) times the variance of the means of the halves. Values above 1.01 are suspicious; Vehtari et al., 2021, recommend a version based on ranks.)

Code 
halves <- function(cs) {
  do.call(
    cbind,
    lapply(cs, function(v) {
      m <- length(v) / 2
      cbind(v[1:m], v[(m + 1):(2 * m)])
    })
  )
}
rhat_hand <- function(cs) {
  h <- halves(cs)
  m <- nrow(h)
  W <- mean(apply(h, 2, var))
  B <- m * var(colMeans(h))
  sqrt(((m - 1) / m * W + B / m) / W)
}
get <- function(p) lapply(chains, function(m) m[-(1:warm), p])

A forecast

In 2016 income was growing by about 2% (Gelman et al., 2020). The forecast for a new election uses all the uncertainty: for every draw of the parameters, draw a new vote.

\[p(y^* \mid y) = \int p(y^* \mid \theta)\, p(\theta \mid y)\, d\theta\]

Bayes factors depend on it even more

A Bayes factor compares two hypotheses, here “the slope is 0” with “the slope is something, distributed like the prior”. It asks how well each predicted the data, so a very wide prior (a slope of 80 is possible) predicts badly. With flat priors for \(\alpha\) and \(\log\sigma\), the likelihood of the slope alone has a formula, \(L(\beta) \propto \left(S + S_{xx}(\beta - \hat\beta)^2\right)^{-(n-1)/2}\), and one integral does the rest:

7. What “calibrated” means

A credible interval is right on average over the prior: if the true values really came from the prior, 95% of the 95% intervals contain them. It is not right for every single true value. We can check both, with the formula of step 3 (here with a narrow prior for the slope, \(\beta \mid \sigma^2 \sim N(0, (\sigma/2)^2)\) and \(\sigma^2 \sim IG(5, 60)\)):

8. Things to keep in mind

  • Write down the prior before you look, in units that a reader understands. Simulate from it (a prior predictive check) and see if it expects absurd data.
  • Centre the predictors: then the prior of the intercept is about the outcome at average values.
  • Report what the result looks like with other priors, at least a wider and a narrower one.
  • Check R-hat and the effective draws for every parameter, and look at the trace plots. rstanarm gives warnings about divergent transitions: do not ignore them.
  • The posterior is conditional on the model. Check it as you would any regression: simulated data, residuals, leave-one-out.
  • Probabilities of hypotheses (“99% that the slope is positive”) need the prior. Do not present them as a p value.
  • With many rows the prior hardly matters. With few, it does, and that is exactly when it helps.
  • Multilevel models are where Bayesian methods shine, because they estimate variances of small groups without trouble: stan_glmer() or brms::brm(). See multilevel models.
  • Relatives: the normal prior is ridge regression as a probability, and a prior on functions is a Gaussian process.

Method (data analysis):

The vote share of the party holding the White House in the 16 presidential elections from 1952 to 2012 was regressed on the growth of real personal income per head during the term (Gelman et al., 2020; Hibbs, 2000), centred at its mean, with a Bayesian linear model with normal errors. The priors were N(50, 5) for the vote share at average growth, N(0, 5) for the slope (points per 1% of growth), and Exponential(1/5) for the residual standard deviation. The posterior was sampled with Hamiltonian Monte Carlo (R package rstanarm; four chains of 10,000 iterations, half of them warm-up); convergence was judged with R-hat and the effective number of draws. We report posterior means, standard deviations and 95% credible intervals, the model was checked with posterior predictive simulations and leave-one-out cross-validation (Vehtari et al., 2017), and the sensitivity to the prior of the slope was examined with six priors and with t-distributed errors. Analyses were conducted in R (Version 4.6.2; R Core Team, 2026).

All chains converged (R-hat ≤ 1.000; at least 16,100 effective draws for the slope). ## The question: sixteen elections

When the economy grows, the party in the White House is said to win the next election. Douglas Hibbs (2000) made a model of it, "bread and peace": the growth of personal income during the term predicts the vote. How strong is the connection, and what does it say about an election in which growth is 2%?

There is a difficulty: there have been **few** elections. With 16 rows an ordinary regression gives a line and a wide interval, and nothing else. A **Bayesian** regression does two things more.

- It starts with a **prior**: a distribution that says what we consider possible before we see the data. (A growth of 1% does not move the vote by 40 points.) The data then change the prior into the **posterior**.
- Its answers are probabilities of the things we want to know: the probability that the slope is above 2, or that the party keeps the White House. An ordinary confidence interval does not say that, although everybody reads it that way.

The price is that one has to state the prior, and to say what happens with another. This page writes everything by hand, and gets the same numbers from the package *rstanarm*.

## 3. The model step by step, with formulas

### Step 1: Bayes' rule

$$\underbrace{p(\theta \mid y)}_{\text{posterior}} \;\propto\; \underbrace{p(y \mid \theta)}_{\text{likelihood}} \times \underbrace{p(\theta)}_{\text{prior}}, \qquad y_i \sim N(\alpha + \beta\,(x_i - \bar x),\ \sigma^2)$$

The likelihood says how well values of the parameters explain the data. Multiplied with the prior, it gives the probability of the values after seeing the data. The sign $\propto$ means "up to a constant that makes the total 1".

### Step 2: one parameter on a grid

To see how it works, pretend that $\alpha$ and $\sigma$ are known (the values of least squares), so that only the slope $\beta$ is unknown. Take a prior that is sceptical: a normal distribution around 0 with SD 1. Compute the three curves at many values of $\beta$:


The posterior lies between the prior and the data. For normal distributions its mean is the mean of the two, weighted with their **precision** (1/variance):

$$E(\beta \mid y) = \frac{\text{prec}_{\text{prior}} \cdot \text{prior mean} + \text{prec}_{\text{data}} \cdot \hat\beta}{\text{prec}_{\text{prior}} + \text{prec}_{\text{data}}}$$

The data weigh `r f1(prec[["data"]])` here, the prior 1. So this prior counts as much as `r f1(prec[["prior"]] / prec[["data"]] * n)` further elections would, next to the `r n` that we have.

### Step 3: the whole model in closed form

For the linear model there is a prior with which everything can be computed with a formula: the **normal–inverse-gamma** prior, $\beta \mid \sigma^2 \sim N(m_0, \sigma^2 V_0)$, $\sigma^2 \sim IG(a_0, b_0)$. The posterior is of the same kind, with

$$V_n = (V_0^{-1} + X^\top X)^{-1}, \qquad m_n = V_n(V_0^{-1}m_0 + X^\top y),$$

$$a_n = a_0 + \tfrac n2, \qquad b_n = b_0 + \tfrac12\left(y^\top y + m_0^\top V_0^{-1}m_0 - m_n^\top V_n^{-1}m_n\right)$$

and each coefficient has a *t* distribution with $2a_n$ degrees of freedom. With $V_0^{-1} \to 0$, $a_0 = -p/2$ and $b_0 = 0$ (a *flat* prior) one gets the numbers of least squares:

```{r closed_form}
nig <- function(X, y, m0, V0inv, a0, b0) {
  Vn <- solve(V0inv + crossprod(X))
  mn <- drop(Vn %*% (V0inv %*% m0 + crossprod(X, y)))
  an <- a0 + length(y) / 2
  bn <- b0 + (sum(y^2) + drop(t(m0) %*% V0inv %*% m0) - drop(t(mn) %*% solve(Vn, mn))) / 2
  data.frame(
    mean = mn,
    low = mn - qt(0.975, 2 * an) * sqrt(bn / an * diag(Vn)),
    high = mn + qt(0.975, 2 * an) * sqrt(bn / an * diag(Vn))
  )
}
X <- cbind(`(Intercept)` = 1, growth = xc)
rbind(
  flat_prior_by_hand = nig(X, y, c(0, 0), diag(0, 2), -1, 0)["growth", ],
  least_squares = c(coef(ls_fit)["growth"], confint(ls_fit)["growth", ])
)
```

With a flat prior the 95% **credible** interval is the 95% confidence interval. The numbers are the same, and what one may say about them is different.

### Step 4: sampling

For most models there is no formula. Then one **draws** from the posterior. The oldest method (Metropolis et al., 1953) is a walk: propose a small random step; if the posterior is higher there, go; if it is lower, go with a probability equal to the ratio. The places visited are draws from the posterior, after a while. The constant in Bayes' rule cancels in the ratio, so nobody needs to know it.

The priors (for the centred predictor):

- $\alpha \sim N(50, 5)$: with average growth the incumbent party gets about half of the votes, very probably between 40 and 60.
- $\beta \sim N(0, 5)$: 1% of growth changes the vote by less than 10 points, in an unknown direction. That is a weak statement, which is only to keep out absurd values.
- $\sigma \sim \text{Exponential}(1/5)$: elections deviate from the line by a few points, 5 on average.

```{r metropolis}
log_posterior <- function(th, yy = y, xx = xc, prior_b = c(0, 5), t_errors = FALSE) {
  # th = (alpha, beta, log sigma)
  s <- exp(th[3])
  mu <- th[1] + th[2] * xx
  loglik <- if (t_errors) {
    sum(dt((yy - mu) / s, 4, log = TRUE) - log(s))
  } else {
    sum(dnorm(yy, mu, s, log = TRUE))
  }
  loglik +
    dnorm(th[1], 50, 5, log = TRUE) +
    dnorm(th[2], prior_b[1], prior_b[2], log = TRUE) +
    dexp(s, 1 / 5, log = TRUE) +
    th[3] # + th[3]: because we walk on log sigma
}
metropolis <- function(draws, start, step, logp, ...) {
  out <- matrix(0, draws, 3, dimnames = list(NULL, c("alpha", "beta", "sigma")))
  now <- start
  lp <- logp(now, ...)
  for (i in seq_len(draws)) {
    candidate <- now + step * rnorm(3)
    lp_new <- logp(candidate, ...)
    if (log(runif(1)) < lp_new - lp) {
      now <- candidate
      lp <- lp_new
    }
    out[i, ] <- now
  }
  out[, 3] <- exp(out[, 3])
  out
}
set.seed(241); steps <- c(1.3, 1, 0.3); warm <- 2000; keep <- 20000
chains <- lapply(1:4, function(k) {
  metropolis(
    warm + keep,
    c(rnorm(1, 50, 8), rnorm(1, 0, 8), log(4) + rnorm(1)),
    steps,
    log_posterior
  )
})
```

### Did the chains arrive?

The check is the **R-hat** of Gelman and Rubin: the variance of all draws together, against the variance within each chain. If the chains are in different places the first is larger. By hand, with every chain cut in two halves, so that a drift within a chain also shows:

$$\hat R = \sqrt{\frac{\frac{m-1}{m}W + \frac 1m B}{W}}$$

($m$: length of a half; $W$: mean of the variances within the halves; $B$: $m$ times the variance of the means of the halves. Values above 1.01 are suspicious; Vehtari et al., 2021, recommend a version based on ranks.)

```{r rhat}
halves <- function(cs) {
  do.call(
    cbind,
    lapply(cs, function(v) {
      m <- length(v) / 2
      cbind(v[1:m], v[(m + 1):(2 * m)])
    })
  )
}
rhat_hand <- function(cs) {
  h <- halves(cs)
  m <- nrow(h)
  W <- mean(apply(h, 2, var))
  B <- m * var(colMeans(h))
  sqrt(((m - 1) / m * W + B / m) / W)
}
get <- function(p) lapply(chains, function(m) m[-(1:warm), p])
diag_tab <- sapply(c("alpha", "beta", "sigma"), function(p) {
  c(
    R_hat_by_hand = rhat_hand(get(p)),
    R_hat_rank = posterior::rhat(do.call(cbind, get(p))),
    effective_draws = posterior::ess_bulk(do.call(cbind, get(p)))
  )
})
round(diag_tab, 4)
rhat_first <- rhat_hand(lapply(chains, function(m) m[1:100, "beta"]))
c(R_hat_of_the_first_100_steps = rhat_first)
ess_stan <- posterior::ess_bulk(matrix(stan[, "growth"], ncol = 4))
```

The **effective** number of draws tells how many independent draws the walk is worth: `r format(round(diag_tab["effective_draws", "beta"]), big.mark = ",")` out of `r format(4 * keep, big.mark = ",")` for the slope. rstanarm gets `r format(round(ess_stan), big.mark = ",")` out of `r format(nrow(stan), big.mark = ",")`.

### Bayes factors depend on it even more

A *Bayes factor* compares two hypotheses, here "the slope is 0" with "the slope is something, distributed like the prior". It asks how well each **predicted** the data, so a very wide prior (a slope of 80 is possible) predicts badly. With flat priors for $\alpha$ and $\log\sigma$, the likelihood of the slope alone has a formula, $L(\beta) \propto \left(S + S_{xx}(\beta - \hat\beta)^2\right)^{-(n-1)/2}$, and one integral does the rest:

```{r bayes_factor}
S <- sum(residuals(ls_fit)^2); Sxx <- sum(xc^2); b_hat <- coef(ls_fit)[["growth"]]
L  <- function(b) (1 + Sxx * (b - b_hat)^2 / S)^(-(n - 1) / 2)
bf <- data.frame(prior_sd = c(0.5, 1, 2, 5, 20, 100, 1000))
bf$bayes_factor_for_an_effect <- sapply(bf$prior_sd, function(s) {
  integrate(function(b) L(b) * dnorm(b, 0, s), b_hat - 8, b_hat + 8, rel.tol = 1e-9)$value / L(0)
})
bf$posterior_mean <- sapply(bf$prior_sd, function(s) {
  den <- integrate(function(b) L(b) * dnorm(b, 0, s), b_hat - 8, b_hat + 8)$value
  integrate(function(b) b * L(b) * dnorm(b, 0, s), b_hat - 8, b_hat + 8)$value / den
})
print(round(bf, 2), row.names = FALSE)
```

From an SD of 5 to one of 1,000 the **posterior** of the slope hardly changes (mean `r f2(bf$posterior_mean[bf$prior_sd == 5])` and `r f2(bf$posterior_mean[bf$prior_sd == 1000])`). The **Bayes factor** goes from `r f1(bf$bayes_factor_for_an_effect[bf$prior_sd == 5])` in favour of an effect to `r f2(bf$bayes_factor_for_an_effect[bf$prior_sd == 1000])`, which is against one. A default, very wide prior makes the "no effect" win in the end, whatever the data say (the Lindley paradox). Use Bayes factors only with priors that you would defend.

## 7. What "calibrated" means

A credible interval is right **on average over the prior**: if the true values really came from the prior, 95% of the 95% intervals contain them. It is not right for every single true value. We can check both, with the formula of step 3 (here with a narrow prior for the slope, $\beta \mid \sigma^2 \sim N(0, (\sigma/2)^2)$ and $\sigma^2 \sim IG(5, 60)$):

```{r calibration}
set.seed(249); V0inv <- diag(c(1 / 4, 4)); m0 <- c(50, 0); a0 <- 5; b0 <- 60
sim_once <- function(beta_fixed = NULL) {
  s2 <- 1 / rgamma(1, a0, b0)
  a <- rnorm(1, 50, sqrt(4 * s2))
  bt <- if (is.null(beta_fixed)) rnorm(1, 0, sqrt(s2 / 4)) else beta_fixed * sqrt(s2 / 4)
  r <- nig(X, a + bt * xc + rnorm(n, 0, sqrt(s2)), m0, V0inv, a0, b0)["growth", ]
  r$low < bt && bt < r$high
}
cal <- c(
  `true slope drawn from the prior` = mean(replicate(3000, sim_once())),
  `true slope 1 prior SD from 0` = mean(replicate(3000, sim_once(1))),

)
cbind(coverage = round(cal, 3))
```

Drawn from the prior: `r pct(cal[[1]], 1)`. For a true slope that the prior considers very unlikely (3 SDs away) it is `r pct(cal[[3]], 1)`. A frequentist confidence interval has its 95% for **every** value, and does not use any knowledge. Choose what you need, and say which.

## 8. Things to keep in mind

- **Write down the prior** before you look, in units that a reader understands. Simulate from it (a *prior predictive check*) and see if it expects absurd data.
- **Centre the predictors**: then the prior of the intercept is about the outcome at average values.
- **Report what the result looks like with other priors**, at least a wider and a narrower one.
- **Check R-hat and the effective draws** for every parameter, and look at the trace plots. rstanarm gives warnings about *divergent transitions*: do not ignore them.
- **The posterior is conditional on the model.** Check it as you would any regression: simulated data, residuals, leave-one-out.
- **Probabilities of hypotheses** ("99% that the slope is positive") need the prior. Do not present them as a *p* value.
- **With many rows** the prior hardly matters. With few, it does, and that is exactly when it helps.
- **Multilevel models** are where Bayesian methods shine, because they estimate variances of small groups without trouble: `stan_glmer()` or `brms::brm()`. See [multilevel models](EXAMPLE_MULTILEVEL.Rmd).
- **Relatives**: the normal prior is [ridge regression](EXAMPLE_REGULARIZED_REGRESSION.Rmd) as a probability, and a prior on functions is a [Gaussian process](EXAMPLE_GAUSSIAN_PROCESS.Rmd).

```{r apa_numbers}
max_rhat <- max(apply(stan, 2, function(v) posterior::rhat(matrix(v, ncol = 4))))
```

**Method** (data analysis):

> The vote share of the party holding the White House in the `r n` presidential elections from `r min(hibbs$year)` to `r max(hibbs$year)` was regressed on the growth of real personal income per head during the term (Gelman et al., 2020; Hibbs, 2000), centred at its mean, with a Bayesian linear model with normal errors. The priors were N(50, 5) for the vote share at average growth, N(0, 5) for the slope (points per 1% of growth), and Exponential(1/5) for the residual standard deviation. The posterior was sampled with Hamiltonian Monte Carlo (R package rstanarm; four chains of 10,000 iterations, half of them warm-up); convergence was judged with R-hat and the effective number of draws. We report posterior means, standard deviations and 95% credible intervals, the model was checked with posterior predictive simulations and leave-one-out cross-validation (Vehtari et al., 2017), and the sensitivity to the prior of the slope was examined with six priors and with *t*-distributed errors. Analyses were conducted in R (Version `r paste(R.version$major, R.version$minor, sep = ".")`; R Core Team, `r R.version$year`).

**Results:**

> All chains converged (R-hat ≤ `r f3(max_rhat)`; at least `r format(round(ess_stan, -2), big.mark = ",")` effective draws for the slope). One percentage point of growth was associated with `r f1(stan_tab["beta", "mean"])` points more of the vote (posterior *SD* = `r f2(stan_tab["beta", "sd"])`, 95% credible interval [`r f1(stan_tab["beta", "low"])`, `r f1(stan_tab["beta", "high"])`]; posterior probability of a positive slope `r ptop(p_pos_stan)`; Table 1). The residual standard deviation was `r f1(stan_tab["sigma", "mean"])` points. Growth improved the expected log predictive density by `r f1(elpd_diff)` (*SE* = `r f1(elpd_se)`). For a growth of 2% the predicted share was `r f1(mean(vote_2))`% (95% prediction interval [`r f1(quantile(vote_2, 0.025))`, `r f1(quantile(vote_2, 0.975))`]), with a probability of `r pct(mean(vote_2 > 50))` of exceeding one half. The posterior mean of the slope was between `r f1(min(sens$mean[1:3]))` and `r f1(max(sens$mean[1:3]))` for weak priors and between `r f1(min(sens$mean[4:6]))` and `r f1(max(sens$mean[4:6]))` for strong ones; with *t*-distributed errors it was `r f1(mean(robust[, "beta"]))`.

## 10. Summary

| | |
|---|---|
| **When** | Few data, knowledge from outside, probabilities of the parameters and forecasts wanted, hierarchical models |
| **The rule** | Posterior $\propto$ likelihood × prior |
| **Linear model** | Closed form (normal–inverse-gamma), or sampling |
| **Sampling** | Metropolis (by hand), Hamiltonian Monte Carlo (Stan) |
| **How (R)** | `stan_glm(y ~ x, prior = normal(0, 5), prior_intercept = normal(50, 5), prior_aux = exponential(0.2))` |
| **Read** | Mean or median, credible interval, probabilities, forecasts |
| **Check** | R-hat, effective draws, simulated data, leave-one-out, other priors |
| **Danger** | Strong priors with few data, Bayes factors with default priors |
