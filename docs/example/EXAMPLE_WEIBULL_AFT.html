Weibull and Accelerated Failure Time Models: How Long Will a Motor Last?

  • Show All Code
  • Hide All Code
  • View Source
Parametric survival regression in R with survival::survreg(), on the classic accelerated life test of motor insulation (Nelson and Hahn, 1972): the Weibull distribution and its hazard, the accelerated failure time model by hand with censored data, the Arrhenius relation, Weibull against log-normal, log-logistic and exponential, extrapolation to working temperature with intervals, proportional hazards and time ratios from one model next to Cox, checks and APA reporting.

The question: five years in a few months

The insulation of an electric motor ages with heat, and one day the motor fails. A motor is meant to run at 130 °C for years. Nobody wants to wait for years to know how long. So engineers test motors at higher temperatures, where they fail sooner, and calculate back. This is an accelerated life test.

Nelson and Hahn (1972) published a famous one: 40 motors at 150, 170, 190 and 220 °C. When the test was stopped, many had not failed, and at 150 °C none had. The question has three parts. How does life depend on the temperature? What is the distribution of the lifetimes? And what does it say about 130 °C, where nothing was measured?

The answer needs a model with a full distribution. The Cox model leaves the baseline open, and so it cannot say anything about times or temperatures outside the data. A parametric survival model can, at the price of an assumption. The accelerated failure time (AFT) model got its name here: the predictors make time itself run faster or slower.

3. The model step by step, with formulas

Step 1: the Weibull distribution

Weibull (1951) proposed a distribution for the strength of materials that has been used for lifetimes ever since. Its survival function and hazard are

\[S(t) = \exp\!\left[-\left(\frac{t}{\eta}\right)^{k}\right], \qquad h(t) = \frac{k}{\eta}\left(\frac{t}{\eta}\right)^{k-1}\]

\(\eta\) is the scale, the time at which 63% have failed. \(k\) is the shape: with \(k > 1\) the hazard rises (wear), with \(k < 1\) it falls (the weak ones go first), and with \(k = 1\) it is constant (the exponential distribution: no memory).

Code 
grid <- seq(0.02, 3, by = 0.02)

)

Step 2: predictors stretch time

\[\log T = \beta_0 + \beta_1 x + \sigma W\]

\(\log T\) is a line plus an error. If \(T\) is Weibull, \(W\) has the smallest extreme value distribution, and \(\sigma = 1/k\). With a normal \(W\), \(T\) is log-normal; with a logistic \(W\), log-logistic. In all of them, one unit more of \(x\) multiplies every quantile of the lifetime by \(e^{\beta_1}\), the time ratio. Life at 190 °C is life at 170 °C in fast motion.

Step 3: why \(1/T\)? The Arrhenius relation

Chemistry says that the speed of a reaction depends on the absolute temperature as \(e^{-E/(kT)}\). If ageing is such a reaction, the log of the lifetime is a straight line in 1 / absolute temperature. This is knowledge from outside the data, and the only thing that makes an extrapolation to 130 °C reasonable. (We use 1000/K, so the numbers are easy to read.)

Step 4: maximum likelihood with censoring

A failure at time \(t\) contributes the density \(f(t)\), a motor still running at time \(t\) contributes the survival probability \(S(t)\):

\[\log L = \sum_{\text{failed}} \log f(t_i) + \sum_{\text{running}} \log S(t_i)\]

By hand, with R’s Weibull functions (dweibull, pweibull):

Code 
minus_loglik <- function(par) {
  # intercept, slope, log(sigma)
  eta <- exp(par[1] + par[2] * motors$x)
  k <- 1 / exp(par[3])
  -sum(ifelse(
    motors$status == 1,
    dweibull(motors$time, k, eta, log = TRUE),
    pweibull(motors$time, k, eta, lower.tail = FALSE, log.p = TRUE)
  ))
}
hand <- optim(c(-12, 9, -1), minus_loglik, control = list(maxit = 5000, reltol = 1e-14))
hand <- optim(hand$par, minus_loglik, control = list(maxit = 5000, reltol = 1e-14))
fit  <- survreg(Surv(time, status) ~ x, data = motors, dist = "weibull")
rbind(
  by_hand = c(`(Intercept)` = hand$par[1], x = hand$par[2], sigma = exp(hand$par[3]), logLik = -hand$value),
  survreg = c(coef(fit), fit$scale, logLik(fit))
)

  • x = 9.72: the slope of the Arrhenius line. Easier to say: going from 160 to 150 °C multiplies the lifetime by 1.70. An old rule of engineers says that 10 degrees less double the life.
  • Scale = 0.33 is \(\sigma\), so the shape is \(k = 1/\sigma\) = 3.07: well above 1. The hazard rises steeply: the insulation wears out.

  • Do not confuse the scale of survreg (\(\sigma\)) with the scale of the Weibull distribution (\(\eta = e^{\beta_0 + \beta_1 x}\)).

Quantiles

The time by which a share \(p\) of the motors has failed:

\[t_p = \exp\big(\beta_0 + \beta_1 x + \sigma\, w_p\big), \qquad w_p = \log[-\log(1 - p)]\]

6. Checking the model

Is the spread the same at all temperatures?

The AFT model assumes one \(\sigma\). Let each temperature have its own (strata):

Code 
# at 150 degrees nothing failed: no information about sigma
with_failures <- subset(motors, temp > 150)
one  <- survreg(Surv(time, status) ~ x, data = with_failures, dist = "weibull")
many <- survreg(Surv(time, status) ~ x + strata(temp), data = with_failures, dist = "weibull")
lr   <- 2 * (as.numeric(logLik(many)) - as.numeric(logLik(one)))
many$scale
 temp=170  temp=190  temp=220 
0.3483426 0.5717329 0.1115813
Code 
c(LR = lr, df = 2, p = pchisq(lr, 2, lower.tail = FALSE))

7.44462238 2.00000000 0.02417802

The scales are 0.35, 0.57, 0.11 at 170, 190 and 220 °C, and the test of equality gives p = .024. The spread is probably not the same: at 220 °C the failures were all found at two neighbouring inspections. With five to seven failures per group no estimate of a spread is reliable, but the assumption of one \(\sigma\) is doubtful, and again it is the highest temperature that stands out.

7. The Weibull model is also a proportional hazards model

The Weibull is special. It is the only distribution that is both an AFT and a PH model. A time ratio of \(e^{\beta}\) is a hazard ratio of \(e^{-\beta/\sigma}\):

\[\text{HR} = e^{-\beta / \sigma} = e^{-\beta k}\]

We check it on the experiment of the Cox page, with 432 men released from prison, half of whom received money, and the weeks until the first arrest:

8. Things to keep in mind

  • Extrapolation is the purpose and the danger. Say what it rests on: the distribution, the physical law, the same cause of failure.
  • Choose the distribution by theory and tradition as well as by AIC. The generalized gamma contains the exponential, Weibull and log-normal as special cases (flexsurv::flexsurvreg(dist = "gengamma")), and splines are more flexible still (Jackson, 2016).
  • Look at the hazard. If it falls after a peak (illness, infant mortality), the Weibull cannot follow it.
  • Censoring must be independent of the lifetime. Here it was fixed in advance.
  • Interval censoring. Failures found at inspections happened some time before. Surv(time1, time2, type = "interval2") does it properly.
  • Time that varies for predictors is harder in AFT models than in Cox.
  • A time ratio is an average stretch. If the effect is different for early and late events, use censored quantile regression, which has no such restriction.
  • Parameter names differ between programs. Check 1/scale, signs, and whether the coefficients are for log time or log hazard.

9. Reporting the results in APA style

A report (APA 7th edition) needs the number of events and of censored cases, the distribution and why, the transformation of the predictors, time ratios or quantiles with intervals, and the basis of any extrapolation. The numbers come from the R objects:

Method (data analysis):

The lifetimes of 40 motors tested at 150, 170, 190 and 220 °C (Nelson & Hahn, 1972) were analysed with a Weibull accelerated failure time model; 23 motors had not failed at the end of the test and were right-censored. The predictor was 1000 divided by the absolute temperature (Arrhenius relation). The Weibull distribution was compared with the exponential, log-normal and log-logistic distributions by the AIC, and the equality of the scale and the linearity of the relation were tested with likelihood-ratio tests. Analyses were conducted in R (Version 4.6.2; R Core Team, 2026) with the package survival (Therneau, 2026).

Results:

Lifetimes were longer at lower temperatures, b = 9.72, SE = 0.70, z = 13.97, p < .001; 10 degrees less, from 160 to 150 °C, multiplied the lifetime by 1.70. The shape parameter was 3.07, an increasing hazard. The Weibull model had an AIC of 298.5 (log-logistic 300.1, log-normal 303.1, exponential 314.7). The extrapolated median lifetime at 130 °C was 42,086 hours, 95% CI [26,347, 67,226] (Table 1); without the tests at 220 °C it was 75,517 hours. These values rest on the Weibull distribution and the Arrhenius relation, which cannot be checked at 130 °C.

## The question: five years in a few months

The insulation of an electric motor ages with heat, and one day the motor fails. A motor is meant to run at 130 °C for years. Nobody wants to wait for years to know how long. So engineers test motors at **higher** temperatures, where they fail sooner, and calculate back. This is an **accelerated life test**.

Nelson and Hahn (1972) published a famous one: 40 motors at 150, 170, 190 and 220 °C. When the test was stopped, many had not failed, and at 150 °C **none** had. The question has three parts. How does life depend on the temperature? What is the distribution of the lifetimes? And what does it say about 130 °C, **where nothing was measured**?

The answer needs a model with a full distribution. The [Cox model](EXAMPLE_COX.Rmd) leaves the baseline open, and so it cannot say anything about times or temperatures outside the data. A **parametric** survival model can, at the price of an assumption. The **accelerated failure time** (AFT) model got its name here: the predictors make time itself run faster or slower.

## 3. The model step by step, with formulas

### Step 1: the Weibull distribution

Weibull (1951) proposed a distribution for the strength of materials that has been used for lifetimes ever since. Its survival function and hazard are

$$S(t) = \exp\!\left[-\left(\frac{t}{\eta}\right)^{k}\right], \qquad h(t) = \frac{k}{\eta}\left(\frac{t}{\eta}\right)^{k-1}$$

$\eta$ is the **scale**, the time at which 63% have failed. $k$ is the **shape**: with $k > 1$ the hazard rises (wear), with $k < 1$ it falls (the weak ones go first), and with $k = 1$ it is constant (the exponential distribution: no memory).

```{r shapes}
grid <- seq(0.02, 3, by = 0.02)
shapes <- do.call(
  rbind,
  lapply(c(0.7, 1, 1.5, 3), function(k) {
    data.frame(t = grid, h = k * grid^(k - 1), shape = paste("k =", k))
  })
)
ggplot(shapes, aes(t, h, colour = shape)) +
  geom_line(linewidth = 1) +
  coord_cartesian(ylim = c(0, 5)) +
  scale_colour_viridis_d(end = 0.9, name = NULL) +
  labs(title = "The hazard of the Weibull distribution (η = 1)", x = "time", y = "hazard") +
  theme_bw() +
  theme(legend.position = "bottom")
```

### Step 2: predictors stretch time

$$\log T = \beta_0 + \beta_1 x + \sigma W$$

$\log T$ is a line plus an error. If $T$ is Weibull, $W$ has the *smallest extreme value* distribution, and $\sigma = 1/k$. With a normal $W$, $T$ is log-normal; with a logistic $W$, log-logistic. In all of them, one unit more of $x$ multiplies **every** quantile of the lifetime by $e^{\beta_1}$, the **time ratio**. Life at 190 °C is life at 170 °C in fast motion.

### Step 3: why $1/T$? The Arrhenius relation

Chemistry says that the speed of a reaction depends on the absolute temperature as $e^{-E/(kT)}$. If ageing is such a reaction, the log of the lifetime is a straight line in **1 / absolute temperature**. This is knowledge from outside the data, and the only thing that makes an extrapolation to 130 °C reasonable. (We use 1000/K, so the numbers are easy to read.)

### Step 4: maximum likelihood with censoring

A failure at time $t$ contributes the **density** $f(t)$, a motor still running at time $t$ contributes the **survival** probability $S(t)$:

$$\log L = \sum_{\text{failed}} \log f(t_i) + \sum_{\text{running}} \log S(t_i)$$

By hand, with R's Weibull functions (`dweibull`, `pweibull`):

```{r by_hand}
minus_loglik <- function(par) {
  # intercept, slope, log(sigma)
  eta <- exp(par[1] + par[2] * motors$x)
  k <- 1 / exp(par[3])
  -sum(ifelse(
    motors$status == 1,
    dweibull(motors$time, k, eta, log = TRUE),
    pweibull(motors$time, k, eta, lower.tail = FALSE, log.p = TRUE)
  ))
}
hand <- optim(c(-12, 9, -1), minus_loglik, control = list(maxit = 5000, reltol = 1e-14))
hand <- optim(hand$par, minus_loglik, control = list(maxit = 5000, reltol = 1e-14))
fit  <- survreg(Surv(time, status) ~ x, data = motors, dist = "weibull")
rbind(
  by_hand = c(`(Intercept)` = hand$par[1], x = hand$par[2], sigma = exp(hand$par[3]), logLik = -hand$value),
  survreg = c(coef(fit), fit$scale, logLik(fit))
)
```

## 4. Fitting the model and reading the output

```{r fit}
summary(fit)
b <- coef(fit); s <- summary(fit)$table; k <- 1 / fit$scale
ratio10 <- exp(b[["x"]] * (1000 / (150 + 273.16) - 1000 / (160 + 273.16))) # from 160 to 150 degrees
```

- **`x`** = `r f2(b[["x"]])`: the slope of the Arrhenius line. Easier to say: going from 160 to 150 °C multiplies the lifetime by `r f2(ratio10)`. An old rule of engineers says that 10 degrees less double the life.
- **`Scale`** = `r f2(fit$scale)` is $\sigma$, so the **shape** is $k = 1/\sigma$ = `r f2(k)`: well above 1. The hazard rises steeply: the insulation **wears out**.
- **`Log(scale)`**: its test asks whether $\sigma = 1$, that is whether the exponential distribution would do. *p* `r pval(s["Log(scale)", "p"])`: it would not.
- **`Loglik`, `Chisq`**: the likelihood-ratio test of all the predictors.
- Do not confuse the `scale` of `survreg` ($\sigma$) with the scale of the Weibull distribution ($\eta = e^{\beta_0 + \beta_1 x}$).

### Quantiles

The time by which a share $p$ of the motors has failed:

$$t_p = \exp\big(\beta_0 + \beta_1 x + \sigma\, w_p\big), \qquad w_p = \log[-\log(1 - p)]$$

```{r quantiles}
at <- data.frame(temp = c(130, 150, 170, 190, 220)); at$x <- 1000 / (at$temp + 273.16)

colnames(q) <- c("10%", "50%", "90%")
round(cbind(temp = at$temp, q))
```

## 5. Which distribution?

```{r distributions}
dists <- names(dist_colours)
fits <- lapply(dists, function(d) survreg(Surv(time, status) ~ x, data = motors, dist = d))
names(fits) <- dists
at130 <- data.frame(x = 1000 / (130 + 273.16))
interval <- function(m, p) {
  r <- predict(m, at130, type = "uquantile", p = p, se.fit = TRUE)
  est <- r$fit[[1]]; se <- r$se.fit[[1]]
  exp(c(estimate = est, low = est - 1.96 * se, high = est + 1.96 * se))
}
compare <- t(sapply(fits, function(m) {
  c(
    AIC = AIC(m),
    median_130 = interval(m, 0.5)[[1]],
    q10_130 = interval(m, 0.1)[[1]],
    q0.1_130 = interval(m, 0.001)[[1]]
  )
}))
round(compare)
```

By the AIC the Weibull (`r f1(compare["weibull", "AIC"])`) and the log-logistic (`r f1(compare["loglogistic", "AIC"])`) are best, the log-normal close, and the exponential is out. With `r sum(motors$status)` failures the data cannot say more. Now look at the predictions for 130 °C.

- The **median** life is `r f0(compare["weibull", "median_130"])`, `r f0(compare["lognormal", "median_130"])` and `r f0(compare["loglogistic", "median_130"])` hours. These agree: about five years of running day and night.
- The time when **one in a thousand** has failed, which matters for a guarantee, is `r f0(compare["weibull", "q0.1_130"])`, `r f0(compare["lognormal", "q0.1_130"])` and `r f0(compare["loglogistic", "q0.1_130"])` hours. Here the distributions disagree by a factor of `r f1(max(compare[1:3, "q0.1_130"]) / min(compare[1:3, "q0.1_130"]))`. Nothing in the data can decide, because there is no data in that tail. (The exponential distribution, which the data reject, would say `r f0(compare["exponential", "q0.1_130"])` hours.)

## 6. Checking the model

### Is the spread the same at all temperatures?

The AFT model assumes one $\sigma$. Let each temperature have its own (`strata`):

```{r strata}
# at 150 degrees nothing failed: no information about sigma
with_failures <- subset(motors, temp > 150)
one  <- survreg(Surv(time, status) ~ x, data = with_failures, dist = "weibull")
many <- survreg(Surv(time, status) ~ x + strata(temp), data = with_failures, dist = "weibull")
lr   <- 2 * (as.numeric(logLik(many)) - as.numeric(logLik(one)))
many$scale
c(LR = lr, df = 2, p = pchisq(lr, 2, lower.tail = FALSE))
```

The scales are `r paste(f2(many$scale), collapse = ", ")` at 170, 190 and 220 °C, and the test of equality gives *p* `r pval(pchisq(lr, 2, lower.tail = FALSE))`. The spread is probably **not** the same: at 220 °C the failures were all found at two neighbouring inspections. With five to seven failures per group no estimate of a spread is reliable, but the assumption of one $\sigma$ is doubtful, and again it is the highest temperature that stands out.

### Is the line straight?

```{r linearity}
curve <- survreg(Surv(time, status) ~ x + I(x^2), data = motors, dist = "weibull")
free  <- survreg(Surv(time, status) ~ factor(temp), data = with_failures, dist = "weibull")
c(AIC_line = AIC(fit), AIC_curve = AIC(curve))
c(AIC_line = AIC(one), AIC_each_temperature_free = AIC(free))
lr_line <- 2 * (as.numeric(logLik(free)) - as.numeric(logLik(one)))
c(LR = lr_line, df = 1, p = pchisq(lr_line, 1, lower.tail = FALSE))
```

A bend (a squared term) lowers the AIC by only `r f1(AIC(fit) - AIC(curve))`. Against a model where each of the three temperatures with failures has its own level, the Arrhenius line loses $\chi^2$(1) = `r f2(lr_line)`, *p* `r pval(pchisq(lr_line, 1, lower.tail = FALSE))`. `r if (pchisq(lr_line, 1, lower.tail = FALSE) < .05) "The line is not perfect. The lifetimes at the highest temperature are longer than it says, perhaps because the mechanism of failure is another one there. If so, the points at 220 °C should not help to predict 130 °C." else "The line is compatible with the data."`

## 7. The Weibull model is also a proportional hazards model

The Weibull is special. It is the only distribution that is **both** an AFT and a PH model. A time ratio of $e^{\beta}$ is a hazard ratio of $e^{-\beta/\sigma}$:

$$\text{HR} = e^{-\beta / \sigma} = e^{-\beta k}$$

We check it on the experiment of [the Cox page](EXAMPLE_COX.Rmd), with 432 men released from prison, half of whom received money, and the weeks until the first arrest:

```{r rossi}
rossi <- read.csv("https://vincentarelbundock.github.io/Rdatasets/csv/carData/Rossi.csv")
rossi$money <- as.integer(rossi$fin == "yes")
aft <- survreg(Surv(week, arrest) ~ money + age + prio, data = rossi, dist = "weibull")
cox <- coxph(Surv(week, arrest) ~ money + age + prio, data = rossi)
tr  <- exp(coef(aft)[["money"]]); tr_ci <- exp(confint(aft)["money", ])
hr_weibull <- exp(-coef(aft) / aft$scale)[-1]
round(
  rbind(
    time_ratio = exp(coef(aft))[-1],
    hazard_ratio_Weibull = hr_weibull,
    hazard_ratio_Cox = exp(coef(cox))
  ),
  3
)
c(shape = 1 / aft$scale)
```

- The **hazard ratio** of the payment is `r f2(hr_weibull[["money"]])` by the Weibull model and `r f2(exp(coef(cox)[["money"]]))` by Cox. They agree, without Cox assuming any shape.
- The **time ratio** is `r f2(tr)`, 95% CI [`r f2(tr_ci[1])`, `r f2(tr_ci[2])`]: the payment stretches the time to the arrest by `r pct(tr - 1)`. Many find this easier to understand than a ratio of hazards (Wei, 1992).

| | Cox | Weibull | Log-normal, log-logistic |
|---|---|---|---|
| Baseline | free | $k$ and $\eta$ | two parameters |
| Effects | hazard ratios | hazard ratios **and** time ratios | time ratios only |
| Hazard over time | any | rising or falling | can rise and then fall |
| Prediction beyond the data | no | yes | yes |
| Assumption | proportional hazards | both, and the shape | time ratios, and the shape |

## 8. Things to keep in mind

- **Extrapolation is the purpose and the danger.** Say what it rests on: the distribution, the physical law, the same cause of failure.
- **Choose the distribution** by theory and tradition as well as by AIC. The generalized gamma contains the exponential, Weibull and log-normal as special cases (`flexsurv::flexsurvreg(dist = "gengamma")`), and splines are more flexible still (Jackson, 2016).
- **Look at the hazard.** If it falls after a peak (illness, infant mortality), the Weibull cannot follow it.
- **Censoring must be independent** of the lifetime. Here it was fixed in advance.
- **Interval censoring.** Failures found at inspections happened some time before. `Surv(time1, time2, type = "interval2")` does it properly.
- **Time that varies** for predictors is harder in AFT models than in Cox.
- **A time ratio is an average stretch.** If the effect is different for early and late events, use [censored quantile regression](EXAMPLE_CENSORED_QUANTILE_REGRESSION.Rmd), which has no such restriction.
- **Parameter names** differ between programs. Check `1/scale`, signs, and whether the coefficients are for log time or log hazard.

**Method** (data analysis):

> The lifetimes of `r nrow(motors)` motors tested at 150, 170, 190 and 220 °C (Nelson & Hahn, 1972) were analysed with a Weibull accelerated failure time model; `r sum(motors$status == 0)` motors had not failed at the end of the test and were right-censored. The predictor was 1000 divided by the absolute temperature (Arrhenius relation). The Weibull distribution was compared with the exponential, log-normal and log-logistic distributions by the AIC, and the equality of the scale and the linearity of the relation were tested with likelihood-ratio tests. Analyses were conducted in R (Version `r paste(R.version$major, R.version$minor, sep = ".")`; R Core Team, `r R.version$year`) with the package survival (Therneau, 2026).

**Results:**

> Lifetimes were longer at lower temperatures, *b* = `r f2(b[["x"]])`, *SE* = `r f2(s["x", 2])`, *z* = `r f2(s["x", 3])`, *p* `r pval(s["x", 4])`; 10 degrees less, from 160 to 150 °C, multiplied the lifetime by `r f2(ratio10)`. The shape parameter was `r f2(k)`, an increasing hazard. The Weibull model had an AIC of `r f1(compare["weibull", "AIC"])` (log-logistic `r f1(compare["loglogistic", "AIC"])`, log-normal `r f1(compare["lognormal", "AIC"])`, exponential `r f1(compare["exponential", "AIC"])`). The extrapolated median lifetime at 130 °C was `r f0(med130[1])` hours, 95% CI [`r f0(med130[2])`, `r f0(med130[3])`] (Table 1); without the tests at 220 °C it was `r f0(m2[1])` hours. These values rest on the Weibull distribution and the Arrhenius relation, which cannot be checked at 130 °C.

**Points to remember:**

- Give the numbers of events and of censored cases at each condition.
- Name the distribution and the parameterisation.
- Report quantiles in real units, with intervals.
- Mark extrapolations, and show how they change with other distributions.

## 10. Summary

| | |
|---|---|
| **When** | Times to an event, with censoring, and a need for full distributions, predictions or time ratios |
| **The model** | $\log T = x^\top\beta + \sigma W$; Weibull: hazard $\propto t^{k-1}$, $k = 1/\sigma$ |
| **How (R)** | `survreg(Surv(time, event) ~ x, data, dist = "weibull")` |
| **Reading it** | $e^\beta$: time ratio; for the Weibull also $e^{-\beta/\sigma}$: hazard ratio |
| **Quantiles** | `predict(fit, newdata, type = "quantile", p = c(.1, .5, .9))` |
| **Choosing** | AIC, residual plots, theory of the hazard |
| **Danger** | Extrapolation in time and in the predictors |
| **Related pages** | [Cox](EXAMPLE_COX.Rmd), [censored quantile regression](EXAMPLE_CENSORED_QUANTILE_REGRESSION.Rmd), [Tobit](EXAMPLE_TOBIT.Rmd) (a survival model in disguise) |
