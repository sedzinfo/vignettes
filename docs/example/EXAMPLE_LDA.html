Theoretical Background

Linear Discriminant Analysis (LDA) is a supervised classification and dimensionality reduction technique introduced by Fisher (1936). Given \(K\) classes and \(p\) predictors, LDA finds a set of linear combinations of the predictors — called discriminant functions — that maximise the ratio of between-class variance to within-class variance.

Formally, the \(k\)-th discriminant function is:

\[z_k = \mathbf{a}_k^\top \mathbf{x}\]

where \(\mathbf{a}_k\) is the vector of discriminant coefficients (the scaling matrix returned by MASS::lda) and \(\mathbf{x}\) is the vector of predictor values for an observation. For \(K\) classes there are at most \(\min(K-1, p)\) discriminant functions.

Classification is performed by assigning each observation to the class whose centroid (in the discriminant space) is closest, weighted by the prior class probabilities:

\[\hat{y} = \arg\max_k \left[ \log \pi_k - \tfrac{1}{2} \delta_k^2(\mathbf{x}) \right]\]

where \(\pi_k\) is the prior probability of class \(k\) and \(\delta_k^2(\mathbf{x})\) is the squared Mahalanobis distance from \(\mathbf{x}\) to the \(k\)-th class centroid.

Key assumptions:

Assumption Description
Multivariate normality Predictors follow a multivariate normal distribution within each class
Homogeneity of covariance All classes share the same covariance matrix \(\boldsymbol{\Sigma}\) (relaxed in QDA)
No perfect multicollinearity Predictors must not be linearly dependent
Adequate sample size The smallest class should comfortably exceed the number of predictors \(p\)

The singular values (SVD) returned by MASS::lda quantify the importance of each discriminant function: larger values indicate greater between-class separation relative to within-class scatter.

Model Specification

We fit LDA using all available predictors to discriminate infertile cases from controls. Because there are only two classes (\(K = 2\)), LDA produces a single discriminant function (\(K - 1 = 1\)).

Note that case ~ . also enters the matching identifiers stratum and pooled.stratum as if they were numeric predictors, although their values are arbitrary labels. Likewise, age and parity were matching variables, so by design they carry almost no discriminating information. In a real analysis the identifiers should be dropped (e.g. case ~ education + age + parity + induced + spontaneous), and matched data are better analysed with conditional logistic regression (survival::clogit). The education dummies and the 0/1/2 abortion counts also depart from the multivariate normality assumption. They are kept here to illustrate the mechanics of LDA.

Code 
model <- MASS::lda(case ~ ., data=infert)

Prior Probabilities and Class Counts

Prior probabilities reflect the proportion of each class in the training data. LDA uses these priors to penalise or favour predictions toward a class based on its base rate. Because each infertile case was matched with two fertile controls, the priors are about 2:1 (0.665 for controls, 0.335 for cases), which pushes borderline observations toward the control class.

Discriminant Function Coefficients

The coefficients (the scaling matrix) define the linear combination of predictors that maximises class separation. They are raw (unstandardised) weights, scaled so that the discriminant scores have unit within-group variance. Their size therefore depends on each predictor’s units (e.g. age is per year), so to compare predictors multiply each coefficient by that predictor’s pooled within-group standard deviation, or use structure correlations.

Positive coefficients push scores toward the infertile case class; negative coefficients push toward the control class (the case centroid lies on the positive side of LD1 in this fit; the sign of a discriminant function is arbitrary). education12+ yrs (2.05) and spontaneous (1.98) carry the largest positive raw weights, followed by induced (1.16). Because raw coefficients depend on units, these weights alone do not rank the predictors’ importance; a standardised comparison is needed for that.

Model Description — Singular Values

MASS::lda reports the singular value (SVD) of the single discriminant function as the ratio of between- to within-group standard deviation on that function. The between-group part is weighted by group size, so the value grows with the sample size and is not an effect size. A more interpretable measure of separation is the distance between the two class centroids on LD1, which is expressed in within-class standard deviation units because the discriminant scores have unit within-group variance.

Posterior Probabilities

LDA also returns posterior class probabilities for each observation — the probability of belonging to each class given the discriminant score. Values close to 0 or 1 indicate high-confidence assignments; values near 0.5 indicate ambiguity.

## Theoretical Background

**Linear Discriminant Analysis (LDA)** is a supervised classification and dimensionality reduction technique introduced by Fisher (1936). Given $K$ classes and $p$ predictors, LDA finds a set of linear combinations of the predictors — called **discriminant functions** — that maximise the ratio of *between-class variance* to *within-class variance*.

Formally, the $k$-th discriminant function is:

$$z_k = \mathbf{a}_k^\top \mathbf{x}$$

where $\mathbf{a}_k$ is the vector of discriminant coefficients (the *scaling* matrix returned by `MASS::lda`) and $\mathbf{x}$ is the vector of predictor values for an observation. For $K$ classes there are at most $\min(K-1, p)$ discriminant functions.

**Classification** is performed by assigning each observation to the class whose centroid (in the discriminant space) is closest, weighted by the prior class probabilities:

$$\hat{y} = \arg\max_k \left[ \log \pi_k - \tfrac{1}{2} \delta_k^2(\mathbf{x}) \right]$$

where $\pi_k$ is the prior probability of class $k$ and $\delta_k^2(\mathbf{x})$ is the squared Mahalanobis distance from $\mathbf{x}$ to the $k$-th class centroid.

**Key assumptions:**

| Assumption | Description |
|---|---|
| Multivariate normality | Predictors follow a multivariate normal distribution within each class |
| Homogeneity of covariance | All classes share the same covariance matrix $\boldsymbol{\Sigma}$ (relaxed in QDA) |
| No perfect multicollinearity | Predictors must not be linearly dependent |
| Adequate sample size | The smallest class should comfortably exceed the number of predictors $p$ |

The **singular values** (SVD) returned by `MASS::lda` quantify the importance of each discriminant function: larger values indicate greater between-class separation relative to within-class scatter.

## Second Example — Iris Dataset

The `iris` dataset provides a three-class problem ($K = 3$, $\min(K-1, p) = 2$ discriminant functions) that illustrates multi-class LDA and the interpretation of a two-dimensional discriminant space.

```{r iris_model}
model_iris <- MASS::lda(Species ~ ., data=iris)
result_iris <- report_lda(model=model_iris)
```

### Proportion of Trace

With two discriminant functions, the **proportion of trace** tells us how much of the total between-class variance each function captures.

```{r iris_trace}
prop_trace <- model_iris$svd^2 / sum(model_iris$svd^2)
cat("LD1 proportion of trace:", round(prop_trace[1], 4), "\n")
cat("LD2 proportion of trace:", round(prop_trace[2], 4), "\n")
```

LD1 captures almost all of the separation (`r round(100*prop_trace[1],1)`% of the trace): setosa lies far from the other two species, and versicolor and virginica are also largely separated along LD1. LD2 adds only a small extra contrast between versicolor and virginica.

### Discriminant Space Plot

```{r iris_plot, fig.width=7, fig.height=5, dev='png', fig.retina=2}
scores_iris <- as.data.frame(predict(model_iris)$x)
scores_iris$Species <- iris$Species

ggplot(scores_iris, aes(x=LD1, y=LD2, colour=Species)) +
  geom_point(alpha=0.7, size=2) +
  stat_ellipse(level=0.95, linewidth=0.8) +
  scale_colour_manual(values=c("#4dac26","#2166ac","#d6604d")) +
  theme_bw() +
  labs(title="Iris species in the LDA discriminant space",
       subtitle="95% concentration ellipses per class",
       x="Linear Discriminant 1", y="Linear Discriminant 2")
```
