Partial Least Squares: How Fat Is This Meat?

  • Show All Code
  • Hide All Code
  • View Source
Partial least squares regression (PLS) in R, by hand and with pls::plsr(), on the Tecator data: predicting the fat content of meat from a near-infrared spectrum of 100 wavelengths. Why least squares overfits, weights, scores and loadings, PLS against principal components regression, grouped cross-validation when samples are measured twice, preprocessing of spectra, a test set, variable importance, several outcomes at once (PLS2), the failure of extrapolation, and APA reporting.

The question: reading fat with light

How much fat is in this minced meat? The chemical analysis takes hours and destroys the sample. Light takes seconds. Shine near-infrared light of 100 different wavelengths through the meat, and measure how much of each is absorbed. Water, fat and protein absorb different wavelengths, so the spectrum contains the answer. But not at any single wavelength: everything overlaps.

So we need a regression of the fat content on 100 predictors, and it has every problem at once:

  • 100 predictors for 172 samples;
  • neighbouring wavelengths that correlate above .99;
  • what varies most in the spectra (how tightly the meat is packed, how it scatters the light) has little to do with fat.

The last point is the one that hurts principal components regression, which picks its components by variance and does not look at the outcome. Partial least squares (PLS) looks at it. It builds components that vary and go with the outcome. It is the standard method of chemistry for this problem (Wold et al., 2001), and it is used wherever there are many correlated predictors.

3. The method step by step, with formulas

Step 1: one component

We look for a weighted sum of the (centred) predictors, \(t = Xw\), with weights of length 1. Principal components analysis maximises the variance of \(t\). PLS maximises its covariance with the outcome:

\[w = \arg\max_{\lVert w \rVert = 1} \text{Cov}(Xw,\, y)^2 = \arg\max_{\lVert w \rVert = 1} \text{Var}(Xw)\,\text{Cor}(Xw, y)^2\;\text{Var}(y)\]

The component must vary and correlate with \(y\). The solution is simple: the weight of each wavelength is proportional to its covariance with \(y\).

\[w = \frac{X^\top y}{\lVert X^\top y \rVert}\]

Step 2: use it, and take it away

Regress \(y\) on the score \(t\) (coefficient \(q\)), and every column of \(X\) on the score \(t\) (coefficients \(p\), the loadings). Subtract what has been explained, from both:

\[q = \frac{y^\top t}{t^\top t}, \quad p = \frac{X^\top t}{t^\top t}, \qquad X \leftarrow X - t\,p^\top, \quad y \leftarrow y - q\,t\]

This is called deflation. What is left of \(X\) is uncorrelated with \(t\).

Step 3: repeat

Find the next weights on what is left, and so on, \(a\) times. At the end, collect the weights in \(W\), the loadings in \(P\) and the coefficients in \(q\). The result is again a linear formula for the original predictors:

\[\hat\beta_{PLS} = W\,(P^\top W)^{-1} q\]

Code 
pls_by_hand <- function(X, y, a) {
  E <- sweep(X, 2, colMeans(X)); f <- y - mean(y)
  W <- P <- matrix(0, ncol(X), a); q <- numeric(a)
  for (k in 1:a) {
    w <- crossprod(E, f); w <- w / sqrt(sum(w^2))      # step 1: weights
    t <- E %*% w                                       #         scores
    q[k] <- sum(f * t) / sum(t^2)                      # step 2: regress y and X on the scores ...
    p <- crossprod(E, t) / sum(t^2)
    E <- E - t %*% t(p); f <- f - t * q[k]             #         ... and deflate
    W[, k] <- w; P[, k] <- p
  }
  beta <- drop(W %*% solve(crossprod(P, W), q))        # step 3
  list(beta = beta, intercept = mean(y) - sum(colMeans(X) * beta))
}
by_hand <- pls_by_hand(meat$nir[train, ], meat$fat[train], 5)
package <- plsr(fat ~ nir, ncomp = 5, data = meat[train, ], method = "oscorespls")
max(abs(by_hand$beta - drop(coef(package, ncomp = 5)))) / max(abs(by_hand$beta))

Our loop gives the coefficients of plsr().

Step 4: how many components?

With few components PLS is stiff; with as many as there are predictors it is least squares. The number is chosen by cross-validation.

4. Choosing the number of components

The folds are made of meats, not of samples, so that twins are never on both sides. We repeat the random division 20 times and average:

Code 
group <- match(content[train], unique(content[train])) # one number for each different meat
grouped_cv <- function(Z, y, ncomp, fitter = plsr, reps = 20) {
  set.seed(31)
  rowMeans(replicate(reps, {
    fold <- sample(rep(1:10, length.out = max(group)))[group]
    err <- matrix(NA, length(y), ncomp)
    for (k in 1:10) {
      d <- data.frame(y = y[fold != k])
      d$Z <- Z[fold != k, ]
      m <- fitter(y ~ Z, ncomp = ncomp, data = d)
      err[fold == k, ] <- drop(predict(m, newdata = list(Z = Z[fold == k, , drop = FALSE]))) -
        y[fold == k]
    }
    sqrt(colMeans(err^2))
  }))
}

The number of components is not the number of parameters

A PLS component was fitted to \(y\) twice: once when its weights were chosen, and once in the regression. So PLS with 14 components is more flexible than a regression with 14 predictors. The curve above shows it: after its minimum, the error of PLS rises faster than that of PCR.

5. Preprocessing: remove what is not about fat

The height of a spectrum is a nuisance that we understand: it comes from the path of the light, not from the chemistry. Chemists remove it before the regression. The standard normal variate transformation (SNV; Barnes et al., 1989) standardises each spectrum by itself (subtract its mean, divide by its standard deviation). Differences between neighbouring wavelengths (derivatives) remove slopes and bends of the background:

\[x_{ij}^{SNV} = \frac{x_{ij} - \bar x_i}{s_i}\]

Coefficients and importance: which wavelengths?

The coefficients say how the prediction changes with each wavelength. Because the wavelengths are so strongly related, single coefficients mean little, but their pattern can be read. The VIP (variable importance in projection) summarises how much each wavelength contributes to the weights, counted by how much of \(y\) each component explains. Its mean square is 1, so values above 1 are “above average”:

\[\text{VIP}_j = \sqrt{ m \sum_{k=1}^{a} \text{SS}_k\, w_{jk}^2 \Big/ \sum_{k=1}^{a} \text{SS}_k }, \qquad \text{SS}_k = q_k^2\, t_k^\top t_k\]

Code 
vip <- function(m, a) {
  w  <- apply(unclass(m$loading.weights)[, 1:a, drop = FALSE], 2, function(v) v / sqrt(sum(v^2)))
  ss <- sapply(1:a, function(k) m$Yloadings[k]^2 * sum(m$scores[, k]^2))
  sqrt(nrow(w) * drop(w^2 %*% ss) / sum(ss))
}

10. Things to keep in mind

  • Think about the preprocessing first. Removing known nuisances helped more than any choice of components. But decide on it with the training data only, inside the cross-validation, if it has settings to choose.
  • Standardise the columns when the predictors are in different units (scale = TRUE). For spectra, where all the columns are absorbances, it is usually not done: it would give the flat, noisy regions as much weight as the informative ones.
  • Cross-validate by the unit that is independent: meats, patients, days, not single measurements.
  • Report the number of components, and why. Taking the smallest model whose error is close to the minimum is wiser than taking the minimum.
  • Do not read single coefficients, and do not select wavelengths by them without validation.
  • PLS is linear. For bends, transform the predictors, add squares, or use a nonlinear method.
  • Outcomes with two classes: PLS on a 0/1 outcome (PLS-DA) always separates the classes in the training data when there are many predictors, even if they are random. The score plot of PLS-DA proves nothing without cross-validation.
  • Not the same as PLS path modelling (PLS-SEM), which estimates networks of composites and has its own rules.

## The question: reading fat with light

How much fat is in this minced meat? The chemical analysis takes hours and destroys the sample. Light takes seconds. Shine near-infrared light of 100 different wavelengths through the meat, and measure how much of each is absorbed. Water, fat and protein absorb different wavelengths, so the **spectrum** contains the answer. But not at any single wavelength: everything overlaps.

So we need a regression of the fat content on 100 predictors, and it has every problem at once:

- 100 predictors for 172 samples;
- neighbouring wavelengths that correlate above .99;
- what varies most in the spectra (how tightly the meat is packed, how it scatters the light) has little to do with fat.

The last point is the one that hurts [principal components regression](EXAMPLE_PRINCIPAL_COMPONENTS_REGRESSION.Rmd), which picks its components by variance and does not look at the outcome. **Partial least squares** (PLS) looks at it. It builds components that vary **and** go with the outcome. It is the standard method of chemistry for this problem (Wold et al., 2001), and it is used wherever there are many correlated predictors.

## 3. The method step by step, with formulas

### Step 1: one component

We look for a weighted sum of the (centred) predictors, $t = Xw$, with weights of length 1. Principal components analysis maximises the variance of $t$. PLS maximises its **covariance with the outcome**:

$$w = \arg\max_{\lVert w \rVert = 1} \text{Cov}(Xw,\, y)^2 = \arg\max_{\lVert w \rVert = 1} \text{Var}(Xw)\,\text{Cor}(Xw, y)^2\;\text{Var}(y)$$

The component must vary **and** correlate with $y$. The solution is simple: the weight of each wavelength is proportional to its covariance with $y$.

$$w = \frac{X^\top y}{\lVert X^\top y \rVert}$$

### Step 2: use it, and take it away

Regress $y$ on the score $t$ (coefficient $q$), and every column of $X$ on the score $t$ (coefficients $p$, the **loadings**). Subtract what has been explained, from both:

$$q = \frac{y^\top t}{t^\top t}, \quad p = \frac{X^\top t}{t^\top t}, \qquad X \leftarrow X - t\,p^\top, \quad y \leftarrow y - q\,t$$

This is called **deflation**. What is left of $X$ is uncorrelated with $t$.

### Step 3: repeat

Find the next weights on what is left, and so on, $a$ times. At the end, collect the weights in $W$, the loadings in $P$ and the coefficients in $q$. The result is again a linear formula for the original predictors:

$$\hat\beta_{PLS} = W\,(P^\top W)^{-1} q$$

```{r by_hand}
pls_by_hand <- function(X, y, a) {
  E <- sweep(X, 2, colMeans(X)); f <- y - mean(y)
  W <- P <- matrix(0, ncol(X), a); q <- numeric(a)
  for (k in 1:a) {
    w <- crossprod(E, f); w <- w / sqrt(sum(w^2))      # step 1: weights
    t <- E %*% w                                       #         scores
    q[k] <- sum(f * t) / sum(t^2)                      # step 2: regress y and X on the scores ...
    p <- crossprod(E, t) / sum(t^2)
    E <- E - t %*% t(p); f <- f - t * q[k]             #         ... and deflate
    W[, k] <- w; P[, k] <- p
  }
  beta <- drop(W %*% solve(crossprod(P, W), q))        # step 3
  list(beta = beta, intercept = mean(y) - sum(colMeans(X) * beta))
}
by_hand <- pls_by_hand(meat$nir[train, ], meat$fat[train], 5)
package <- plsr(fat ~ nir, ncomp = 5, data = meat[train, ], method = "oscorespls")
max(abs(by_hand$beta - drop(coef(package, ncomp = 5)))) / max(abs(by_hand$beta))
```

Our loop gives the coefficients of `plsr()`.

### Step 4: how many components?

With few components PLS is stiff; with as many as there are predictors it **is** least squares. The number is chosen by cross-validation.

## 4. Choosing the number of components

The folds are made of **meats**, not of samples, so that twins are never on both sides. We repeat the random division 20 times and average:

```{r grouped_cv}
group <- match(content[train], unique(content[train])) # one number for each different meat
grouped_cv <- function(Z, y, ncomp, fitter = plsr, reps = 20) {
  set.seed(31)
  rowMeans(replicate(reps, {
    fold <- sample(rep(1:10, length.out = max(group)))[group]
    err <- matrix(NA, length(y), ncomp)
    for (k in 1:10) {
      d <- data.frame(y = y[fold != k])
      d$Z <- Z[fold != k, ]
      m <- fitter(y ~ Z, ncomp = ncomp, data = d)
      err[fold == k, ] <- drop(predict(m, newdata = list(Z = Z[fold == k, , drop = FALSE]))) -
        y[fold == k]
    }
    sqrt(colMeans(err^2))
  }))
}
```

## 5. Preprocessing: remove what is not about fat

The height of a spectrum is a nuisance that we understand: it comes from the path of the light, not from the chemistry. Chemists remove it before the regression. The **standard normal variate** transformation (SNV; Barnes et al., 1989) standardises each spectrum **by itself** (subtract its mean, divide by its standard deviation). Differences between neighbouring wavelengths (**derivatives**) remove slopes and bends of the background:

$$x_{ij}^{SNV} = \frac{x_{ij} - \bar x_i}{s_i}$$


```{r test_chart, fig.height = 5.5}
  fat - predicted ~ predicted + I(predicted^2),

```

The points follow the line, with a slight **bend**: the model predicts too little in the middle and too much at the ends (the quadratic term of the residuals has *t* = `r f1(curvature[["t value"]])`). The relation between absorbance and concentration is not exactly linear, and a linear method can only approximate it. This is what nonlinear methods, such as [neural networks](EXAMPLE_NEURAL_NETWORK.Rmd), gain on these data (Borggaard & Thodberg, 1992).

### Coefficients and importance: which wavelengths?

The coefficients say how the prediction changes with each wavelength. Because the wavelengths are so strongly related, single coefficients mean little, but their **pattern** can be read. The **VIP** (variable importance in projection) summarises how much each wavelength contributes to the weights, counted by how much of $y$ each component explains. Its mean square is 1, so values above 1 are "above average":

$$\text{VIP}_j = \sqrt{ m \sum_{k=1}^{a} \text{SS}_k\, w_{jk}^2 \Big/ \sum_{k=1}^{a} \text{SS}_k }, \qquad \text{SS}_k = q_k^2\, t_k^\top t_k$$

```{r vip}
vip <- function(m, a) {
  w  <- apply(unclass(m$loading.weights)[, 1:a, drop = FALSE], 2, function(v) v / sqrt(sum(v^2)))
  ss <- sapply(1:a, function(k) m$Yloadings[k]^2 * sum(m$scores[, k]^2))
  sqrt(nrow(w) * drop(w^2 %*% ss) / sum(ss))
}
pattern <- data.frame(wavelength = rep(wavelength, 2),
                      value = c(drop(coef(model, ncomp = 3)), vip(model, 3)),
                      what = rep(c("coefficient", "VIP"), each = 100))
ggplot(pattern, aes(wavelength, value)) +
  geom_hline(
    data = data.frame(what = c("coefficient", "VIP"), y = c(0, 1)),
    aes(yintercept = y),
    colour = "grey60"
  ) +
  geom_line(colour = "#2a78d6", linewidth = 0.9) +
  facet_wrap(~what, ncol = 1, scales = "free_y") +
  labs(title = "Coefficients and importance of the wavelengths", x = "wavelength (nm)", y = NULL) +
  theme_bw()
top <- wavelength[which.max(vip(model, 3))]
```

The largest positive coefficients are around `r round(top_coef)` nm, in the region where fat absorbs. It is a good sign when a model that was never told any chemistry finds it.

## 8. Three outcomes at once: PLS2

PLS can have several outcomes. The weights are then those that maximise the covariance with **all** of them together. Water, fat and protein are strongly related: whatever is not fat is mostly water.

```{r pls2}
contents <- as.matrix(meat[, c("water", "fat", "protein")])
round(cor(contents[train, ]), 2)
many <- data.frame(row.names = seq_len(sum(train)))
many$Y <- contents[train, ]
many$Z <- versions$SNV[train, ]
pls2 <- plsr(Y ~ Z, ncomp = 8, data = many)
one_by_one <- sapply(1:3, function(j) {
  d <- data.frame(y = contents[train, j])
  d$Z <- versions$SNV[train, ]
  rmse(
    drop(predict(
      plsr(y ~ Z, ncomp = 8, data = d),
      newdata = list(Z = versions$SNV[no_twin, ]),
      ncomp = 8
    )),
    contents[no_twin, j]
  )
})
together <- predict(pls2, newdata = list(Z = versions$SNV[no_twin, ]), ncomp = 8)[, , 1]
compare <- rbind(
  separate = one_by_one,
  together = sapply(1:3, function(j) rmse(together[, j], contents[no_twin, j]))
)
colnames(compare) <- colnames(contents)
round(compare, 2)
```

Together or separately makes little difference here. PLS2 is useful when the outcomes are noisy measurements of a few common things; when they are different things, separate models are better.

## 10. Things to keep in mind

- **Think about the preprocessing first.** Removing known nuisances helped more than any choice of components. But decide on it with the training data only, inside the cross-validation, if it has settings to choose.
- **Standardise the columns** when the predictors are in different units (`scale = TRUE`). For spectra, where all the columns are absorbances, it is usually not done: it would give the flat, noisy regions as much weight as the informative ones.
- **Cross-validate by the unit that is independent**: meats, patients, days, not single measurements.
- **Report the number of components, and why.** Taking the smallest model whose error is close to the minimum is wiser than taking the minimum.
- **Do not read single coefficients**, and do not select wavelengths by them without validation.
- **PLS is linear.** For bends, transform the predictors, add squares, or use a nonlinear method.
- **Outcomes with two classes**: PLS on a 0/1 outcome (PLS-DA) always separates the classes in the training data when there are many predictors, even if they are random. The score plot of PLS-DA proves nothing without cross-validation.
- **Not the same** as *PLS path modelling* (PLS-SEM), which estimates networks of composites and has its own rules.

## 12. Summary

| | |
|---|---|
| **When** | Many correlated predictors, perhaps more than rows, and the aim is prediction |
| **Component** | $t = Xw$ with maximal covariance with $y$; $w \propto X^\top y$ |
| **Then** | Deflate $X$ and $y$, repeat; $\hat\beta = W(P^\top W)^{-1}q$ |
| **How (R)** | `pls::plsr(y ~ X, ncomp = , data = , scale = , validation = )` |
| **Choose** | The number of components, by cross-validation in independent units |
| **Against PCR** | Fewer components, about the same error |
| **Interpretation** | Scores (a map of the samples), patterns of coefficients, VIP |
| **Several outcomes** | `plsr(cbind(y1, y2) ~ X)` (PLS2) |
| **Limits** | Linear; no extrapolation; in-sample fit means nothing with many predictors |
