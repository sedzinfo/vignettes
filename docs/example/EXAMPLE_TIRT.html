Load

Code 
library(thurstonianIRT)

The model is the Thurstonian IRT model of Brown and Maydeu-Olivares (2011), fitted with the thurstonianIRT package (Bürkner, Schulte & Holling, 2019).

The data

Forced-choice rankings must be expressed as binary pairwise outcomes: for each pair {i, k} in a block, y = 1 if item i is preferred to item k and 0 otherwise (Brown & Maydeu-Olivares, 2011). In the examples below, rank 1 denotes the most preferred item. The triplets data are already in this pairwise format; raw ranks could instead be passed to make_TIRT_data(..., format = "ranks", direction = "smaller"), which performs this recoding automatically.

## The data

Forced-choice rankings must be expressed as binary pairwise outcomes: for each pair {i, k} in a block, y = 1 if item i is preferred to item k and 0 otherwise (Brown & Maydeu-Olivares, 2011).
In the examples below, rank 1 denotes the most preferred item.
The `triplets` data are already in this pairwise format; raw ranks could instead be passed to `make_TIRT_data(..., format = "ranks", direction = "smaller")`, which performs this recoding automatically.

### Example 1

| Rank | Rank | Rank | 
|------|------|------|
| A    | B    | C    |
| 1    | 2    | 3    |

| binary | binary | binary | 
|--------|--------|--------|
| {A, B} | {A, C} | {B, C} |
|   1    |    1   |   1    |


### Example 2
