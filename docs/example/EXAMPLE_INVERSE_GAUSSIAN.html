Inverse Gaussian Regression: How Much Faster Do We Recognise Common Words?

  • Show All Code
  • Hide All Code
  • View Source
Inverse Gaussian regression in R with glm() and lme4, on reaction times in a lexical decision task: the distribution of the time to reach a threshold, a variance that grows with the cube of the mean, identity against log link, why transforming reaction times changes interactions, comparison with the normal, gamma and log-normal, mixed models with crossed subjects and words, checks and APA reporting.

The question: milliseconds

You see a string of letters and must press a button as fast as you can: is it a word or not? Cat takes less time than vole. The more frequent a word is in the language, the faster we recognise it. By how many milliseconds? And is the gain larger for people who learned English as a foreign language?

Reaction times are the daily bread of experimental psychology, and they have an awkward distribution: always positive, with a long tail to the right, and more variable when they are slower. The usual remedy is to transform them (the logarithm, or \(-1/RT\)) until they look normal, and to run a linear model. But a transformed time is no longer a time. “The logarithm is 0.03 smaller” is not an answer to “how many milliseconds?”. Worse: an interaction that exists in milliseconds may vanish in logarithms, and the other way round (Lo & Andrews, 2015).

A generalized linear model does not transform the data. It chooses a distribution that has the right shape, and keeps the mean in milliseconds. The inverse Gaussian is such a distribution, and it comes with a theory of what a reaction time is.

3. The model step by step, with formulas

Step 1: a story about a decision

Imagine that the brain collects evidence. It starts at zero, drifts upwards with speed \(v\), and shakes randomly on the way. When it reaches a threshold \(a\), the button is pressed. The time of the first passage through the threshold has an inverse Gaussian distribution (also called the Wald distribution; Folks & Chhikara, 1978), with

\[\mu = \frac{a}{v} \;\text{(mean)}, \qquad \lambda = a^2 \;\text{(shape)}\]

A simulation of such random walks:

Code 
set.seed(101)
v <- 0.1
a <- 30
steps <- 1500 # drift per millisecond, threshold
walk <- function() {
  w <- cumsum(v + rnorm(steps))
  hit <- which(w >= a)[1]
  list(path = w, time = hit)
}
times <- replicate(4000, walk()$time)
few <- do.call(
  rbind,
  lapply(1:6, function(i) {
    w <- walk()
    n <- if (is.na(w$time)) steps else w$time
    data.frame(walk = i, t = 1:n, x = w$path[1:n])
  })
)
pa <- ggplot(few, aes(t, x, group = walk, colour = factor(walk))) +
  geom_line(linewidth = 0.4) +
  geom_hline(yintercept = a, linetype = "dashed") +
  guides(colour = "none") +
  labs(title = "Six decisions: evidence until the threshold", x = "milliseconds", y = "evidence") +
  theme_bw()

  sqrt(lambda / (2 * pi * x^3)) * exp(-lambda * (x - mu)^2 / (2 * mu^2 * x))

Step 2: the variance

\[E(y) = \mu, \qquad \text{Var}(y) = \frac{\mu^3}{\lambda} = \phi\,\mu^3\]

The variance grows with the cube of the mean. Compare: constant for the normal, \(\mu\) for Poisson, \(\mu^2\) for the gamma, \(\mu^3\) for the inverse Gaussian. Slow conditions are much more variable, and have a longer tail.

Step 3: the mean, and its link

\[\mu_i = x_i^\top\beta \;\;\text{(identity link)} \qquad\text{or}\qquad \log\mu_i = x_i^\top\beta \;\;\text{(log link)}\]

With the identity link, effects are in milliseconds and add up. With the log link they are percentages and multiply. (The textbook link is \(1/\mu^2\), which nobody can read.) The choice is about how effects combine, and it decides what “no interaction” means.

Step 4: the weights

The likelihood equations weight each observation by the inverse of its variance, \(1/\mu^3\). The slow, noisy conditions count less. By hand, for the identity link, this is a repeated weighted least squares:

Code 
X <- model.matrix(~ freq * foreign, data = words); y <- words$rt
beta <- coef(lm(rt ~ freq * foreign, data = words))                    # start from OLS
for (it in 1:50) {
  mu <- drop(X %*% beta)
  new <- coef(lm.wfit(X, y, w = 1 / mu^3)) # identity link: plain weighted least squares
  if (max(abs(new - beta)) < 1e-9) {
    break
  }
  beta <- new
}
fit <- glm(
  rt ~ freq * foreign,
  family = inverse.gaussian(link = "identity"),
  data = words,
  start = coef(lm(rt ~ freq * foreign, data = words))
)
rbind(by_hand = beta, glm = coef(fit))
        (Intercept)      freq  foreign freq:foreign
by_hand    568.8714 -19.77006 99.88254    -20.07592
glm        568.8714 -19.77006 99.88244    -20.07548

(glm() needs starting values with the identity link. The coefficients of OLS are good ones.)

In milliseconds the interaction is clear, t = -3.3. On the log scale it is weaker, t = -3.0, and for the reciprocal weaker again, t = -2.3. It is the same data. Slow people have larger differences of every kind, in milliseconds. A transformation that compresses long times compresses this too. Here the interaction survives; in other data it disappears, or even turns round. So the scale must be chosen for a reason: a theory in milliseconds (stages that add up) needs milliseconds. Whether the times look normal is no argument, because a generalized linear model does not need them to.

6. People and words: a mixed model

Each person answered many times, and each word was answered by many people. Fast people are fast for all words, hard words are hard for everybody. The answers are crossed in subjects and words, and both are samples from larger populations. A generalized linear mixed model has a random intercept for each (Baayen et al., 2008; Lo & Andrews, 2015):

\[\mu_{ij} = x_{ij}^\top\beta + u_i + w_j, \qquad u_i \sim N(0, \sigma_u^2), \quad w_j \sim N(0, \sigma_w^2)\]

Code 
mixed <- glmer(
  rt ~ freq * foreign + (1 | subject) + (1 | word),
  data = words,
  family = inverse.gaussian(link = "identity"),
  control = glmerControl(optimizer = "bobyqa", optCtrl = list(maxfun = 2e5))
)

7. Checking the model

Code 
pig <- function(x, mu, lambda) {
  pnorm(sqrt(lambda / x) * (x / mu - 1)) +
    exp(2 * lambda / mu) * pnorm(-sqrt(lambda / x) * (x / mu + 1))
} # the distribution function
quantile_res <- function(y, mu, phi) qnorm(pmin(pmax(pig(y, mu, 1 / phi), 1e-12), 1 - 1e-12))
phi_m  <- sum(residuals(mixed, type = "pearson")^2) / (nrow(words) - 6)
chk <- rbind(
  data.frame(
    r = quantile_res(words$rt, fitted(fit), phi),
    model = "inverse Gaussian, no random effects"
  ),
  data.frame(r = quantile_res(words$rt, fitted(mixed), phi_m), model = "inverse Gaussian, mixed"),
  data.frame(
    r = rstandard(lm(rt ~ freq * foreign, data = words)),
    model = "normal, no random effects"
  ),
  data.frame(r = as.numeric(scale(resid(linear))), model = "normal, mixed")
)
chk <- do.call(
  rbind,
  lapply(split(chk, chk$model), function(d) cbind(d, q = qqnorm(d$r, plot.it = FALSE)$x))
)
ggplot(chk, aes(q, r)) +
  geom_abline(colour = "grey60") +
  geom_point(alpha = 0.3, size = 0.8, colour = "#2a78d6") +
  facet_wrap(~model) +
  coord_cartesian(ylim = c(-5, 8)) +

    title = "Quantile residuals against the normal distribution",

If the model is right, the points lie on the line. The normal models have a long right tail: 1.5% of the residuals of the mixed normal model are above 3 SD, where 0.13% are expected. The inverse Gaussian models follow the line better over most of the range, and their tail is shorter (1.1% for the mixed one), but still too long: a few very slow answers (lapses of attention) remain. They are usually cut off by a rule that is fixed before looking at the results.

8. Things to keep in mind

  • The theory of the single threshold is a simplification. Reaction times also contain the time to see and to press. Adding a constant gives the shifted Wald, and a normal or exponential part the ex-Wald (Heathcote, 2004). Two thresholds, with errors, lead to the diffusion model.
  • Use it as a convenient shape, not as proof of the theory. The log-normal or the gamma may fit as well in other data.
  • Identity link: watch the sign. Nothing keeps the mean positive. With reaction times it is never a problem; with small means it is.
  • Choose the link and the scale before you see the interaction. An interaction that exists on one scale only is removable: say so, and say which scale your theory speaks.
  • Outliers and cut-offs. Report the rule and how many answers it removed.
  • Errors. We left out wrong answers. If one condition has more of them, speed and accuracy must be analysed together.
  • Random effects for people and items. Averaging over words first, or over people, hides one of the two.
  • Starting values are needed for the identity link. Scale and centre the predictors, or glmer() will not converge.

Method (data analysis):

Reaction times of correct lexical decisions (1,594 answers of 21 participants to 79 words; Baayen, 2008) were analysed with a generalized linear mixed model with an inverse Gaussian distribution and an identity link (Lo & Andrews, 2015), so that effects are in milliseconds. The inverse Gaussian was preferred to the normal, gamma and log-normal distributions by the AIC. Fixed effects were log word frequency (centred), native language (English or other) and their interaction; participants and words had random intercepts. Analyses were conducted in R (Version 4.6.2; R Core Team, 2026) with the package lme4 (Bates et al., 2015).

Results:

Native speakers recognised words of average frequency in 568 ms. They also gained more from frequency, b = -18.6 ms, SE = 4.1, z = -4.51, p < .001 (Table 1). The interaction had the same sign on the log scale (t = -4.22).

## The question: milliseconds

You see a string of letters and must press a button as fast as you can: is it a word or not? *Cat* takes less time than *vole*. The more **frequent** a word is in the language, the faster we recognise it. By how many milliseconds? And is the gain larger for people who learned English as a foreign language?

Reaction times are the daily bread of experimental psychology, and they have an awkward distribution: always positive, with a long tail to the right, and more variable when they are slower. The usual remedy is to transform them (the logarithm, or $-1/RT$) until they look normal, and to run a linear model. But a transformed time is no longer a time. "The logarithm is 0.03 smaller" is not an answer to "how many milliseconds?". Worse: **an interaction that exists in milliseconds may vanish in logarithms**, and the other way round (Lo & Andrews, 2015).

A **generalized linear model** does not transform the data. It chooses a distribution that has the right shape, and keeps the **mean in milliseconds**. The **inverse Gaussian** is such a distribution, and it comes with a theory of what a reaction time is.

## 3. The model step by step, with formulas

### Step 1: a story about a decision

Imagine that the brain collects evidence. It starts at zero, drifts upwards with speed $v$, and shakes randomly on the way. When it reaches a threshold $a$, the button is pressed. The time of the **first passage** through the threshold has an **inverse Gaussian** distribution (also called the Wald distribution; Folks & Chhikara, 1978), with

$$\mu = \frac{a}{v} \;\text{(mean)}, \qquad \lambda = a^2 \;\text{(shape)}$$

A simulation of such random walks:

```{r walks}
set.seed(101)
v <- 0.1
a <- 30
steps <- 1500 # drift per millisecond, threshold
walk <- function() {
  w <- cumsum(v + rnorm(steps))
  hit <- which(w >= a)[1]
  list(path = w, time = hit)
}
times <- replicate(4000, walk()$time)
few <- do.call(
  rbind,
  lapply(1:6, function(i) {
    w <- walk()
    n <- if (is.na(w$time)) steps else w$time
    data.frame(walk = i, t = 1:n, x = w$path[1:n])
  })
)
pa <- ggplot(few, aes(t, x, group = walk, colour = factor(walk))) +
  geom_line(linewidth = 0.4) +
  geom_hline(yintercept = a, linetype = "dashed") +
  guides(colour = "none") +
  labs(title = "Six decisions: evidence until the threshold", x = "milliseconds", y = "evidence") +
  theme_bw()
dig <- function(x, mu, lambda) {
  sqrt(lambda / (2 * pi * x^3)) * exp(-lambda * (x - mu)^2 / (2 * mu^2 * x))
} # the density
curve_data <- data.frame(t = 10:1200); curve_data$d <- dig(curve_data$t, a / v, a^2)
pb <- ggplot(data.frame(times), aes(times)) +
  geom_histogram(
    aes(y = after_stat(density)),
    binwidth = 25,
    fill = "grey80",
    colour = "white",
    na.rm = TRUE
  ) +
  geom_line(data = curve_data, aes(t, d), colour = "#eb6834", linewidth = 1) +
  labs(
    title = "4,000 such times, and the inverse Gaussian density",
    x = "milliseconds",
    y = "density"
  ) +
  theme_bw()
patchwork::wrap_plots(pa, pb, ncol = 1)
c(mean_of_simulation = mean(times, na.rm = TRUE), theory = a / v)
```

### Step 2: the variance

$$E(y) = \mu, \qquad \text{Var}(y) = \frac{\mu^3}{\lambda} = \phi\,\mu^3$$

The variance grows with the **cube** of the mean. Compare: constant for the normal, $\mu$ for Poisson, $\mu^2$ for the gamma, $\mu^3$ for the inverse Gaussian. Slow conditions are much more variable, and have a longer tail.

### Step 3: the mean, and its link

$$\mu_i = x_i^\top\beta \;\;\text{(identity link)} \qquad\text{or}\qquad \log\mu_i = x_i^\top\beta \;\;\text{(log link)}$$

With the **identity** link, effects are in milliseconds and add up. With the **log** link they are percentages and multiply. (The textbook link is $1/\mu^2$, which nobody can read.) The choice is about **how effects combine**, and it decides what "no interaction" means.

### Step 4: the weights

The likelihood equations weight each observation by the inverse of its variance, $1/\mu^3$. The slow, noisy conditions count less. By hand, for the identity link, this is a repeated weighted least squares:

```{r by_hand}
X <- model.matrix(~ freq * foreign, data = words); y <- words$rt
beta <- coef(lm(rt ~ freq * foreign, data = words))                    # start from OLS
for (it in 1:50) {
  mu <- drop(X %*% beta)
  new <- coef(lm.wfit(X, y, w = 1 / mu^3)) # identity link: plain weighted least squares
  if (max(abs(new - beta)) < 1e-9) {
    break
  }
  beta <- new
}
fit <- glm(
  rt ~ freq * foreign,
  family = inverse.gaussian(link = "identity"),
  data = words,
  start = coef(lm(rt ~ freq * foreign, data = words))
)
rbind(by_hand = beta, glm = coef(fit))
```

(`glm()` needs starting values with the identity link. The coefficients of OLS are good ones.)

```{r fit}

```

- **`(Intercept)`**: `r f0(b[[1]])` ms, the mean for a native speaker and a word of average frequency.
- **`freq`**: `r f1(b[["freq"]])`: for native speakers, each unit of log frequency saves `r f1(abs(b[["freq"]]))` ms.
- **`foreign`**: the others are `r f0(b[["foreign"]])` ms slower at average frequency.
- **`freq:foreign`**: `r f1(b[["freq:foreign"]])`: for them, one unit of frequency saves `r f1(abs(b[["freq:foreign"]]))` ms **more**, that is `r f1(abs(b[["freq"]] + b[["freq:foreign"]]))` ms in all.
- **`Dispersion`** = `r formatC(phi, format = "e", digits = 2)`: $\phi = 1/\lambda$. The predicted SD at a mean of $\mu$ is $\sqrt{\phi\mu^3}$: `r f0(sqrt(phi * 500^3))` ms at 500 ms and `r f0(sqrt(phi * 700^3))` ms at 700 ms.

These standard errors treat the `r num(nrow(words))` answers as independent. They are not, and section 6 repairs that. First, the distribution.

The inverse Gaussian describes the reaction times best, then the log-normal and the gamma, and the normal distribution is far behind: an AIC `r f0(aics[["normal, identity"]] - aics[["inverse Gaussian, identity"]])` points larger. Between the two links there is little to choose.

### The interaction depends on the scale

Does frequency help the foreign speakers more? Ask in four ways:

```{r scales}

  `milliseconds (inverse Gaussian, identity)` = s["freq:foreign", 1:4],
  `ratios (inverse Gaussian, log link)` = coef(summary(fams[[4]]))["freq:foreign", 1:4],

round(int, 4)
```

In milliseconds the interaction is clear, *t* = `r f1(int[1, "t"])`. On the log scale it is weaker, *t* = `r f1(int[3, "t"])`, and for the reciprocal weaker again, *t* = `r f1(int[4, "t"])`. It is the **same data**. Slow people have larger differences of every kind, in milliseconds. A transformation that compresses long times compresses this too. Here the interaction survives; in other data it disappears, or even turns round. So the scale must be chosen for a **reason**: a theory in milliseconds (stages that add up) needs milliseconds. Whether the times look normal is no argument, because a generalized linear model does not need them to.

## 6. People and words: a mixed model

Each person answered many times, and each word was answered by many people. Fast people are fast for all words, hard words are hard for everybody. The answers are **crossed** in subjects and words, and both are samples from larger populations. A generalized linear **mixed** model has a random intercept for each (Baayen et al., 2008; Lo & Andrews, 2015):

$$\mu_{ij} = x_{ij}^\top\beta + u_i + w_j, \qquad u_i \sim N(0, \sigma_u^2), \quad w_j \sim N(0, \sigma_w^2)$$

```{r mixed}
mixed <- glmer(
  rt ~ freq * foreign + (1 | subject) + (1 | word),
  data = words,
  family = inverse.gaussian(link = "identity"),
  control = glmerControl(optimizer = "bobyqa", optCtrl = list(maxfun = 2e5))
)
sm <- coef(summary(mixed))
round(sm, 4)
VarCorr(mixed)
```

```{r mixed_compare}
compare <- data.frame(

print(cbind(term = compare$term, round(compare[, -1], 2)), row.names = FALSE)
```

- The difference between the two language groups is about the same (`r f0(sm["foreign", 1])` ms), but its standard error is `r f1(sm["foreign", 2] / s["foreign", 2])` times as large: it compares `r sum(tapply(words$foreign, words$subject, mean) == 0)` with `r sum(tapply(words$foreign, words$subject, mean) == 1)` **people**, not hundreds of answers. The *t* falls from `r f1(t_lang[["glm"]])` to `r f1(t_lang[["mixed"]])`.
- The effect of frequency compares **words**: its standard error grows a little.
- The interaction is a comparison **within** people and words, and it becomes **more** precise, because the mixed model removes their differences: *SE* `r f1(sm["freq:foreign", 2])` instead of `r f1(s["freq:foreign", 2])`.
- People differ by an SD of `r f0(attr(VarCorr(mixed)$subject, "stddev"))` ms, words by `r f0(attr(VarCorr(mixed)$word, "stddev"))` ms.

The standard errors of `glmer()` with this family are known to be rough, and Lo and Andrews recommend it nevertheless for the fit. With only 21 people, treat a *z* of 2 as weak evidence. Random slopes (a personal effect of frequency) would be the next step.

## 7. Checking the model

```{r checks, fig.height = 6}
pig <- function(x, mu, lambda) {
  pnorm(sqrt(lambda / x) * (x / mu - 1)) +
    exp(2 * lambda / mu) * pnorm(-sqrt(lambda / x) * (x / mu + 1))
} # the distribution function
quantile_res <- function(y, mu, phi) qnorm(pmin(pmax(pig(y, mu, 1 / phi), 1e-12), 1 - 1e-12))
phi_m  <- sum(residuals(mixed, type = "pearson")^2) / (nrow(words) - 6)
chk <- rbind(
  data.frame(
    r = quantile_res(words$rt, fitted(fit), phi),
    model = "inverse Gaussian, no random effects"
  ),
  data.frame(r = quantile_res(words$rt, fitted(mixed), phi_m), model = "inverse Gaussian, mixed"),
  data.frame(
    r = rstandard(lm(rt ~ freq * foreign, data = words)),
    model = "normal, no random effects"
  ),
  data.frame(r = as.numeric(scale(resid(linear))), model = "normal, mixed")
)
chk <- do.call(
  rbind,
  lapply(split(chk, chk$model), function(d) cbind(d, q = qqnorm(d$r, plot.it = FALSE)$x))
)
ggplot(chk, aes(q, r)) +
  geom_abline(colour = "grey60") +
  geom_point(alpha = 0.3, size = 0.8, colour = "#2a78d6") +
  facet_wrap(~model) +
  coord_cartesian(ylim = c(-5, 8)) +
  labs(
    title = "Quantile residuals against the normal distribution",
    x = "normal quantile",
    y = "residual"
  ) +
  theme_bw()
tail_share <- tapply(chk$r, chk$model, function(v) mean(v > 3))
cbind(percent_above_3_SD = round(100 * tail_share, 2))
```

If the model is right, the points lie on the line. The normal models have a long right tail: `r f1(100 * tail_share[["normal, mixed"]])`% of the residuals of the mixed normal model are above 3 SD, where 0.13% are expected. The inverse Gaussian models follow the line better over most of the range, and their tail is shorter (`r f1(100 * tail_share[["inverse Gaussian, mixed"]])`% for the mixed one), but still too long: a few very slow answers (lapses of attention) remain. They are usually cut off by a rule that is fixed **before** looking at the results.

## 8. Things to keep in mind

- **The theory of the single threshold** is a simplification. Reaction times also contain the time to see and to press. Adding a constant gives the *shifted Wald*, and a normal or exponential part the *ex-Wald* (Heathcote, 2004). Two thresholds, with errors, lead to the diffusion model.
- **Use it as a convenient shape**, not as proof of the theory. The log-normal or the gamma may fit as well in other data.
- **Identity link: watch the sign.** Nothing keeps the mean positive. With reaction times it is never a problem; with small means it is.
- **Choose the link and the scale before you see the interaction.** An interaction that exists on one scale only is *removable*: say so, and say which scale your theory speaks.
- **Outliers and cut-offs.** Report the rule and how many answers it removed.
- **Errors.** We left out wrong answers. If one condition has more of them, speed and accuracy must be analysed together.
- **Random effects** for people **and** items. Averaging over words first, or over people, hides one of the two.
- **Starting values** are needed for the identity link. Scale and centre the predictors, or `glmer()` will not converge.

**Method** (data analysis):

> Reaction times of correct lexical decisions (`r num(nrow(words))` answers of `r length(unique(words$subject))` participants to `r length(unique(words$word))` words; Baayen, 2008) were analysed with a generalized linear mixed model with an inverse Gaussian distribution and an identity link (Lo & Andrews, 2015), so that effects are in milliseconds. Fixed effects were log word frequency (centred), native language (English or other) and their interaction; participants and words had random intercepts. **Results:**

> Native speakers recognised words of average frequency in `r f0(sm[1, 1])` ms. More frequent words were recognised faster, *b* = `r f1(sm["freq", 1])` ms per log unit, *SE* = `r f1(sm["freq", 2])`, *z* = `r f2(sm["freq", 3])`, *p* `r pval(sm["freq", 4])`, and participants with another native language were slower, *b* = `r f1(sm["foreign", 1])` ms, *SE* = `r f1(sm["foreign", 2])`, *z* = `r f2(sm["foreign", 3])`, *p* `r pval(sm["foreign", 4])`. They also gained more from frequency, *b* = `r f1(sm["freq:foreign", 1])` ms, *SE* = `r f1(sm["freq:foreign", 2])`, *z* = `r f2(sm["freq:foreign", 3])`, *p* `r pval(sm["freq:foreign", 4])` (Table 1). The interaction had the same sign on the log scale (*t* = `r f2(t_int[["log_normal"]])`).

## 10. Summary

| | |
|---|---|
| **When** | Positive, right-skewed outcomes whose variance grows very fast with the mean: reaction times, times to a threshold |
| **The distribution** | Time of the first passage of a drifting random walk; $\text{Var} = \phi\mu^3$ |
| **How (R)** | `glm(y ~ x, family = inverse.gaussian("identity"), start = ...)`; mixed: `lme4::glmer()` |
| **Links** | Identity: milliseconds that add; log: ratios that multiply |
| **Against transforming** | Keeps the mean and the unit; interactions depend on the scale |
| **Against the gamma** | The variance grows with $\mu^3$ instead of $\mu^2$ |
| **Checks** | Quantile residuals, AIC against gamma and log-normal |
| **Related pages** | [Gamma regression](EXAMPLE_GAMMA.Rmd), [multilevel models](EXAMPLE_MULTILEVEL.Rmd), [generalized linear models](EXAMPLE_GENERALIZED.rmd) |
