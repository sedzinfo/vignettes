Regression Discontinuity: Does Winning by a Hair Help You Win Again?

  • Show All Code
  • Hide All Code
  • View Source
Regression discontinuity in R on 1,390 elections to the US Senate: why a narrow win is like a coin toss, comparing means in a window, local linear regression by hand with the triangular kernel, the same numbers as rdrobust, how the bandwidth trades bias against noise, robust bias-corrected intervals and what they are, the density test by hand and with rddensity, placebo outcomes, placebo cutoffs and the donut, why global polynomials are a bad idea, a simulation of the coverage of the intervals, what the number means, and APA reporting.

The question: a win by a hair

A party that holds a seat has a better chance to keep it. Is that because it holds the seat: more press, more donations, more favours? Or because it holds the seat where people like the party anyway? The states that the Democrats won and the states that they lost differ in everything. Comparing them says nothing about the seat itself.

But some elections were very close. A party that won by 0.3 points and a party that lost by 0.3 points had about the same voters, the same year and the same kind of candidates. Rain in one city, and the result would have been the other way round. At the cutoff of zero, winning is close to a coin toss. So compare those who just won with those who just lost (Lee, 2008).

The design is called regression discontinuity (RD). It works whenever a treatment is given by a threshold in a running variable (score, age, income, votes) that nobody controls exactly. Thistlethwaite and Campbell (1960) invented it to find out what a certificate of merit, given to pupils above a test score, does for their further way.

3. The model step by step, with formulas

Step 1: what is estimated

Write \(Y(1)\) for the next share if the party wins now, \(Y(0)\) if it loses, and \(X\) for the margin. If both average curves are continuous at the cutoff, then

\[\tau = E[Y(1) - Y(0) \mid X = 0] = \lim_{x \downarrow 0} E[Y \mid X = x] - \lim_{x \uparrow 0} E[Y \mid X = x]\]

Nothing is assumed about the rest of the line. The effect is for elections at the cutoff.

Step 2: a window

The simplest answer: take the elections with a margin below 1 point (or 2, or 5) and compare the two groups with a t test.

Step 3: a line on each side

Better than a narrow window: allow for the slope. Fit a straight line on each side, only with the elections within a bandwidth \(h\), and give more weight to those near the cutoff (triangular kernel):

\[\min \sum_i w_i \left(y_i - \alpha - \tau D_i - \beta x_i - \gamma D_i x_i\right)^2, \qquad w_i = \max(0,\ 1 - |x_i|/h)\]

\(D\) is 1 for a win, and \(\tau\) is the jump. The package chooses \(h\); we take its value (Step 4) and do the rest by hand:

Code 
fit_rd <- rdrobust(s$vote, s$margin)
h <- fit_rd$bws["h", "left"]
local <- function(h, p, d = s) {
  # weighted least squares on each side, p: degree; returns the jump and its robust (HC0) SE
  side <- function(keep) {
    X <- outer(d$margin[keep], 0:p, "^")
    w <- 1 - abs(d$margin[keep]) / h
    A <- solve(crossprod(X, w * X))
    b <- A %*% crossprod(X, w * d$vote[keep])
    e <- drop(d$vote[keep] - X %*% b)
    V <- A %*% crossprod(X * (w * e)) %*% A
    c(b[1], V[1, 1])
  }
  l <- side(d$margin < 0 & d$margin > -h)
  r <- side(d$margin >= 0 & d$margin < h)
  c(jump = r[1] - l[1], SE = sqrt(l[2] + r[2]))
}
z <- subset(s, abs(margin) < h); z$w <- 1 - abs(z$margin) / h
wls <- lm(vote ~ won * margin, z, weights = w)
rbind(
  by_hand = local(h, 1),
  lm_with_weights = c(coef(wls)[["won"]], sqrt(sandwich::vcovHC(wls, type = "HC0")["won", "won"])),
  rdrobust_hc0 = with(
    rdrobust(s$vote, s$margin, h = h, vce = "hc0"),
    c(coef["Conventional", 1], se["Conventional", 1])
  )
)

Step 4: how wide?

A wide bandwidth uses many elections (little noise), but the curve may bend, and the straight line misses the edge (bias). A narrow one is the reverse. The error is roughly

\[\text{MSE}(h) \approx h^4 B^2 + \frac{V}{n h},\]

with \(B\) from the curvature at the cutoff and \(V\) from the scatter there. The best \(h\) is proportional to \((V/(B^2 n))^{1/5}\). rdrobust() estimates \(B\) and \(V\) from the data and finds h = 17.8 points, which keeps 683 elections.

Step 5: the interval that knows about the bias

The best bandwidth for the estimate leaves a bias: at the minimum of the formula above it is exactly half a standard error. So the usual interval (estimate ± 1.96 SE) is centred at the wrong place, and contains the truth in 92% instead of 95% of the samples. Calonico et al. (2014) subtract an estimate of the bias, and add the noise of that estimate to the standard error: the robust bias-corrected interval. It sounds complicated and has a simple core: if the bias is estimated with the same bandwidth, it is exactly the local quadratic fit.

Code 
rb <- rdrobust(s$vote, s$margin, h = h, b = h, vce = "hc0")
rbind(
  local_quadratic_by_hand = local(h, 2),
  rdrobust_robust_same_bandwidth = c(rb$coef["Robust", 1], rb$se["Robust", 1])
)
                                   jump       SE
local_quadratic_by_hand        8.321204 2.057432
rdrobust_robust_same_bandwidth 8.321204 2.057432

By default rdrobust() uses a larger bandwidth for the bias (28.0 points), which is less noisy.

5. Can we believe it?

The assumption (continuity) cannot be tested directly. Four checks come close.

6. What not to do: a global polynomial

Before local regression became common, people fitted a high polynomial in the running variable to all data and read off the jump:

    m <- lm(vote ~ won * poly(margin, p, raw = TRUE), s)
    data.frame(
      degree = p,
      jump = coef(m)[["won"]],
      SE = sqrt(sandwich::vcovHC(m, type = "HC1")["won", "won"])

  })

7. Are the intervals right? A simulation

We make a population that looks like ours: the curve is a polynomial of degree 4 on each side (so the true jump is known), the margins come from the data, the noise is normal. Draw 500 samples and let rdrobust() do everything, bandwidth included.

Code 
sim_rd <- function(degree, reps = 500) {
  ml <- lm(vote ~ poly(margin, degree, raw = TRUE), s, subset = won == 0)
  mr <- lm(vote ~ poly(margin, degree, raw = TRUE), s, subset = won == 1)
  mu <- ifelse(s$won == 1, predict(mr, s), predict(ml, s))

9. Things to keep in mind

  • Draw the plot first. If you cannot see the jump, be careful with the number.
  • Know the rule. Is the threshold applied strictly? Do other things change at the same threshold (another law at age 18)? Then the jump is the effect of all of them.
  • Fuzzy RD: when crossing the threshold only raises the probability of treatment, divide the jump in the outcome by the jump in the treatment. That is instrumental variables at the cutoff: rdrobust(y, x, fuzzy = treatment).
  • Discrete running variables (age in years, whole test points): there is no “just above”; the methods need care.
  • Control variables are not needed. They can shorten the interval (covs =), and must be fixed before the treatment.
  • Report the bandwidth, its selection, the kernel, the number of observations on each side within it, and the robust interval. Show other bandwidths.
  • Power is low: only the observations near the edge count. Here 683 of 1,297.

## The question: a win by a hair

A party that holds a seat has a better chance to keep it. Is that because it **holds** the seat: more press, more donations, more favours? Or because it holds the seat where people like the party anyway? The states that the Democrats won and the states that they lost differ in everything. Comparing them says nothing about the seat itself.

But some elections were **very** close. A party that won by 0.3 points and a party that lost by 0.3 points had about the same voters, the same year and the same kind of candidates. Rain in one city, and the result would have been the other way round. At the cutoff of zero, winning is close to a **coin toss**. So compare those who just won with those who just lost (Lee, 2008).

The design is called **regression discontinuity** (RD). It works whenever a *treatment* is given by a threshold in a *running variable* (score, age, income, votes) that nobody controls exactly. Thistlethwaite and Campbell (1960) invented it to find out what a certificate of merit, given to pupils above a test score, does for their further way.

## 3. The model step by step, with formulas

### Step 1: what is estimated

Write $Y(1)$ for the next share if the party wins now, $Y(0)$ if it loses, and $X$ for the margin. If both average curves are **continuous** at the cutoff, then

$$\tau = E[Y(1) - Y(0) \mid X = 0] = \lim_{x \downarrow 0} E[Y \mid X = x] - \lim_{x \uparrow 0} E[Y \mid X = x]$$

Nothing is assumed about the rest of the line. The effect is for elections **at the cutoff**.

### Step 2: a window

The simplest answer: take the elections with a margin below 1 point (or 2, or 5) and compare the two groups with a *t* test.

```{r windows}
windows <- do.call(

  lapply(c(0.5, 1, 2, 3, 5, 10), function(k) {

      window = k,

```

The narrower the window, the more alike the two groups, and the fewer the elections. In the wide windows the slope of the curves gets into the comparison: winners by 8 points are in other states than losers by 8 points.

### Step 3: a line on each side

Better than a narrow window: allow for the slope. Fit a straight line on each side, only with the elections within a **bandwidth** $h$, and give more weight to those near the cutoff (*triangular kernel*):

$$\min \sum_i w_i \left(y_i - \alpha - \tau D_i - \beta x_i - \gamma D_i x_i\right)^2, \qquad w_i = \max(0,\ 1 - |x_i|/h)$$

$D$ is 1 for a win, and $\tau$ is the jump. The package chooses $h$; we take its value (Step 4) and do the rest by hand:

```{r by_hand}
fit_rd <- rdrobust(s$vote, s$margin)
h <- fit_rd$bws["h", "left"]
local <- function(h, p, d = s) {
  # weighted least squares on each side, p: degree; returns the jump and its robust (HC0) SE
  side <- function(keep) {
    X <- outer(d$margin[keep], 0:p, "^")
    w <- 1 - abs(d$margin[keep]) / h
    A <- solve(crossprod(X, w * X))
    b <- A %*% crossprod(X, w * d$vote[keep])
    e <- drop(d$vote[keep] - X %*% b)
    V <- A %*% crossprod(X * (w * e)) %*% A
    c(b[1], V[1, 1])
  }
  l <- side(d$margin < 0 & d$margin > -h)
  r <- side(d$margin >= 0 & d$margin < h)
  c(jump = r[1] - l[1], SE = sqrt(l[2] + r[2]))
}
z <- subset(s, abs(margin) < h); z$w <- 1 - abs(z$margin) / h
wls <- lm(vote ~ won * margin, z, weights = w)
rbind(
  by_hand = local(h, 1),
  lm_with_weights = c(coef(wls)[["won"]], sqrt(sandwich::vcovHC(wls, type = "HC0")["won", "won"])),
  rdrobust_hc0 = with(
    rdrobust(s$vote, s$margin, h = h, vce = "hc0"),
    c(coef["Conventional", 1], se["Conventional", 1])
  )
)
```

Three times the same: a jump of `r f1(local(h, 1)[["jump"]])` points. The line through the points on the left ends at `r f1(coef(wls)[["(Intercept)"]])`%, the one on the right starts at `r f1(coef(wls)[["(Intercept)"]] + coef(wls)[["won"]])`%.

### Step 4: how wide?

A wide bandwidth uses many elections (little noise), but the curve may bend, and the straight line misses the edge (bias). A narrow one is the reverse. The error is roughly

$$\text{MSE}(h) \approx h^4 B^2 + \frac{V}{n h},$$

with $B$ from the curvature at the cutoff and $V$ from the scatter there. The best $h$ is proportional to $(V/(B^2 n))^{1/5}$. `rdrobust()` estimates $B$ and $V$ from the data and finds *h* = `r f1(h)` points, which keeps `r sum(abs(s$margin) < h)` elections.

### Step 5: the interval that knows about the bias

The best bandwidth for the **estimate** leaves a bias: at the minimum of the formula above it is exactly half a standard error. So the usual interval (estimate ± 1.96 *SE*) is centred at the wrong place, and contains the truth in `r pct(pnorm(1.96 - 0.5) - pnorm(-1.96 - 0.5))` instead of 95% of the samples. Calonico et al. (2014) subtract an estimate of the bias, and add the noise of **that** estimate to the standard error: the **robust bias-corrected** interval. It sounds complicated and has a simple core: if the bias is estimated with the same bandwidth, it is exactly the **local quadratic** fit.


By default `rdrobust()` uses a larger bandwidth for the bias (`r f1(fit_rd$bws["b", "left"])` points), which is less noisy.

`r if (all(placebo$p > .05)) "None of the five jumps is significant." else paste(sum(placebo$p < .05), "of the five have p < .05.")` The margin of the previous election jumps by `r f1(placebo$jump[1])` points, with an interval from `r f1(placebo$low[1])` to `r f1(placebo$high[1])`: not zero for certain, but no pattern either.

### Placebo cutoffs and the donut

At other values of the margin nobody wins or loses anything, so there should be no jump. And the result should not depend on the few elections right at the edge:


## 6. What not to do: a global polynomial

Before local regression became common, people fitted a high polynomial in the running variable to **all** data and read off the jump:

```{r global_polynomials}
global <- do.call(
  rbind,
  lapply(1:6, function(p) {
    m <- lm(vote ~ won * poly(margin, p, raw = TRUE), s)
    data.frame(
      degree = p,
      jump = coef(m)[["won"]],
      SE = sqrt(sandwich::vcovHC(m, type = "HC1")["won", "won"])
    )
  })
)
print(round(global, 2), row.names = FALSE)
```

The answer goes from `r f1(min(global$jump))` to `r f1(max(global$jump))` with the degree, and each has a small standard error that knows nothing of the choice. A polynomial lets elections that were won by 80 points have a say about the edge (Gelman & Imbens, 2019). Local lines do not.

## 7. Are the intervals right? A simulation

We make a population that looks like ours: the curve is a polynomial of degree 4 on each side (so the true jump is known), the margins come from the data, the noise is normal. Draw 500 samples and let `rdrobust()` do everything, bandwidth included.

```{r simulation}
sim_rd <- function(degree, reps = 500) {
  ml <- lm(vote ~ poly(margin, degree, raw = TRUE), s, subset = won == 0)
  mr <- lm(vote ~ poly(margin, degree, raw = TRUE), s, subset = won == 1)
  mu <- ifelse(s$won == 1, predict(mr, s), predict(ml, s))
  truth <- coef(mr)[[1]] - coef(ml)[[1]]
  sigma <- sd(s$vote - mu)
  r <- replicate(reps, {
    i <- sample(nrow(s), replace = TRUE)
    m <- rdrobust(mu[i] + rnorm(nrow(s), 0, sigma), s$margin[i], masspoints = "off")
    c(
      m$coef["Conventional", 1],
      m$ci["Conventional", 1] < truth & truth < m$ci["Conventional", 2],
      m$ci["Robust", 1] < truth & truth < m$ci["Robust", 2],
      m$bws["h", "left"]
    )
  })
  data.frame(
    degree = degree,
    true_jump = truth,
    mean_estimate = mean(r[1, ]),
    mean_bandwidth = mean(r[4, ]),
    coverage_usual = mean(r[2, ]),
    coverage_robust = mean(r[3, ])
  )
}
set.seed(221); sims <- do.call(rbind, lapply(3:5, sim_rd))
print(round(sims, 3), row.names = FALSE)
```

`r if (min(sims$coverage_usual) < 0.93) paste0("The usual interval contains the truth in ", pct(min(sims$coverage_usual), 1), " to ", pct(max(sims$coverage_usual), 1), " of the samples, depending on how much the curve bends at the edge. The robust interval has ", pct(min(sims$coverage_robust), 1), " to ", pct(max(sims$coverage_robust), 1), ". ") else paste0("Both intervals contain the truth in about 95% of the samples (usual: ", pct(min(sims$coverage_usual), 1), " to ", pct(max(sims$coverage_usual), 1), "; robust: ", pct(min(sims$coverage_robust), 1), " to ", pct(max(sims$coverage_robust), 1), "). ")`Where the true curve bends strongly at the edge, the local linear estimate is too low on average (degree 4: `r f1(sims$mean_estimate[2])` instead of `r f1(sims$true_jump[2])`), and the robust interval is what saves us.

## 8. What the number means

- It is the effect **at the cutoff**, for elections that were nearly tied. A safe seat may be different.
- It is the advantage of the **party** that holds the seat, not of the person: the candidate in the next election may be a new one.
- What about **winning** again? The same design with the outcome "the Democrat gets more than half of the votes next time":


A narrow win raises the probability of a majority next time by `r f1(100 * win$coef["Conventional", 1])` percentage points, 95% CI [`r f1(100 * win$ci["Robust", 1])`, `r f1(100 * win$ci["Robust", 2])`]. (With more than two candidates more than half is stricter than winning.) With standard errors clustered by state, the interval for the share is [`r f1(clustered$ci["Robust", 1])`, `r f1(clustered$ci["Robust", 2])`]: no important change.

## 9. Things to keep in mind

- **Draw the plot first.** If you cannot see the jump, be careful with the number.
- **Know the rule.** Is the threshold applied strictly? Do other things change at the same threshold (another law at age 18)? Then the jump is the effect of all of them.
- **Fuzzy RD**: when crossing the threshold only raises the **probability** of treatment, divide the jump in the outcome by the jump in the treatment. That is [instrumental variables](EXAMPLE_INSTRUMENTAL_VARIABLES.Rmd) at the cutoff: `rdrobust(y, x, fuzzy = treatment)`.
- **Discrete running variables** (age in years, whole test points): there is no "just above"; the methods need care.
- **Control variables** are not needed. They can shorten the interval (`covs =`), and must be fixed before the treatment.
- **Report the bandwidth**, its selection, the kernel, the number of observations on each side within it, and the robust interval. Show other bandwidths.
- **Power is low**: only the observations near the edge count. Here `r sum(fit_rd$N_h)` of `r num(nrow(s))`.

> The effect of holding a US Senate seat on the party's share in the next election was estimated with a sharp regression discontinuity design (Lee, 2008), using `r num(nrow(s))` elections between `r min(s$year)` and `r max(s$year)` (Cattaneo et al., 2015). The running variable was the Democratic margin of victory, with a cutoff of zero. We fitted local linear regressions with a triangular kernel on each side of the cutoff, with the bandwidth that minimises the mean squared error, and report robust bias-corrected 95% confidence intervals (Calonico et al., 2014; R package rdrobust). The assumption that parties could not steer the margin was examined with the density test of Cattaneo et al.
