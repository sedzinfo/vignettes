Generalized Estimating Equations (GEE): Which Pill Clears Up the Toenail?

  • Show All Code
  • Hide All Code
  • View Source
Generalized estimating equations in R, by hand and with geepack, on a randomised trial of two treatments with 294 patients seen up to seven times: correlated yes-or-no outcomes, the working correlation and the sandwich, population-averaged effects, independence, exchangeable and AR(1) structures with the QIC, GEE against a mixed model and why their coefficients differ, missing visits and inverse probability weights, what happens with few clusters, and APA reporting.

The question: the same people, again and again

Fungus under a toenail is hard to get rid of. In a randomised trial, 294 patients took one of two drugs, terbinafine or itraconazole, for three months, and were seen up to seven times in about a year (De Backer et al., 1998). At each visit the doctor noted whether the nail was badly affected or not. Which drug works better?

The outcome is yes or no, so we think of logistic regression. But there are about six observations of each patient, and they are far from independent: a bad nail is usually still bad at the next visit. Logistic regression would count 1,908 observations as 1,908 patients, and its standard errors would be wrong.

There are two families of solutions. Mixed models give each patient a random effect (see multilevel models). Generalized estimating equations (GEE; Liang & Zeger, 1986) do not model the patients at all. They model the average of the population at each time, and repair the standard errors afterwards. For yes-or-no outcomes the two give different coefficients, which answer different questions. This page explains which is which.

3. The model step by step, with formulas

Step 1: a model for the mean, and nothing more

For patient \(i\) at visit \(j\):

\[\log\frac{\mu_{ij}}{1 - \mu_{ij}} = \beta_0 + \beta_1\,\text{terb}_i + \beta_2\,\text{month}_{ij} + \beta_3\,\text{terb}_i \times \text{month}_{ij}, \qquad \mu_{ij} = P(\text{bad}_{ij} = 1)\]

This is the marginal mean: the share of bad nails among all patients with these values. We say nothing about single patients.

Step 2: the estimating equations

Logistic regression solves \(\sum_{ij} x_{ij}(y_{ij} - \mu_{ij}) = 0\). GEE generalises it. Let \(V_i\) be a guess of the covariance matrix of the observations of patient \(i\), and \(D_i\) the derivatives of the means:

\[\sum_i D_i^\top V_i^{-1} (y_i - \mu_i) = 0, \qquad V_i = \phi\, A_i^{1/2} R(\alpha) A_i^{1/2}\]

\(A_i\) has the binomial variances \(\mu(1-\mu)\) on the diagonal. \(R(\alpha)\) is the working correlation, a simple pattern that is chosen by the analyst.

Working correlation Assumes
independence no correlation: the equations of logistic regression
exchangeable the same correlation \(\alpha\) for every pair of visits
AR(1) \(\alpha\) for neighbours, \(\alpha^2\) two visits apart, and so on
unstructured a free correlation for every pair

Step 3: the great advantage

The estimate \(\hat\beta\) is consistent even if the working correlation is wrong, as long as the model for the mean is right. A better guess makes it more precise, that is all. (If there are missing visits, there is a condition. See section 6.)

Step 4: the sandwich

The variance is not taken from the working correlation, which may be wrong, but from how much the patients really differ from the model:

\[\widehat{\text{Var}}(\hat\beta) = B^{-1} M B^{-1}, \qquad B = \sum_i D_i^\top V_i^{-1} D_i, \qquad M = \sum_i D_i^\top V_i^{-1} e_i e_i^\top V_i^{-1} D_i\]

The meat \(M\) contains the products of the residuals of the same patient, \(e_i e_i^\top\), so any correlation is in it. By hand, with independence:

Code 
# independence: ordinary logistic regression
glm_fit <- glm(bad ~ terb * month, family = binomial, data = nail)
X <- model.matrix(glm_fit); mu <- fitted(glm_fit); e <- nail$bad - mu
B <- crossprod(X, X * mu * (1 - mu))
scores <- rowsum(X * e, nail$id) # one row per patient: the sum over the visits
V_hand <- solve(B) %*% crossprod(scores) %*% solve(B)
gee_ind <- geeglm(
  bad ~ terb * month,
  id = id,
  waves = visit,
  data = nail,
  family = binomial,
  corstr = "independence"
)
rbind(
  by_hand = sqrt(diag(V_hand)),
  geeglm = sqrt(diag(vcov(gee_ind))),
  naive_glm = sqrt(diag(vcov(glm_fit)))

The coefficients of the mixed model are 2.3 times as large. It is no error in either.

  • The mixed model coefficient is subject-specific: it compares a patient with the same patient (or with another who has the same random effect) one month later. \(e^{-0.39}\) = 0.68 per month.
  • The GEE coefficient is population-averaged: it compares the share of bad nails among all patients with that share one month later. 0.84 per month.

The random intercepts have an SD of 4.0 on the logit scale, which is enormous: some patients are almost surely bad, others almost surely fine. Average many steep S-curves that start at different places, and the average is a flat S-curve:

6. Missing visits

Not all patients came to all visits. GEE needs the missing ones to be missing completely at random. Otherwise the patients who remain are a special group, and the average is an average of them. Do patients with a bad nail miss the next visit more often?

Code 
# one row for every planned visit
panel <- merge(expand.grid(visit = 1:7, id = unique(nail$id)), nail, all.x = TRUE)
panel <- panel[order(panel$id, panel$visit), ]
panel$seen <- as.integer(!is.na(panel$bad))
panel$terb <- ave(panel$terb, panel$id, FUN = function(v) v[!is.na(v)][1])
last_seen <- function(v) {
  out <- rep(NA, length(v))
  for (k in seq_along(v)[-1]) {
    past <- v[1:(k - 1)]
    past <- past[!is.na(past)]
    out[k] <- if (length(past)) tail(past, 1) else NA
  }
  out
}

The repair for GEE is inverse probability weighting (Robins et al., 1995): each observation is weighted by one over the probability that it was made, given the past. Those who are seen although patients like them are often missing count more.

7. Few clusters

The sandwich is a large-sample method, and the sample size is the number of clusters. With few, the robust standard errors are too small. An experiment: no effect of treatment at all, clusters of 6 observations with a strong correlation, and the test at 5%.

Code 
set.seed(122)
false_positive <- function(n_clusters, reps = 400) {
  mean(
    replicate(reps, {
      d <- data.frame(
        id = rep(seq_len(n_clusters), each = 6),
        trt = rep(rep(0:1, length.out = n_clusters), each = 6)
      )
      d$y <- rbinom(nrow(d), 1, plogis(-0.3 + rep(rnorm(n_clusters, 0, 1.5), each = 6)))
      m <- try(
        geeglm(y ~ trt, id = id, data = d, family = binomial, corstr = "exchangeable"),
        silent = TRUE
      )
      if (inherits(m, "try-error")) NA else coef(summary(m))["trt", 4] < .05
    }),
    na.rm = TRUE
  )
}
sizes <- c(10, 20, 40, 100)
type1 <- sapply(sizes, false_positive)
setNames(round(type1, 3), paste(sizes, "clusters"))
 10 clusters  20 clusters  40 clusters 100 clusters 
       0.095        0.075        0.078        0.055

With 10 clusters the test rejects a true null hypothesis in 10% of the studies, with 100 in 6%. Below about 40 or 50 clusters use a small-sample correction (Mancl & DeRouen, 2001; the package clubSandwich) or a mixed model.

8. Things to keep in mind

  • Say whose effect it is: population-averaged. Do not write “a patient’s odds”.
  • Sort the data by cluster, and give the visit number in waves if some are missing, or AR(1) will take the wrong neighbours.
  • The working correlation is a tool, not a finding. If the correlations are what you study, use another model.
  • No likelihood: no AIC, no likelihood-ratio test. Use Wald tests and the QIC.
  • Predictors that vary within a cluster can make the estimate depend on the working correlation, if the past of a predictor matters for the future of the outcome. Independence is the safe choice then.
  • Randomised at baseline. The groups are the same at month 0 by design, so one can leave out the main effect of terb and gain precision.
  • Straight lines on the logit scale may not be right for a year. Check the shape with the visits as a factor.
  • Counts, gamma and other outcomes work in the same way, with another family.

Method (data analysis):

The presence of a moderate or severe infection at up to seven visits of 294 patients (1,908 observations; De Backer et al., 1998) was analysed with generalized estimating equations with a logit link and an exchangeable working correlation (Liang & Zeger, 1986). The model contained treatment, time in months and their interaction; standard errors are robust. Odds ratios are population-averaged. Independence and AR(1) working correlations, inverse probability weights for missing visits, and a logistic mixed model with random intercepts, whose odds ratios are patient-specific, served as sensitivity analyses. Analyses were conducted in R (Version 4.6.2; R Core Team, 2026) with the packages geepack (Halekoh et al., 2006) and lme4.

Results:

The odds of a moderate or severe infection fell by 16% per month with itraconazole, OR = 0.84, 95% CI [0.79, 0.89], p < .001. The decrease was somewhat faster with terbinafine, OR = 0.93 per month, 95% CI [0.83, 1.03], p = .151, but the difference was not significant (Table 1). In the mixed model, the patient-specific odds ratio of the interaction was 0.87, p = .044. The estimate of the interaction was between -0.088 and -0.067 with the three working correlations (p between .073 and .197), and -0.067 with weights for missing visits.

## The question: the same people, again and again

Fungus under a toenail is hard to get rid of. In a randomised trial, 294 patients took one of two drugs, terbinafine or itraconazole, for three months, and were seen up to seven times in about a year (De Backer et al., 1998). At each visit the doctor noted whether the nail was badly affected or not. Which drug works better?

The outcome is yes or no, so we think of logistic regression. But there are about six observations of **each patient**, and they are far from independent: a bad nail is usually still bad at the next visit. Logistic regression would count 1,908 observations as 1,908 patients, and its standard errors would be wrong.

There are two families of solutions. **Mixed models** give each patient a random effect (see [multilevel models](EXAMPLE_MULTILEVEL.Rmd)). **Generalized estimating equations** (GEE; Liang & Zeger, 1986) do not model the patients at all. They model the **average** of the population at each time, and repair the standard errors afterwards. For yes-or-no outcomes the two give **different coefficients**, which answer different questions. This page explains which is which.

## 3. The model step by step, with formulas

### Step 1: a model for the mean, and nothing more

For patient $i$ at visit $j$:

$$\log\frac{\mu_{ij}}{1 - \mu_{ij}} = \beta_0 + \beta_1\,\text{terb}_i + \beta_2\,\text{month}_{ij} + \beta_3\,\text{terb}_i \times \text{month}_{ij}, \qquad \mu_{ij} = P(\text{bad}_{ij} = 1)$$

This is the **marginal** mean: the share of bad nails among all patients with these values. We say nothing about single patients.

### Step 2: the estimating equations

Logistic regression solves $\sum_{ij} x_{ij}(y_{ij} - \mu_{ij}) = 0$. GEE generalises it. Let $V_i$ be a guess of the covariance matrix of the observations of patient $i$, and $D_i$ the derivatives of the means:

$$\sum_i D_i^\top V_i^{-1} (y_i - \mu_i) = 0, \qquad V_i = \phi\, A_i^{1/2} R(\alpha) A_i^{1/2}$$

$A_i$ has the binomial variances $\mu(1-\mu)$ on the diagonal. $R(\alpha)$ is the **working correlation**, a simple pattern that is chosen by the analyst.

| Working correlation | Assumes |
|---|---|
| independence | no correlation: the equations of logistic regression |
| exchangeable | the same correlation $\alpha$ for every pair of visits |
| AR(1) | $\alpha$ for neighbours, $\alpha^2$ two visits apart, and so on |
| unstructured | a free correlation for every pair |

### Step 3: the great advantage

The estimate $\hat\beta$ is **consistent even if the working correlation is wrong**, as long as the model for the mean is right. A better guess makes it more precise, that is all. (If there are missing visits, there is a condition. See section 6.)

### Step 4: the sandwich

The variance is not taken from the working correlation, which may be wrong, but from how much the patients really differ from the model:

$$\widehat{\text{Var}}(\hat\beta) = B^{-1} M B^{-1}, \qquad B = \sum_i D_i^\top V_i^{-1} D_i, \qquad M = \sum_i D_i^\top V_i^{-1} e_i e_i^\top V_i^{-1} D_i$$

The meat $M$ contains the products of the residuals of the **same** patient, $e_i e_i^\top$, so any correlation is in it. By hand, with independence:

```{r by_hand}
# independence: ordinary logistic regression
glm_fit <- glm(bad ~ terb * month, family = binomial, data = nail)
X <- model.matrix(glm_fit); mu <- fitted(glm_fit); e <- nail$bad - mu
B <- crossprod(X, X * mu * (1 - mu))
scores <- rowsum(X * e, nail$id) # one row per patient: the sum over the visits
V_hand <- solve(B) %*% crossprod(scores) %*% solve(B)
gee_ind <- geeglm(
  bad ~ terb * month,
  id = id,
  waves = visit,
  data = nail,
  family = binomial,
  corstr = "independence"
)
rbind(
  by_hand = sqrt(diag(V_hand)),
  geeglm = sqrt(diag(vcov(gee_ind))),
  naive_glm = sqrt(diag(vcov(glm_fit)))
)
```

The estimates of GEE with independence **are** those of logistic regression. The standard errors are not: that of the intercept is `r f1(sqrt(V_hand[1, 1]) / sqrt(vcov(glm_fit)[1, 1]))` times larger.

- **`month`**: odds ratio $e^{`r f3(s["month", 1])`}$ = `r f2(or[["month"]])` per month, 95% CI [`r f2(low[["month"]])`, `r f2(high[["month"]])`]: with itraconazole the odds of a bad nail, **in the population**, fall by `r pct(1 - or[["month"]])` per month.
- **`terb`**: at month 0 the groups are alike (`r f2(or[["terb"]])`), as they should be after randomisation.
- **`terb:month`**: `r f2(or[["terb:month"]])`, [`r f2(low[["terb:month"]])`, `r f2(high[["terb:month"]])`], *p* `r pval(s["terb:month", 4])`: with terbinafine the odds fall `r pct(1 - or[["terb:month"]])` more per month. The direction favours terbinafine, and the interval contains 1.
- **`Wald`** and `Pr(>|W|)`: the squared *z* tests, with the robust standard errors.
- **`alpha`** = `r f2(gee_ex$geese$alpha)`: the estimated working correlation between two visits of a patient. It is not a result, just a tool.

### Which working correlation?

```{r structures}
fits <- list(independence = gee_ind, exchangeable = gee_ex, AR1 = gee_ar)
tab <- t(sapply(fits, function(m) {
  cs <- coef(summary(m))
  c(
    b = cs["terb:month", 1],
    SE_robust = cs["terb:month", 2],
    p = cs["terb:month", 4],
    QIC = QIC(m)[[1]]
  )
}))
round(rbind(tab, `naive logistic` = c(coef(summary(glm_fit))["terb:month", c(1, 2, 4)], NA)), 4)
```

The estimates differ a little, the robust standard errors less. The **QIC** is the AIC of GEE: it compares models for the mean, and also working correlations (smaller is better). It is not a strong guide. The natural choice for visits in time is AR(1) or exchangeable; the important thing is to **choose beforehand**, not by the *p* value. (The naive logistic regression would have given *p* `r pval(coef(summary(glm_fit))["terb:month", 4])`.)

## 5. GEE or mixed model? Two different questions

A logistic **mixed model** gives each patient a random intercept:

```{r mixed}
mixed <- glmer(bad ~ terb * month + (1 | id), data = nail, family = binomial, nAGQ = 20)
sm <- coef(summary(mixed)); sd_u <- attr(VarCorr(mixed)$id, "stddev")
round(cbind(GEE = s[, 1], mixed = sm[, 1], ratio = sm[, 1] / s[, 1]), 3)
sd_u
c(p_GEE = s["terb:month", 4], p_mixed = sm["terb:month", 4])
```

The coefficients of the mixed model are **`r f1(sm["month", 1] / s["month", 1])` times as large**. It is no error in either.

- The **mixed model** coefficient is **subject-specific**: it compares a patient with **the same patient** (or with another who has the same random effect) one month later. $e^{`r f2(sm["month", 1])`}$ = `r f2(exp(sm["month", 1]))` per month.
- The **GEE** coefficient is **population-averaged**: it compares the share of bad nails among all patients with that share one month later. `r f2(or[["month"]])` per month.

The random intercepts have an SD of `r f1(sd_u)` on the logit scale, which is enormous: some patients are almost surely bad, others almost surely fine. Average many steep S-curves that start at different places, and the average is a **flat** S-curve:

```{r curves_chart}
m_grid <- seq(0, 14, by = 0.1); set.seed(121); u <- rnorm(40, 0, sd_u)
single <- do.call(
  rbind,
  lapply(seq_along(u), function(k) {
    data.frame(month = m_grid, p = plogis(sm[1, 1] + sm[3, 1] * m_grid + u[k]), patient = k)
  })

many <- rnorm(20000, 0, sd_u)

    title = "Forty patients of the mixed model (grey), and the population (itraconazole)",
```

There is an approximate rule for the factor between the two, $\sqrt{1 + 0.346\,\sigma_u^2}$ (Zeger et al., 1988): here `r f1(shrink)`. With a normal outcome and an identity link the two coefficients are the same, and the question does not arise.

| | GEE | Mixed model |
|---|---|---|
| Question | How does the **population** change? (public health, policy, trials) | How does a **patient** change? (treatment of one person) |
| Assumes about patients | nothing | a distribution of random effects |
| Wrong correlation | estimates still right | estimates may be wrong |
| Missing visits | must not depend on the outcome (MCAR) | may depend on the **observed** past (MAR) |
| Single patients | no predictions | predictions of the random effects |
| Few clusters | standard errors too small | better |

## 6. Missing visits

Not all patients came to all visits. GEE needs the missing ones to be **missing completely at random**. Otherwise the patients who remain are a special group, and the average is an average of them. Do patients with a bad nail miss the next visit more often?

```{r dropout}
# one row for every planned visit
panel <- merge(expand.grid(visit = 1:7, id = unique(nail$id)), nail, all.x = TRUE)
panel <- panel[order(panel$id, panel$visit), ]
panel$seen <- as.integer(!is.na(panel$bad))
panel$terb <- ave(panel$terb, panel$id, FUN = function(v) v[!is.na(v)][1])
last_seen <- function(v) {
  out <- rep(NA, length(v))
  for (k in seq_along(v)[-1]) {
    past <- v[1:(k - 1)]
    past <- past[!is.na(past)]
    out[k] <- if (length(past)) tail(past, 1) else NA
  }
  out
}
# the status when the patient was last seen
panel$bad_before <- ave(panel$bad, panel$id, FUN = last_seen)
later <- subset(panel, visit > 1 & !is.na(bad_before))
stay  <- glm(seen ~ factor(visit) + terb + bad_before, family = binomial, data = later)
c(planned = nrow(panel), missing = sum(panel$seen == 0))
round(coef(summary(stay))[c("terb", "bad_before"), ], 3)
```

`r sum(panel$seen == 0)` of the `r num(nrow(panel))` planned visits are missing. Patients whose nail was bad when they were last seen have `r f2(exp(coef(stay)[["bad_before"]]))` times the odds of being seen at a visit (*p* `r pval(coef(summary(stay))["bad_before", 4])`). `r if (coef(summary(stay))["bad_before", 4] < .05) "So the missing visits are related to the outcome, and plain GEE is in doubt." else "There is no clear sign that the missing visits depend on the outcome, although a test with this few missing visits proves little."`

The repair for GEE is **inverse probability weighting** (Robins et al., 1995): each observation is weighted by one over the probability that it was made, given the past. Those who are seen although patients like them are often missing count more.

```{r ipw}
later$w <- 1 / predict(stay, type = "response")
weighted <- merge(subset(panel, seen == 1), later[, c("id", "visit", "w")], all.x = TRUE)
weighted$w[is.na(weighted$w)] <- 1 # the first visits
weighted <- weighted[order(weighted$id, weighted$visit), ]
gee_w <- geeglm(
  bad ~ terb * month,
  id = id,
  data = weighted,
  weights = w,
  family = binomial,
  corstr = "independence"
)
round(
  rbind(
    unweighted = coef(summary(gee_ind))["terb:month", ],
    weighted = coef(summary(gee_w))["terb:month", ]
  ),
  4
)
range(weighted$w)
```

The weights are between `r f2(min(weighted$w))` and `r f2(max(weighted$w))`, and the estimate hardly moves: `r formatC(coef(gee_w)[["terb:month"]], format = "f", digits = 4)` instead of `r formatC(coef(gee_ind)[["terb:month"]], format = "f", digits = 4)`. (The weights are used with independence, for which the theory is clean. They assume that whether a patient is seen depends only on the drug, the visit and the last status.)

## 7. Few clusters

The sandwich is a large-sample method, and the sample size is the number of **clusters**. With few, the robust standard errors are too small. An experiment: no effect of treatment at all, clusters of 6 observations with a strong correlation, and the test at 5%.

```{r few_clusters}
set.seed(122)
false_positive <- function(n_clusters, reps = 400) {
  mean(
    replicate(reps, {
      d <- data.frame(
        id = rep(seq_len(n_clusters), each = 6),
        trt = rep(rep(0:1, length.out = n_clusters), each = 6)
      )
      d$y <- rbinom(nrow(d), 1, plogis(-0.3 + rep(rnorm(n_clusters, 0, 1.5), each = 6)))
      m <- try(
        geeglm(y ~ trt, id = id, data = d, family = binomial, corstr = "exchangeable"),
        silent = TRUE
      )
      if (inherits(m, "try-error")) NA else coef(summary(m))["trt", 4] < .05
    }),
    na.rm = TRUE
  )
}
sizes <- c(10, 20, 40, 100)
type1 <- sapply(sizes, false_positive)
setNames(round(type1, 3), paste(sizes, "clusters"))
```

With 10 clusters the test rejects a true null hypothesis in `r pct(type1[1])` of the studies, with 100 in `r pct(type1[4])`. Below about 40 or 50 clusters use a small-sample correction (Mancl & DeRouen, 2001; the package `clubSandwich`) or a mixed model.

## 8. Things to keep in mind

- **Say whose effect it is**: population-averaged. Do not write "a patient's odds".
- **Sort the data by cluster**, and give the visit number in `waves` if some are missing, or AR(1) will take the wrong neighbours.
- **The working correlation is a tool**, not a finding. If the correlations are what you study, use another model.
- **No likelihood**: no AIC, no likelihood-ratio test. Use Wald tests and the QIC.
- **Predictors that vary within a cluster** can make the estimate depend on the working correlation, if the past of a predictor matters for the future of the outcome. Independence is the safe choice then.
- **Randomised at baseline.** The groups are the same at month 0 by design, so one can leave out the main effect of `terb` and gain precision.
- **Straight lines on the logit scale** may not be right for a year. Check the shape with the visits as a factor.
- **Counts, gamma and other outcomes** work in the same way, with another family.

**Method** (data analysis):

> The presence of a moderate or severe infection at up to seven visits of `r length(unique(nail$id))` patients (`r num(nrow(nail))` observations; De Backer et al., 1998) was analysed with generalized estimating equations with a logit link and an exchangeable working correlation (Liang & Zeger, 1986). The model contained treatment, time in months and their interaction; standard errors are robust. Odds ratios are population-averaged. Independence and AR(1) working correlations, inverse probability weights for missing visits, and a logistic mixed model with random intercepts, whose odds ratios are patient-specific, served as sensitivity analyses. Analyses were conducted in R (Version `r paste(R.version$major, R.version$minor, sep = ".")`; R Core Team, `r R.version$year`) with the packages geepack (Halekoh et al., 2006) and lme4.

**Results:**

> The odds of a moderate or severe infection fell by `r pct(1 - or[["month"]])` per month with itraconazole, *OR* = `r f2(or[["month"]])`, 95% CI [`r f2(low[["month"]])`, `r f2(high[["month"]])`], *p* `r pval(s["month", 4])`. The decrease was somewhat faster with terbinafine, *OR* = `r f2(or[["terb:month"]])` per month, 95% CI [`r f2(low[["terb:month"]])`, `r f2(high[["terb:month"]])`], *p* `r pval(s["terb:month", 4])`, but the difference was not significant (Table 1). In the mixed model, the patient-specific odds ratio of the interaction was `r f2(exp(sm["terb:month", 1]))`, *p* `r pval(sm["terb:month", 4])`. The estimate of the interaction was between `r f3(min(tab[, "b"]))` and `r f3(max(tab[, "b"]))` with the three working correlations (*p* between `r nz(min(tab[, "p"]), 3)` and `r nz(max(tab[, "p"]), 3)`), and `r f3(coef(gee_w)[["terb:month"]])` with weights for missing visits.

## 10. Summary

| | |
|---|---|
| **When** | Repeated or clustered outcomes of any type, and the interest is in the average of the population |
| **The model** | A GLM for the marginal mean, a working correlation within clusters |
| **How (R)** | `geepack::geeglm(y ~ x, id = id, waves = visit, data, family, corstr = "exchangeable")` |
| **Standard errors** | Robust (sandwich): valid whatever the correlation is, with enough clusters |
| **Choosing the correlation** | Beforehand; the QIC as a guide |
| **Against mixed models** | Population-averaged against subject-specific; smaller coefficients for logits |
| **Needs** | Missing completely at random (or weights), 40 or more clusters |
| **Related pages** | [Multilevel models](EXAMPLE_MULTILEVEL.Rmd), [generalized linear models](EXAMPLE_GENERALIZED.rmd), [missing data](EXAMPLE_MISSING_DATA.Rmd) |
