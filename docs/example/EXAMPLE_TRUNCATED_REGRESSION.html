Truncated Regression: What If Only the Tall Sons Had Been Measured?

  • Show All Code
  • Hide All Code
  • View Source
Truncated regression in R, by hand with optim() and with truncreg, on Galton’s family heights: we keep only the sons of 68 inches or more, as an army with a minimum height would, and try to recover the truth that the full data show. Truncated normal likelihood, why least squares is biased, the inverse Mills ratio, truncation against censoring (Tobit), what rounding, a wrong cut-off and non-normal errors do, restricted maximum likelihood and APA reporting.

The question: the records of a tall army

Historians learn how tall people were, and so how well they were fed, from the records of armies. But many armies had a minimum height. Shorter men were sent away, and nobody wrote them down. From such records the population looks too tall. And a regression on them, for example of a son’s height on his parents’ heights, gives wrong slopes, as we shall see.

A sample is truncated when the cases beyond a limit are missing altogether. We do not know who they were, nor how many. Other examples: an experiment that admits only families with an income below some limit (Hausman & Wise, 1977), a survey of firms with more than ten employees, the patients of a clinic that admits only those above some blood value.

Truncated regression tries to recover the line of the full population from the truncated sample. Can it? With real truncated data one never knows, because the truth is missing. So we use data for which we know the truth, Galton’s heights from simple linear regression, and make the truncated sample ourselves: an imaginary guard regiment that takes only sons of 68 inches (173 cm) or more.

3. The model step by step, with formulas

Step 1: the line of the whole population

\[y_i = \beta_0 + \beta_1\, \text{father}_i + \beta_2\, \text{mother}_i + \varepsilon_i, \qquad \varepsilon_i \sim N(0, \sigma^2)\]

We see case \(i\) only if \(y_i \ge c\), with \(c = 68\).

Step 2: the distribution of those we see

Among all the sons of such parents, the heights have a normal curve around \(\mu_i = \beta_0 + \beta_1 \text{father}_i + \beta_2 \text{mother}_i\). Cut off the part below \(c\). What remains has an area of \(P(y_i \ge c) = \Phi\!\big(\frac{\mu_i - c}{\sigma}\big)\), less than 1. To be a distribution again it must be divided by that area. The result is the truncated normal density:

\[f(y_i \mid y_i \ge c) = \frac{\frac{1}{\sigma}\,\phi\!\left(\frac{y_i - \mu_i}{\sigma}\right)}{\Phi\!\left(\frac{\mu_i - c}{\sigma}\right)}\]

(\(\phi\) is the height of the standard normal curve, dnorm(); \(\Phi\) the area to the left, pnorm().)

shape <- do.call(

Step 3: the average of those we see

The mean of the truncated normal is above the line:

\[E(y_i \mid y_i \ge c) = \mu_i + \sigma\, \lambda(\alpha_i), \qquad \lambda(\alpha) = \frac{\phi(\alpha)}{1 - \Phi(\alpha)}, \qquad \alpha_i = \frac{c - \mu_i}{\sigma}\]

\(\lambda\) is the inverse Mills ratio. It is large when most of the curve is cut off (\(\mu_i\) far below \(c\)) and goes to zero when nothing is. So the mean of the sons in the records is pushed up most where the parents are short. This term, which OLS does not know, is the bias.

Step 4: maximum likelihood

Add up the logarithms of the densities of step 2, and find the \(\beta\)’s and \(\sigma\) that make the sum as large as possible:

\[\log L = \sum_i \left[ \log \frac{1}{\sigma}\phi\!\left(\frac{y_i - \mu_i}{\sigma}\right) - \log \Phi\!\left(\frac{\mu_i - c}{\sigma}\right) \right]\]

The first part is the ordinary normal likelihood. The second is the correction. It says: take into account that I could not have seen it otherwise. The estimates are consistent if the model is right (Amemiya, 1973).

Code 
X <- model.matrix(naive); y <- guards$son
minus_loglik <- function(par, X, y, cut) {
  # par: the coefficients, then log(sigma)
  mu <- drop(X %*% par[-length(par)])
  s <- exp(par[length(par)])
  -sum(dnorm(y, mu, s, log = TRUE) - pnorm((mu - cut) / s, log.p = TRUE))
}
start <- c(coef(naive), log(sigma(naive)))                      # start from OLS
hand  <- optim(start, minus_loglik, X = X, y = y, cut = minimum, method = "BFGS", hessian = TRUE,
               control = list(maxit = 1000, reltol = 1e-12, parscale = c(10, 0.1, 0.1, 0.1)))
c(hand$par[-4], sigma = exp(hand$par[[4]]), logLik = -hand$value)

Two kinds of effect

The slope \(\beta_1\) is the effect in the whole population. If the question is about the men in the regiment, it is the slope of \(E(y \mid y \ge c)\), which is smaller:

\[\frac{\partial E(y \mid y \ge c)}{\partial x} = \beta_1 \left[1 - \lambda(\alpha)\,\big(\lambda(\alpha) - \alpha\big)\right]\]

Code 
mu    <- drop(X %*% b[1:3])
alpha <- (minimum - mu) / b[["sigma"]]
mills <- dnorm(alpha) / pnorm(alpha, lower.tail = FALSE)
shrink <- 1 - mills * (mills - alpha)                   # always between 0 and 1
cbind(
  value = c(
    average_factor = mean(shrink),
    effect_in_the_population = b[["father"]],
    effect_among_the_tall = b[["father"]] * mean(shrink),
    OLS = coef(naive)[["father"]]
  )
)

effect_in_the_population 0.4571609
effect_among_the_tall    0.2182480

Averaged over the men in the records, the factor is 0.48, so one inch of father goes with 0.22 inches among the tall sons: about what OLS found. OLS is not “wrong”. It answers the question about the regiment, and people read it as an answer about the population.

5. Truncated or censored?

A censored sample is less damaged. There we know how many cases are beyond the limit, and their predictors; only the exact outcome is missing. Suppose that the regiment had written down the parents’ heights of the rejected sons, with the note “below 68”. That is the Tobit model:

Code 
sons$recorded <- pmax(sons$son, minimum)
tobit <- survreg(
  Surv(recorded, son >= minimum, type = "left") ~ father + mother,
  data = sons,
  dist = "gaussian"
)
rbind(truth = truth[1:3], tobit = coef(tobit), truncated = b[1:3])

The standard error of the Tobit slope is less than half as large. It is worth a lot to write down even those who are turned away. The most expensive mistake is to treat a censored sample as truncated, by deleting the cases at the limit.

6. What can go wrong

The correction rests on three assumptions: we know the cut-off, the cut-off was applied strictly, and the errors are normal, right down to the tail that we cannot see. Each can fail.

Rounding moves the cut-off

Most of Galton’s heights are rounded to an inch or a half inch. A son written down as 68 may be 67.75. So the true limit of the records is a bit below 68:

Code 
share_whole <- mean(guards$son %% 1 == 0)
cuts <- c(68, 67.75, 67.5)
moved <- t(sapply(cuts, function(cc) {
  m <- truncreg(son ~ father + mother, data = guards, point = cc, direction = "left")
  c(cut = cc, coef(m)[2:4])
}))
round(rbind(moved, truth = c(NA, truth[2:4])), 3)
        cut father mother sigma
      68.00  0.457  0.477 2.401
      67.75  0.375  0.389 2.165
      67.50  0.327  0.338 2.016
truth    NA  0.418  0.329 2.295

70% of the heights in the records are whole inches. Taking 67.75 or 67.5 as the limit changes the father’s slope from 0.46 to 0.38 and 0.33. A quarter of an inch matters that much, because the heights are densest near the limit and the correction depends on how the curve is cut there. The right treatment is a likelihood for intervals (“the son is between 67.5 and 68.5”). The smallest honest step is to report the results for more than one limit.

The errors must be normal

The model extends the curve that it sees into the part that it does not see. If the hidden tail has another shape, it is wrong. A simulation with the real parents’ heights and the true line, and three kinds of errors with the same standard deviation:

Code 
set.seed(17)
Xf   <- model.matrix(full); line <- drop(Xf %*% truth[1:3]); s0 <- truth[["sigma"]]
kinds <- list(normal             = function(n) rnorm(n, 0, s0),
              `long tails (t, 4 df)` = function(n) rt(n, 4) * s0 / sqrt(2),
              `skewed (long to the right)` = function(n) (rgamma(n, 4) - 4) / 2 * s0)
reps <- 500
sim <- lapply(kinds, function(draw) {
  t(replicate(reps, {
    yy <- line + draw(length(line))
    keep <- yy >= minimum
    d <- data.frame(son = yy, father = Xf[, 2], mother = Xf[, 3])[keep, ]
    o <- coef(lm(son ~ father + mother, d))
    m <- try(
      suppressWarnings(truncreg(
        son ~ father + mother,
        data = d,
        point = minimum,
        direction = "left"
      )),
      silent = TRUE
    )
    c(OLS = o[["father"]], truncated = if (inherits(m, "try-error")) NA else coef(m)[["father"]])
  }))
})
bias <- do.call(
  rbind,
  lapply(names(sim), function(k) {
    data.frame(
      errors = k,
      true = truth[["father"]],
      OLS = mean(sim[[k]][, "OLS"]),
      truncated = mean(sim[[k]][, "truncated"], na.rm = TRUE),
      SD_OLS = sd(sim[[k]][, "OLS"]),
      SD_truncated = sd(sim[[k]][, "truncated"], na.rm = TRUE),
      failed = sum(is.na(sim[[k]][, "truncated"]))
    )
  })
)
print(cbind(errors = bias$errors, round(bias[, -1], 3)), row.names = FALSE)
                     errors  true   OLS truncated SD_OLS SD_truncated failed
                     normal 0.418 0.232     0.413  0.046        0.086      0

  • With normal errors the truncated regression is right on average (0.41, truth 0.42), and OLS is far off (0.23).
  • With long tails it gives 0.54, and with skewed errors 0.54. The correction is biased in both cases. With skewed errors it is off by 29%.
  • Even when it is right on average, it is imprecise: the spread of the estimates is 1.9 times that of OLS.

Our errors are close to normal (the full data allow us to check), so the method had a fair chance here. With a truly truncated sample this check is impossible: the tail that would show it is the missing one.

How much can be cut away?

With a quarter of the sons missing (limit 68) the estimate is still usable. When more than half of them are missing (limit 70) the standard error is 0.25, more than half of the true slope. And OLS becomes flatter and flatter.

7. Borrowing a number: restricted maximum likelihood

The weak part of the estimation is \(\sigma\). From the cut curve alone it is hard to tell a wide distribution with a low mean from a narrow one with a high mean, and errors in \(\sigma\) carry over to the slopes. Height is a special case, because its spread is nearly the same in all populations that have been measured. A’Hearn (2004) proposed to fix \(\sigma\) at a known value and to estimate the rest:

Code 
with_sigma <- function(s_fixed) {
  f <- function(par) minus_loglik(c(par, log(s_fixed)), X = X, y = y, cut = minimum)

}

8. Things to keep in mind

  • Is it really truncated? If you know how many cases are beyond the limit, it is censored: use Tobit. If the cases are missing because of another variable (people who did not answer, women who do not work), it is sample selection, the subject of the Heckman model.
  • Selecting on a predictor is harmless. Keeping only the sons of tall fathers does not bias the slope (it costs precision). Only selection on the outcome does.
  • The limit must be known and strict. In real armies, short volunteers were let in when soldiers were needed, and the density near the limit thins out gradually. Historians cut at a higher point, where the records are complete.
  • Normality cannot be checked where it matters. Try other distributions (crch::trch() has logistic and t errors) and report how much the answer moves.
  • The two limits can be on both sides: crch and gamlss.tr handle them.
  • Counts without zeros (the number of visits of those who visited) need the zero-truncated Poisson or negative binomial.
  • Standard errors here ignore that brothers share their parents. For the full data we used cluster-robust errors in simple linear regression; for the truncated model, bootstrap the families.
  • No miracle. The correction replaces missing information by an assumption. If the conclusion depends on it, say so.

## The question: the records of a tall army

Historians learn how tall people were, and so how well they were fed, from the records of armies. But many armies had a **minimum height**. Shorter men were sent away, and nobody wrote them down. From such records the population looks too tall. And a regression on them, for example of a son's height on his parents' heights, gives **wrong slopes**, as we shall see.

A sample is **truncated** when the cases beyond a limit are missing altogether. We do not know who they were, nor how many. Other examples: an experiment that admits only families with an income below some limit (Hausman & Wise, 1977), a survey of firms with more than ten employees, the patients of a clinic that admits only those above some blood value.

**Truncated regression** tries to recover the line of the full population from the truncated sample. Can it? With real truncated data one never knows, because the truth is missing. So we use data for which we **know** the truth, Galton's heights from [simple linear regression](EXAMPLE_SIMPLE_LINEAR_REGRESSION.Rmd), and make the truncated sample ourselves: an imaginary guard regiment that takes only sons of **68 inches (173 cm) or more**.

## 3. The model step by step, with formulas

### Step 1: the line of the whole population

$$y_i = \beta_0 + \beta_1\, \text{father}_i + \beta_2\, \text{mother}_i + \varepsilon_i, \qquad \varepsilon_i \sim N(0, \sigma^2)$$

We see case $i$ only if $y_i \ge c$, with $c = 68$.

### Step 2: the distribution of those we see

Among all the sons of such parents, the heights have a normal curve around $\mu_i = \beta_0 + \beta_1 \text{father}_i + \beta_2 \text{mother}_i$. Cut off the part below $c$. What remains has an area of $P(y_i \ge c) = \Phi\!\big(\frac{\mu_i - c}{\sigma}\big)$, less than 1. To be a distribution again it must be divided by that area. The result is the **truncated normal** density:

$$f(y_i \mid y_i \ge c) = \frac{\frac{1}{\sigma}\,\phi\!\left(\frac{y_i - \mu_i}{\sigma}\right)}{\Phi\!\left(\frac{\mu_i - c}{\sigma}\right)}$$

($\phi$ is the height of the standard normal curve, `dnorm()`; $\Phi$ the area to the left, `pnorm()`.)

```{r truncated_density}
shape <- do.call(
  rbind,
  lapply(c(66.5, 69, 72), function(mu) {
    h <- seq(60, 80, by = 0.05)
    data.frame(
      h,
      whole = dnorm(h, mu, truth[["sigma"]]),
      seen = ifelse(
```

### Step 3: the average of those we see

The mean of the truncated normal is **above** the line:

$$E(y_i \mid y_i \ge c) = \mu_i + \sigma\, \lambda(\alpha_i), \qquad \lambda(\alpha) = \frac{\phi(\alpha)}{1 - \Phi(\alpha)}, \qquad \alpha_i = \frac{c - \mu_i}{\sigma}$$

$\lambda$ is the **inverse Mills ratio**. It is large when most of the curve is cut off ($\mu_i$ far below $c$) and goes to zero when nothing is. So the mean of the sons in the records is pushed up most where the parents are short. This term, which OLS does not know, is the bias.

### Step 4: maximum likelihood

Add up the logarithms of the densities of step 2, and find the $\beta$'s and $\sigma$ that make the sum as large as possible:

$$\log L = \sum_i \left[ \log \frac{1}{\sigma}\phi\!\left(\frac{y_i - \mu_i}{\sigma}\right) - \log \Phi\!\left(\frac{\mu_i - c}{\sigma}\right) \right]$$

The first part is the ordinary normal likelihood. The second is the correction. It says: *take into account that I could not have seen it otherwise*. The estimates are consistent if the model is right (Amemiya, 1973).

```{r by_hand}
X <- model.matrix(naive); y <- guards$son
minus_loglik <- function(par, X, y, cut) {
  # par: the coefficients, then log(sigma)
  mu <- drop(X %*% par[-length(par)])
  s <- exp(par[length(par)])
  -sum(dnorm(y, mu, s, log = TRUE) - pnorm((mu - cut) / s, log.p = TRUE))
}
start <- c(coef(naive), log(sigma(naive)))                      # start from OLS
hand  <- optim(start, minus_loglik, X = X, y = y, cut = minimum, method = "BFGS", hessian = TRUE,
               control = list(maxit = 1000, reltol = 1e-12, parscale = c(10, 0.1, 0.1, 0.1)))
c(hand$par[-4], sigma = exp(hand$par[[4]]), logLik = -hand$value)
```

### Two kinds of effect

The slope $\beta_1$ is the effect in the whole population. If the question is about the **men in the regiment**, it is the slope of $E(y \mid y \ge c)$, which is smaller:

$$\frac{\partial E(y \mid y \ge c)}{\partial x} = \beta_1 \left[1 - \lambda(\alpha)\,\big(\lambda(\alpha) - \alpha\big)\right]$$

```{r marginal}
mu    <- drop(X %*% b[1:3])
alpha <- (minimum - mu) / b[["sigma"]]
mills <- dnorm(alpha) / pnorm(alpha, lower.tail = FALSE)
shrink <- 1 - mills * (mills - alpha)                   # always between 0 and 1
cbind(
  value = c(
    average_factor = mean(shrink),
    effect_in_the_population = b[["father"]],
    effect_among_the_tall = b[["father"]] * mean(shrink),
    OLS = coef(naive)[["father"]]
  )
)
```

Averaged over the men in the records, the factor is `r f2(mean(shrink))`, so one inch of father goes with `r f2(b[["father"]] * mean(shrink))` inches among the tall sons: about what OLS found. OLS is not "wrong". It answers the question about the regiment, and people read it as an answer about the population.

## 5. Truncated or censored?

A **censored** sample is less damaged. There we know **how many** cases are beyond the limit, and their predictors; only the exact outcome is missing. Suppose that the regiment had written down the parents' heights of the rejected sons, with the note "below 68". That is the [Tobit model](EXAMPLE_TOBIT.Rmd):

```{r tobit}
sons$recorded <- pmax(sons$son, minimum)
tobit <- survreg(
  Surv(recorded, son >= minimum, type = "left") ~ father + mother,
  data = sons,
  dist = "gaussian"
)
rbind(truth = truth[1:3], tobit = coef(tobit), truncated = b[1:3])
rbind(truth = coef(summary(full))[, 2], tobit = sqrt(diag(vcov(tobit)))[1:3], truncated = se[1:3])
```

| | Truncated | Censored |
|---|---|---|
| Cases beyond the limit | missing | present, with the value "beyond the limit" |
| Their predictors | unknown | known |
| Their number | unknown | known |
| Model | truncated regression | Tobit |
| Standard error of the father's slope here | `r f3(se[["father"]])` | `r f3(sqrt(diag(vcov(tobit)))[["father"]])` |

The standard error of the Tobit slope is less than half as large. It is worth a lot to write down even those who are turned away. The most expensive mistake is to treat a censored sample as truncated, by deleting the cases at the limit.

---

## 6. What can go wrong

The correction rests on three assumptions: we know the **cut-off**, the cut-off was applied **strictly**, and the errors are **normal**, right down to the tail that we cannot see. Each can fail.

### Rounding moves the cut-off

Most of Galton's heights are rounded to an inch or a half inch. A son written down as 68 may be 67.75. So the true limit of the records is a bit **below** 68:

```{r rounding}
share_whole <- mean(guards$son %% 1 == 0)
cuts <- c(68, 67.75, 67.5)
moved <- t(sapply(cuts, function(cc) {
  m <- truncreg(son ~ father + mother, data = guards, point = cc, direction = "left")
  c(cut = cc, coef(m)[2:4])
}))
round(rbind(moved, truth = c(NA, truth[2:4])), 3)
```

`r pct(share_whole)` of the heights in the records are whole inches. Taking 67.75 or 67.5 as the limit changes the father's slope from `r f2(moved[1, "father"])` to `r f2(moved[2, "father"])` and `r f2(moved[3, "father"])`. A quarter of an inch matters that much, because the heights are densest near the limit and the correction depends on how the curve is cut there. The right treatment is a likelihood for intervals ("the son is between 67.5 and 68.5"). The smallest honest step is to report the results for more than one limit.

### The errors must be normal

The model extends the curve that it sees into the part that it does not see. If the hidden tail has another shape, it is wrong. A simulation with the real parents' heights and the true line, and three kinds of errors with the same standard deviation:

```{r simulation}
set.seed(17)
Xf   <- model.matrix(full); line <- drop(Xf %*% truth[1:3]); s0 <- truth[["sigma"]]
kinds <- list(normal             = function(n) rnorm(n, 0, s0),
              `long tails (t, 4 df)` = function(n) rt(n, 4) * s0 / sqrt(2),
              `skewed (long to the right)` = function(n) (rgamma(n, 4) - 4) / 2 * s0)
reps <- 500
sim <- lapply(kinds, function(draw) {
  t(replicate(reps, {
    yy <- line + draw(length(line))
    keep <- yy >= minimum
    d <- data.frame(son = yy, father = Xf[, 2], mother = Xf[, 3])[keep, ]
    o <- coef(lm(son ~ father + mother, d))
    m <- try(
      suppressWarnings(truncreg(
        son ~ father + mother,
        data = d,
        point = minimum,
        direction = "left"
      )),
      silent = TRUE
    )
    c(OLS = o[["father"]], truncated = if (inherits(m, "try-error")) NA else coef(m)[["father"]])
  }))
})
bias <- do.call(
  rbind,
  lapply(names(sim), function(k) {
    data.frame(
      errors = k,
      true = truth[["father"]],
      OLS = mean(sim[[k]][, "OLS"]),
      truncated = mean(sim[[k]][, "truncated"], na.rm = TRUE),
      SD_OLS = sd(sim[[k]][, "OLS"]),
      SD_truncated = sd(sim[[k]][, "truncated"], na.rm = TRUE),
      failed = sum(is.na(sim[[k]][, "truncated"]))
    )
  })
)
print(cbind(errors = bias$errors, round(bias[, -1], 3)), row.names = FALSE)
```

- With **normal** errors the truncated regression is right on average (`r f2(bias$truncated[1])`, truth `r f2(truth[["father"]])`), and OLS is far off (`r f2(bias$OLS[1])`).
- With **long tails** it gives `r f2(bias$truncated[2])`, and with **skewed** errors `r f2(bias$truncated[3])`. The correction is biased in both cases. With skewed errors it is off by `r pct(abs(bias$truncated[3] / truth[["father"]] - 1))`.
- Even when it is right on average, it is **imprecise**: the spread of the estimates is `r f1(bias$SD_truncated[1] / bias$SD_OLS[1])` times that of OLS.

Our errors are close to normal (the full data allow us to check), so the method had a fair chance here. With a truly truncated sample this check is impossible: the tail that would show it is the missing one.

### How much can be cut away?

```{r cutoffs}
limits <- c(64, 66, 67, 68, 69, 70)
by_limit <- do.call(
  rbind,
  lapply(limits, function(cc) {
    d <- subset(sons, son >= cc)
    m <- truncreg(son ~ father + mother, data = d, point = cc, direction = "left")
    data.frame(
      limit = cc,
      kept = nrow(d),
      share = nrow(d) / nrow(sons),
      OLS = coef(lm(son ~ father + mother, d))[["father"]],
      truncated = coef(m)[["father"]],
      SE = sqrt(vcov(m)["father", "father"])
    )
  })
)
round(by_limit, 3)
```

With a quarter of the sons missing (limit 68) the estimate is still usable. When more than half of them are missing (limit 70) the standard error is `r f2(by_limit$SE[6])`, more than half of the true slope. And OLS becomes flatter and flatter.

## 7. Borrowing a number: restricted maximum likelihood

The weak part of the estimation is $\sigma$. From the cut curve alone it is hard to tell a wide distribution with a low mean from a narrow one with a high mean, and errors in $\sigma$ carry over to the slopes. Height is a special case, because its spread is nearly the same in all populations that have been measured. A'Hearn (2004) proposed to **fix** $\sigma$ at a known value and to estimate the rest:

```{r restricted}
with_sigma <- function(s_fixed) {
  f <- function(par) minus_loglik(c(par, log(s_fixed)), X = X, y = y, cut = minimum)
  o <- optim(
    coef(naive),
    f,
    method = "BFGS",
    hessian = TRUE,
    control = list(maxit = 1000, reltol = 1e-12, parscale = c(10, 0.1, 0.1))
  )
  list(b = o$par, se = sqrt(diag(solve(o$hessian))))
}
known <- with_sigma(truth[["sigma"]])
rbind(truth = truth[1:3], free_sigma = b[1:3], fixed_sigma = known$b)
rbind(free_sigma = se[1:3], fixed_sigma = known$se)
low <- with_sigma(0.9 * truth[["sigma"]]); high <- with_sigma(1.1 * truth[["sigma"]])
c(
  father_if_sigma_10pct_too_small = low$b[["father"]],
  father_if_sigma_10pct_too_large = high$b[["father"]]
)
```

With $\sigma$ known, the standard error of the father's slope falls from `r f3(se[["father"]])` to `r f3(known$se[["father"]])`. But if the borrowed value is 10% too small or too large, the slope becomes `r f2(low$b[["father"]])` or `r f2(high$b[["father"]])`. Here we cheated and took the true value. In practice the value comes from other studies, and it must be the spread **given the predictors**, not the plain one.

## 8. Things to keep in mind

- **Is it really truncated?** If you know how many cases are beyond the limit, it is censored: use [Tobit](EXAMPLE_TOBIT.Rmd). If the cases are missing because of **another** variable (people who did not answer, women who do not work), it is sample selection, the subject of the [Heckman model](EXAMPLE_HECKMAN_SELECTION.Rmd).
- **Selecting on a predictor is harmless.** Keeping only the sons of tall **fathers** does not bias the slope (it costs precision). Only selection on the outcome does.
- **The limit must be known and strict.** In real armies, short volunteers were let in when soldiers were needed, and the density near the limit thins out gradually. Historians cut at a higher point, where the records are complete.
- **Normality cannot be checked** where it matters. Try other distributions (`crch::trch()` has logistic and *t* errors) and report how much the answer moves.
- **The two limits** can be on both sides: `crch` and `gamlss.tr` handle them.
- **Counts without zeros** (the number of visits of those who visited) need the zero-truncated Poisson or negative binomial.
- **Standard errors here ignore that brothers share their parents.** For the full data we used cluster-robust errors in [simple linear regression](EXAMPLE_SIMPLE_LINEAR_REGRESSION.Rmd); for the truncated model, bootstrap the families.
- **No miracle.** The correction replaces missing information by an assumption. If the conclusion depends on it, say so.

**Method** (data analysis):

> Only sons with a height of at least `r minimum` inches were in the sample (`r nrow(guards)` of the `r nrow(sons)` sons in Galton's records; the limit was imposed for this example). Because selection depended on the outcome, we regressed the son's height on the heights of both parents with a truncated normal regression, estimated by maximum likelihood with a left truncation point of `r minimum`. The coefficients refer to the population without truncation. We examined the sensitivity to the truncation point (67.5 and 67.75 inches, because heights were rounded). Analyses were conducted in R (Version `r paste(R.version$major, R.version$minor, sep = ".")`; R Core Team, `r R.version$year`) with the package truncreg (Croissant & Zeileis, 2026).

**Results:**

> In the truncated regression, the son's height increased with that of the father, *b* = `r f2(b[["father"]])`, *SE* = `r f2(se[["father"]])`, 95% CI [`r f2(b[["father"]] - 1.96 * se[["father"]])`, `r f2(b[["father"]] + 1.96 * se[["father"]])`], *z* = `r f2(z[["father"]])`, *p* `r pval(pv[["father"]])`, and of the mother, *b* = `r f2(b[["mother"]])`, *SE* = `r f2(se[["mother"]])`, 95% CI [`r f2(b[["mother"]] - 1.96 * se[["mother"]])`, `r f2(b[["mother"]] + 1.96 * se[["mother"]])`], *z* = `r f2(z[["mother"]])`, *p* `r pval(pv[["mother"]])` (Table 1). ## 10. Summary

| | |
|---|---|
| **When** | Cases beyond a known limit of the **outcome** are missing from the sample |
| **Why not OLS** | The errors of those who remain are related to the predictors: slopes too flat |
| **The model** | Truncated normal: the normal density divided by the probability of being seen |
| **How (R)** | `truncreg::truncreg(y ~ x, data, point = c, direction = "left")` |
| **Coefficients** | For the whole population; for those in the sample, multiply by $1 - \lambda(\lambda - \alpha)$ |
| **Censored instead** | If the number and predictors of the others are known: [Tobit](EXAMPLE_TOBIT.Rmd), much more precise |
| **Assumptions** | Known and strict limit, normal errors with constant variance |
| **Weak points** | Imprecise, and sensitive to rounding, the limit and the shape of the errors |
| **Related pages** | [Tobit](EXAMPLE_TOBIT.Rmd), [simple linear regression](EXAMPLE_SIMPLE_LINEAR_REGRESSION.Rmd) |
