Description

Comparing the mean scores of two groups assumes that the questionnaire measures the same thing in the same way in both. Measurement invariance tests that assumption, in a sequence of increasingly strict multi-group confirmatory factor models (Vandenberg & Lance, 2000; Putnick & Bornstein, 2016):

Level Constraint across groups What it allows
Configural Same factor structure The construct has the same form
Metric (weak) Equal loadings Comparing correlations and regressions
Scalar (strong) Equal loadings and intercepts Comparing means

If scalar invariance fails, a group difference in observed scores mixes a difference in the trait with differences in how particular items or facets work in each group. Partial invariance (Byrne, Shavelson & Muthén, 1989) frees the intercepts that differ and compares latent means through the indicators that remain invariant. A step is accepted here when it lowers CFI by no more than .010 and raises RMSEA by no more than .015 (Chen, 2007); chi-square tests are not used, because with thousands of respondents per group they reject any constraint.

The questionnaire is the IPIP-NEO-120 (Johnson, 2014): 120 public-domain items from the International Personality Item Pool that measure the 30 facets of the NEO PI-R five-factor model, four items per facet and six facets per domain. Respondents rated each item from 1 (very inaccurate) to 5 (very accurate). The tests below ask whether its scores can be compared between men and women, between 12 countries and between age groups, and what the comparisons show where they are allowed.

Data and cleaning

Johnson made the 619,150 protocols collected online between 2001 and 2011 freely available on the Open Science Framework, with the scoring key. data/prepare_ipipneo120.R applies the rules below. Johnson had already screened the protocols, so the consistency check (the even-odd index of Johnson, 2005, on the 30 pairs of half-facets) removes very few; most exclusions are incomplete protocols.

The facets that load more on another domain than on their own each make sense from their content: activity level and assertiveness go with the energetic, goal-directed side of Conscientiousness, self-consciousness with low Extraversion, immoderation (giving in to cravings) with low Conscientiousness, emotionality (openness to feelings) with Neuroticism, and dutifulness shares Conscientiousness with Agreeableness. A one-factor model per domain therefore cannot fit perfectly, which the next step deals with.

Step 1: A Baseline Model for Each Domain

Invariance is tested on a model that fits in each group, so the first step is a model that fits in the whole sample. Each domain is modelled as one factor measured by its six facet scores. A single factor rarely fits a Big Five domain perfectly, because some facets share variance beyond the domain (Depression and Self-Consciousness, for example, are closer to each other than to Anger). Residual covariances are added from the modification indices in the US sample, the largest first and at most three per domain, and kept fixed in form for all the comparisons.

# Cohen's d of women minus men, used for the domains and facets below
cohen_d <- function(x, g) {
  m <- tapply(x, g, mean); v <- tapply(x, g, var); n <- tapply(x, g, length)
  unname((m["Female"] - m["Male"]) / sqrt(sum((n - 1) * v) / (sum(n) - 2)))
}
facet_d <- data.frame(facet = facet_codes, d = sapply(facet_codes, function(f) cohen_d(us[[f]], us$sex)))

Metric invariance holds in 5 of the 5 domains: the facets measure the domains with the same loadings for men and women. Full scalar invariance fails in every domain; it holds once some facet intercepts are freed. A freed intercept means that men and women with the same level of the domain score differently on that facet. In Agreeableness, for example, women score much higher than men on Sympathy (d = 0.57), Altruism (0.50) and Modesty (0.45), but not on Trust (0.01), so the facets cannot all share one domain-level difference (the facet chart below).

Costa, Terracciano and McCrae (2001), across 26 cultures, found that women score higher than men on Neuroticism and Agreeableness, and that some facets show differences in the opposite direction to their domain: women higher on openness to feelings, men higher on assertiveness and openness to ideas. The same appears here: women score higher on Emotionality (openness to feelings, d = 0.62), men on Assertiveness (-0.13) and Intellect (openness to ideas, -0.20). The comparison of latent and observed differences is where invariance testing changes the conclusion. For Neuroticism the latent difference (0.65) is larger than the observed one (0.43). For Openness the two even differ in sign: in the observed domain score women score higher (+0.20), because they score higher on the facets whose intercepts had to be freed (Emotionality d = 0.62, Artistic Interests d = 0.34, Liberalism d = 0.16); the latent difference, which rests on the invariant facets (Imagination, Adventurousness, Intellect), slightly favours men (-0.24). Which sex is “more open” depends on which facets are treated as measuring Openness in the same way for both, which is exactly the question measurement invariance answers.

```{r load, include=FALSE}
baseline_model <- function(dom, data, max_add = 3) {
  model <- paste0(dom, " =~ ", paste(grep(paste0("^", dom), facet_codes, value = TRUE), collapse = " + "))
  fit   <- cfa(model, data = data, estimator = "MLR")
  start <- fitMeasures(fit, fit_names)
  added <- character(0)
  while (length(added) < max_add &&
         (fitMeasures(fit, "cfi.robust") < 0.95 || fitMeasures(fit, "rmsea.robust") > 0.08)) {
    mi    <- modindices(fit, sort. = TRUE)
    mi    <- mi[mi$op == "~~", ][1, ]
    added <- c(added, paste(mi$lhs, "~~", mi$rhs))
    model <- paste(c(model, tail(added, 1)), collapse = "\n")
    fit   <- cfa(model, data = data, estimator = "MLR")
  }
  list(model = model, added = added, start = start, final = fitMeasures(fit, fit_names))
}

# Steps 2-4: configural, metric (equal loadings) and scalar (equal loadings and intercepts)
# models; if scalar invariance fails by Chen's (2007) criteria, free the intercept with the
# largest score test, one at a time (partial invariance), keeping at least two invariant
invariance <- function(model, data, group, dom) {
  groups <- levels(droplevels(data[[group]]))
  run <- function(equal, partial = character(0))
    cfa(model, data = data, group = group, group.label = groups, group.equal = equal,
        group.partial = partial, estimator = "MLR")
  fits <- list(configural = run(character(0)), metric = run("loadings"),
               scalar = run(c("loadings", "intercepts")))
  fm <- t(sapply(fits, fitMeasures, fit_names))
  passes <- function(f) fitMeasures(f, "cfi.robust") - fm["metric", 1] >= -0.010 &&
                        fitMeasures(f, "rmsea.robust") - fm["metric", 2] <= 0.015
  final <- fits$scalar
  freed <- character(0)
  n_ind <- length(grep(paste0("^", dom), facet_codes))
  while (!passes(final) && length(freed) < n_ind - 2) {
    score <- lavTestScore(final)$uni
    pt    <- parTable(final)
    row   <- match(score$lhs, pt$plabel)
    is_int <- pt$op[row] == "~1"
    chi2  <- tapply(score$X2[is_int], pt$lhs[row][is_int], sum)
    freed <- c(freed, names(which.max(chi2)))
    final <- run(c("loadings", "intercepts"), paste(freed, "~1"))
  }
  if (length(freed)) fm <- rbind(fm, partial = fitMeasures(final, fit_names))
  table <- data.frame(step = rownames(fm), fm, row.names = NULL)
  table$d_cfi   <- c(NA, fm[2, 1] - fm[1, 1], fm[-(1:2), 1] - fm[2, 1])
  table$d_rmsea <- c(NA, fm[2, 2] - fm[1, 2], fm[-(1:2), 2] - fm[2, 2])
  metric_ok <- table$d_cfi[2] >= -0.010 && table$d_rmsea[2] <= 0.015
  list(table = table, freed = freed, fit = final, groups = groups, passes = passes(final), metric_ok = metric_ok)
}
```

## Description

Comparing the mean scores of two groups assumes that the questionnaire measures the same thing in the same way in both. **Measurement invariance** tests that assumption, in a sequence of increasingly strict multi-group confirmatory factor models (Vandenberg & Lance, 2000; Putnick & Bornstein, 2016):

| Level | Constraint across groups | What it allows |
|---|---|---|
| **Configural** | Same factor structure | The construct has the same form |
| **Metric** (weak) | Equal loadings | Comparing correlations and regressions |
| **Scalar** (strong) | Equal loadings and intercepts | Comparing **means** |

If scalar invariance fails, a group difference in observed scores mixes a difference in the trait with differences in how particular items or facets work in each group. **Partial invariance** (Byrne, Shavelson & Muthén, 1989) frees the intercepts that differ and compares latent means through the indicators that remain invariant. A step is accepted here when it lowers CFI by no more than .010 and raises RMSEA by no more than .015 (Chen, 2007); chi-square tests are not used, because with thousands of respondents per group they reject any constraint.

The questionnaire is the **IPIP-NEO-120** (Johnson, 2014): 120 public-domain items from the [International Personality Item Pool](https://ipip.ori.org/) that measure the 30 facets of the NEO PI-R five-factor model, four items per facet and six facets per domain. Respondents rated each item from 1 (*very inaccurate*) to 5 (*very accurate*). The tests below ask whether its scores can be compared between **men and women**, between **12 countries** and between **age groups**, and what the comparisons show where they are allowed.

The facets that load more on another domain than on their own each make sense from their content: activity level and assertiveness go with the energetic, goal-directed side of Conscientiousness, self-consciousness with low Extraversion, immoderation (giving in to cravings) with low Conscientiousness, emotionality (openness to feelings) with Neuroticism, and dutifulness shares Conscientiousness with Agreeableness. A one-factor model per domain therefore cannot fit perfectly, which the next step deals with.

## Step 1: A Baseline Model for Each Domain

Invariance is tested on a model that fits in each group, so the first step is a model that fits in the whole sample. Each domain is modelled as one factor measured by its six facet scores. A single factor rarely fits a Big Five domain perfectly, because some facets share variance beyond the domain (Depression and Self-Consciousness, for example, are closer to each other than to Anger). Residual covariances are added from the modification indices in the US sample, the largest first and at most three per domain, and kept fixed in form for all the comparisons.

## Step 2: Men and Women

```{r sex}

# Cohen's d of women minus men, used for the domains and facets below
cohen_d <- function(x, g) {
  m <- tapply(x, g, mean); v <- tapply(x, g, var); n <- tapply(x, g, length)
  unname((m["Female"] - m["Male"]) / sqrt(sum((n - 1) * v) / (sum(n) - 2)))
}
facet_d <- data.frame(facet = facet_codes, d = sapply(facet_codes, function(f) cohen_d(us[[f]], us$sex)))
```

Metric invariance holds in `r 5 - length(metric_fails(inv_sex))` of the 5 domains: the facets measure the domains with the same loadings for men and women. Full scalar invariance fails in every domain; it holds once some facet intercepts are freed. A freed intercept means that men and women with the same level of the domain score differently on that facet. In Agreeableness, for example, women score much higher than men on Sympathy (*d* = `r sprintf("%.2f", facet_d$d[facet_d$facet == "A6"])`), Altruism (`r sprintf("%.2f", facet_d$d[facet_d$facet == "A3"])`) and Modesty (`r sprintf("%.2f", facet_d$d[facet_d$facet == "A5"])`), but not on Trust (`r sprintf("%.2f", facet_d$d[facet_d$facet == "A1"])`), so the facets cannot all share one domain-level difference (the facet chart below).

Costa, Terracciano and McCrae (2001), across 26 cultures, found that women score higher than men on Neuroticism and Agreeableness, and that some facets show differences in the opposite direction to their domain: women higher on openness to feelings, men higher on assertiveness and openness to ideas. The same appears here: women score higher on Emotionality (openness to feelings, *d* = `r sprintf("%.2f", facet_d$d[facet_d$facet == "O3"])`), men on Assertiveness (`r sprintf("%.2f", facet_d$d[facet_d$facet == "E3"])`) and Intellect (openness to ideas, `r sprintf("%.2f", facet_d$d[facet_d$facet == "O5"])`). The comparison of latent and observed differences is where invariance testing changes the conclusion. For Neuroticism the latent difference (`r sprintf("%.2f", sex_diff$latent[sex_diff$domain == "Neuroticism"])`) is larger than the observed one (`r sprintf("%.2f", sex_diff$observed[sex_diff$domain == "Neuroticism"])`). For **Openness** the two even differ in sign: in the observed domain score women score higher (`r sprintf("%+.2f", sex_diff$observed[sex_diff$domain == "Openness"])`), because they score higher on the facets whose intercepts had to be freed (`r paste0(facet_names[inv_sex$O$freed], " *d* = ", sprintf("%.2f", facet_d$d[match(inv_sex$O$freed, facet_d$facet)]), collapse = ", ")`); the latent difference, which rests on the invariant facets (`r paste(facet_names[setdiff(grep("^O", facet_codes, value = TRUE), inv_sex$O$freed)], collapse = ", ")`), slightly favours men (`r sprintf("%+.2f", sex_diff$latent[sex_diff$domain == "Openness"])`). Which sex is "more open" depends on which facets are treated as measuring Openness in the same way for both, which is exactly the question measurement invariance answers.

## Facet-Level Invariance Map

The domain models above use facet scores. The same tests can be run inside each facet, with its four items as indicators, which is a much stricter look at the items themselves.

```{r facetmap, fig.width=8, fig.height=8, dev='png', fig.retina=2}
facet_step <- function(f, data, group) {
  model <- paste0("F =~ ", paste(key$item[key$facet_code == f], collapse = " + "))
  groups <- levels(droplevels(data[[group]]))
  cfi <- sapply(list(character(0), "loadings", c("loadings", "intercepts")), function(eq)
    fitMeasures(cfa(model, data = data, group = group, group.label = groups, group.equal = eq,
                    estimator = "MLR"), "cfi.robust"))
  data.frame(facet = f, configural = cfi[1], metric = cfi[2] - cfi[1], scalar = cfi[3] - cfi[2])
```
