Is Greece a Good Place to Invest? Risk, Costs, the State and the Courts

  • Show All Code
  • Hide All Code
  • View Source
Published

November 12, 2026

What is this?

Is Greece a good place to invest? The answer depends on the investor, whether they buy Greek bonds, build a factory or open a business, but some questions matter to all of them, and each can be measured in the same way for every EU country:

  1. Do investors invest in Greece? What the economy invests, and what comes from abroad.
  2. Is the country a financial risk? The interest rate on its bonds, and its debt.
  3. What does it cost to produce there? Wages and electricity.
  4. How well does the state work? Bureaucracy, regulation, the rule of law and corruption.
  5. Do the courts protect investors? How long a case takes, and what companies think.
  6. Can goods move? Ports, roads and customs.

The data come from Eurostat, the statistical office of the EU, and from the World Bank, and are downloaded when the document is knitted, so the charts show the latest figures. Two sets of figures come from the European Commission’s 2026 EU Justice Scoreboard, a report, and are typed in below with the figure they come from. The charts of countries show the 27 EU countries, with Greece in red and the EU as a whole, where there is a figure for it, in blue.

Rankings of countries are a starting point, not a verdict: an investor in a Greek hotel and an investor in a Greek factory face different costs and different risks.

}

world_bank <- function(indicator, years = "2000:2025") {
  url <- paste0("https://api.worldbank.org/v2/country/", paste(iso3, collapse = ";"), "/indicator/", indicator,
                "?format=json&per_page=5000&date=", years)

  x <- data.frame(geo = names(iso3)[match(x$countryiso3code, iso3)], time = as.numeric(x$date), values = x$value)
  x[!is.na(x$values), ]
}

# the EU countries and the EU in the latest year with data for Greece and for most EU countries
latest <- function(x, at_least = 20) {
  x <- x[x$geo %in% c(eu_codes, "EU27_2020"), ]
  for (y in sort(unique(x$time[x$geo == "EL"]), decreasing = TRUE)) {
    if (sum(x$geo %in% eu_codes & x$time == y) >= at_least) return(x[x$time == y, ])
  }
  stop("No year with data for Greece and for most EU countries")
}

ordinal <- function(k) {
  paste0(k, if (k %% 100 %in% 11:13) "th" else c("th", "st", "nd", "rd", rep("th", 6))[k %% 10 + 1])
}
# the place of Greece among the EU countries, counted from the nearer end: "the highest",
# "the 3rd highest", "the 2nd lowest", ...
place <- function(x) {
  v <- x$values[x$geo %in% eu_codes]
  from_top <- sum(v > greece(x)) + 1
  from_bottom <- sum(v < greece(x)) + 1
  k <- min(from_top, from_bottom)
  end <- if (from_top <= from_bottom) "highest" else "lowest"
  paste("the", if (k == 1) end else paste(ordinal(k), end))
}

# the source of a chart, as a note under it, and the common layout
chart <- function(p, title, source, y_title = "", y_axis = list(), x_axis = list(), annotations = list(), margin = list(t = 70, b = 90), note_y = -0.16, ...) {
  note <- list(
    text = paste("Source:", source), xref = "paper", yref = "paper", x = 0, y = note_y,
    xanchor = "left", yanchor = "top", showarrow = FALSE, font = list(size = 11, color = dark_gray)
  )
  layout(p,
    title = list(text = title, x = 0.02, xanchor = "left", y = 0.97, yanchor = "top"),
    yaxis = modifyList(list(title = y_title), y_axis),
    xaxis = modifyList(list(title = ""), x_axis),
    margin = margin,
    annotations = c(annotations, list(note)),
    ...
  ) %>% config(displaylogo = FALSE)
}
legend_top <- list(orientation = "h", x = 0, y = 1.02, yanchor = "bottom")

# the EU countries from the highest to the lowest, Greece in red and the EU in blue; where there is
# no figure for the EU, a dotted line marks the median country
ranking <- function(x, title, source, suffix = "%", digits = 1) {
  x <- x[x$geo %in% c(eu_codes, "EU27_2020"), ]
  x$name <- eu_name[x$geo]
  x <- x[order(x$values), ]
  x$name <- factor(x$name, levels = x$name)
  lines <- list()
  notes <- list()
  if (!any(x$geo == "EU27_2020")) {
    m <- median(x$values[x$geo %in% eu_codes])
    lines <- list(list(type = "line", x0 = m, x1 = m, y0 = 0, y1 = 1, yref = "paper", line = list(color = blue, width = 2, dash = "dot")))
    notes <- list(list(x = m, y = 1, yref = "paper", text = "Median EU country", xanchor = "left", yanchor = "bottom",
                       xshift = 4, showarrow = FALSE, font = list(color = blue)))
  }
  # the source 45 px under the plot, below the numbers of the axis
  height <- knitr::opts_current$get("out.height.px")
  if (!is.numeric(height)) height <- 864
  plot_ly(x,
    x = ~values, y = ~name, type = "bar", orientation = "h",
    marker = list(color = ifelse(x$geo == "EL", greek_red, ifelse(x$geo == "EU27_2020", blue, gray))),
    hovertemplate = paste0("%{y}: %{x:.", digits, "f}", suffix, "<extra></extra>")
  ) %>%
    chart(paste0(title, ", ", floor(x$time[1])), source, x_axis = list(ticksuffix = suffix), shapes = lines,
          annotations = notes, margin = list(l = 130, t = 70, b = 90), note_y = -45 / (height - 70 - 90))
}

# Greece and a second line (the EU, or another country) over time
two_lines <- function(a, b, name_b, title, source, y_title, suffix = "%", digits = 1, y_axis = list(), ...) {
  plot_ly(a, x = ~time, y = ~values, type = "scatter", mode = "lines", name = "Greece",
    line = list(color = greek_red, width = 3),
    hovertemplate = paste0("%{x}: %{y:.", digits, "f}", suffix, "<extra>Greece</extra>")) %>%
    add_trace(data = b, x = ~time, y = ~values, type = "scatter", mode = "lines", name = name_b,
      line = list(color = blue, width = 3), inherit = FALSE,
      hovertemplate = paste0("%{x}: %{y:.", digits, "f}", suffix, "<extra>", name_b, "</extra>")) %>%
    chart(title, source, y_title, y_axis = modifyList(list(ticksuffix = suffix), y_axis), legend = legend_top, ...)
}

1. Do investors invest in Greece?

Code 
investment_line <- series(investment_all, "EL")
peak_year <- investment_line$time[which.max(investment_line$values)]
low_year <- investment_line$time[which.min(investment_line$values)]

Less than in almost all the EU, though more than at the bottom of the crisis. In 2025, Greece invested 18.0% of its GDP in buildings, machines, equipment and software, against 21.5% in the EU: the 3rd lowest share of the 27 countries. Before the crisis it invested more than the EU, 25.9% of GDP in 2000; by 2019 it had fallen to 11.0%. An economy that invests less than it did, and less than its neighbours, adds little to what it can produce.

2. Is the country a financial risk?

Code 
# since 2001, when Greece joined the euro: before, its bonds were in drachmas
greek_yields <- series(yields_all[yields_all$time >= 2001, ], "EL")
german_yields <- series(yields_all[yields_all$time >= 2001, ], "DE")
spread <- merge(greek_yields, german_yields, by = "time", suffixes = c("_el", "_de"))
spread$values <- spread$values_el - spread$values_de
worst <- spread[which.max(spread$values), ]

The markets no longer see Greece as a high risk, but its debt is the highest in the EU.

The interest rate that a country pays on its bonds is what the markets think of its risk. In 2012, in the debt crisis, Greece’s 10-year bonds paid 22.5% a year, 21.0 points more than Germany’s. In 2025 they paid 3.4%, only 0.8 points more than Germany’s and no more than the EU average of 3.4%. The credit rating agencies agree. They cut Greece to junk in the crisis, but S&P, Fitch, DBRS and Scope have rated it investment grade again since 2023, and Moody’s since 2025, so the large funds that may hold only such bonds can buy Greek debt again.

The debt that worried the markets is still there: 145.4% of GDP in 2025, the highest in the EU, where it is 81.5%, though down from 209.4% in 2020. Much of it is owed to other euro countries on long terms and low interest rates, which is why the markets accept it. The economy grew by 2.1% in 2025, against 1.4% in the EU.

3. What does it cost to produce there?

Cheap labour, electricity at about the EU’s price.

An hour of work cost employers in Greece €18.2 in 2025, wages and the employers’ contributions together, against €34.9 in the EU: the 6th lowest of 26 countries. Labour is cheap partly because it produces little: an hour of work in Greece produces about half of what it produces on average in the EU (see Greece at Work).

Electricity matters most for factories, data centres and cold storage. In the first half of 2026, a business that uses 2 to 20 GWh a year, a medium-sized factory, paid 16.0 cents per kWh in Greece before VAT, against 15.6 cents in the EU: the 11th highest of 27 countries. Renewables, which keep the price of electricity from following the price of gas, gave 26.9% of the energy used in Greece in 2025, against 26.2% in the EU.

4. How well does the state work?

g <- function(name, column) gov_table[[column]][gov_table$indicator == name]

Bureaucracy and law and order: in the bottom third of the EU. The World Bank combines surveys of companies, households and experts into four measures of how well the state works: how good the public administration is (government effectiveness), how well regulation lets private business work (regulatory quality), how far contracts, property rights, the police and the courts can be relied on (rule of law), and how little public power is used for private gain (control of corruption). Each runs from about -2.5 to +2.5. In 2025, Greece had the 2nd lowest score of the EU for government effectiveness, the 6th lowest for regulatory quality, the 3rd lowest for the rule of law and the 7th lowest for control of corruption. All four are better than those of most countries in the world, but they are below the EU’s middle.

5. Do the courts protect investors?

Greek courts are the slowest in the EU, and Greek companies trust them the least.

An investor needs to know that a contract will be enforced. In 2024, a civil or commercial dispute took about 740 days to be resolved at first instance in Greece, more than two years before any appeal: the longest of the EU countries with data. Cyprus and Italy, the next slowest, needed about 680 and 590 days, and most EU countries fewer than 300 (2026 EU Justice Scoreboard, Figure 5, from the CEPEJ study of the Council of Europe).

Companies see it. Asked in 2026 how well the law and the courts protect their investments, 25% of Greek companies said that they were confident, the lowest share in the EU, where it is 56% in the median country; 70% were not confident, and 36% very unconfident, more than in any other country.

6. Can goods move?

Ports, roads and customs: close to the EU’s middle. The World Bank’s Logistics Performance Index scores, from 1 to 5, how well a country’s customs, ports, roads and railways, shipping and tracking work, from a survey of the companies that move goods. In 2022, Greece scored 3.70, against 3.60 in the median EU country: the 10th highest of 27 countries. Its ports, Piraeus first among them, are among the busiest of the Mediterranean.

So, is Greece a good place to invest?

It depends on what an investor needs, and the data show which needs Greece meets:

  1. Financial risk is low again: the bonds pay about what the EU’s pay, and the rating agencies call them investment grade, though the debt, 145% of GDP, is the EU’s highest.
  2. Costs are low: labour costs €18.2 an hour against €34.9 in the EU, and electricity is at about the EU’s price.
  3. Investors are coming back, but not enough: foreign investment has risen, yet the economy invests 18% of its GDP, the 3rd lowest share in the EU.
  4. The state is the weak point: the public administration, regulation, the rule of law and the control of corruption are all in the bottom part of the EU.
  5. And the courts most of all: about 740 days for a first judgment, the longest in the EU, and 25% of Greek companies confident that the law protects their investments, the lowest share.

For an investor who needs cheap labour and a growing market, and seldom goes to court, Greece has become a reasonable bet. For one whose investment depends on contracts and permits, the slow courts and the bureaucracy are the risk to price in.

## What is this?

Is Greece a good place to invest? The answer depends on the investor, whether they buy Greek bonds, build a factory or open a business, but some questions matter to all of them, and each can be measured in the same way for every EU country:

1. **Do investors invest in Greece?** What the economy invests, and what comes from abroad.
2. **Is the country a financial risk?** The interest rate on its bonds, and its debt.
3. **What does it cost to produce there?** Wages and electricity.
4. **How well does the state work?** Bureaucracy, regulation, the rule of law and corruption.
5. **Do the courts protect investors?** How long a case takes, and what companies think.
6. **Can goods move?** Ports, roads and customs.

The data come from **Eurostat**, the statistical office of the EU, and from the **World Bank**, and are downloaded when the document is knitted, so the charts show the latest figures. Two sets of figures come from the European Commission's *2026 EU Justice Scoreboard*, a report, and are typed in below with the figure they come from. The charts of countries show the 27 EU countries, with Greece in red and the EU as a whole, where there is a figure for it, in blue.

Rankings of countries are a starting point, not a verdict: an investor in a Greek hotel and an investor in a Greek factory face different costs and different risks.

# the place of Greece among the EU countries, counted from the nearer end: "the highest",
# "the 3rd highest", "the 2nd lowest", ...
place <- function(x) {
  v <- x$values[x$geo %in% eu_codes]

  end <- if (from_top <= from_bottom) "highest" else "lowest"
  paste("the", if (k == 1) end else paste(ordinal(k), end))
}

# the source of a chart, as a note under it, and the common layout
chart <- function(p, title, source, y_title = "", y_axis = list(), x_axis = list(), annotations = list(), margin = list(t = 70, b = 90), note_y = -0.16, ...) {
  note <- list(
    text = paste("Source:", source), xref = "paper", yref = "paper", x = 0, y = note_y,
    xanchor = "left", yanchor = "top", showarrow = FALSE, font = list(size = 11, color = dark_gray)
  )
  layout(p,
    title = list(text = title, x = 0.02, xanchor = "left", y = 0.97, yanchor = "top"),
    yaxis = modifyList(list(title = y_title), y_axis),
    xaxis = modifyList(list(title = ""), x_axis),
    margin = margin,
    annotations = c(annotations, list(note)),
    ...
  ) %>% config(displaylogo = FALSE)
}
legend_top <- list(orientation = "h", x = 0, y = 1.02, yanchor = "bottom")

# the EU countries from the highest to the lowest, Greece in red and the EU in blue; where there is
# no figure for the EU, a dotted line marks the median country
ranking <- function(x, title, source, suffix = "%", digits = 1) {
  x <- x[x$geo %in% c(eu_codes, "EU27_2020"), ]
  x$name <- eu_name[x$geo]
  x <- x[order(x$values), ]
  x$name <- factor(x$name, levels = x$name)
  lines <- list()
  notes <- list()
  if (!any(x$geo == "EU27_2020")) {
    m <- median(x$values[x$geo %in% eu_codes])
    lines <- list(list(type = "line", x0 = m, x1 = m, y0 = 0, y1 = 1, yref = "paper", line = list(color = blue, width = 2, dash = "dot")))
    notes <- list(list(x = m, y = 1, yref = "paper", text = "Median EU country", xanchor = "left", yanchor = "bottom",
                       xshift = 4, showarrow = FALSE, font = list(color = blue)))
  }
  # the source 45 px under the plot, below the numbers of the axis
  height <- knitr::opts_current$get("out.height.px")
  if (!is.numeric(height)) height <- 864
  plot_ly(x,
    x = ~values, y = ~name, type = "bar", orientation = "h",
    marker = list(color = ifelse(x$geo == "EL", greek_red, ifelse(x$geo == "EU27_2020", blue, gray))),
    hovertemplate = paste0("%{y}: %{x:.", digits, "f}", suffix, "<extra></extra>")
  ) %>%
    chart(paste0(title, ", ", floor(x$time[1])), source, x_axis = list(ticksuffix = suffix), shapes = lines,
          annotations = notes, margin = list(l = 130, t = 70, b = 90), note_y = -45 / (height - 70 - 90))
}

    chart(title, source, y_title, y_axis = modifyList(list(ticksuffix = suffix), y_axis), legend = legend_top, ...)
}

## 2. Is the country a financial risk?

```{r risk_numbers}
# since 2001, when Greece joined the euro: before, its bonds were in drachmas
greek_yields <- series(yields_all[yields_all$time >= 2001, ], "EL")
german_yields <- series(yields_all[yields_all$time >= 2001, ], "DE")
spread <- merge(greek_yields, german_yields, by = "time", suffixes = c("_el", "_de"))
spread$values <- spread$values_el - spread$values_de
worst <- spread[which.max(spread$values), ]
now <- spread[nrow(spread), ]
debt_line <- series(debt_all, "EL")
debt_peak <- debt_line[which.max(debt_line$values), ]
```

**The markets no longer see Greece as a high risk, but its debt is the highest in the EU.**

The interest rate that a country pays on its bonds is what the markets think of its risk. In `r worst$time`, in the debt crisis, Greece's 10-year bonds paid `r one(worst$values_el)`% a year, `r one(worst$values)` points more than Germany's. In `r now$time` they paid `r one(now$values_el)`%, only `r one(now$values)` points more than Germany's and `r if (greece(yields) <= eu(yields)) "no more than" else "a little more than"` the EU average of `r one(eu(yields))`%. The credit rating agencies agree. They cut Greece to *junk* in the crisis, but S&P, Fitch, DBRS and Scope have rated it *investment grade* again since 2023, and Moody's since 2025, so the large funds that may hold only such bonds can buy Greek debt again.

Much of it is owed to other euro countries on long terms and low interest rates, which is why the markets accept it. The economy grew by `r percent(greece(growth), 1)` in `r growth$time[1]`, against `r percent(eu(growth), 1)` in the EU.

## 3. What does it cost to produce there?

**Cheap labour, electricity at about the EU's price.**

An hour of work cost employers in Greece €`r one(greece(labour))` in `r labour$time[1]`, wages and the employers' contributions together, against €`r one(eu(labour))` in the EU: `r place(labour)` of `r countries(labour)` countries. Labour is cheap partly because it produces little: an hour of work in Greece produces about half of what it produces on average in the EU (see [Greece at Work](ILLUSTRATION_GREEK_WORKFORCE.Rmd)).

## 5. Do the courts protect investors?

**Greek courts are the slowest in the EU, and Greek companies trust them the least.**

An investor needs to know that a contract will be enforced. In 2024, a civil or commercial dispute took about `r court_days[["EL"]]` days to be resolved at first instance in Greece, more than two years before any appeal: the longest of the EU countries with data. Cyprus and Italy, the next slowest, needed about `r court_days[["CY"]]` and `r court_days[["IT"]]` days, and most EU countries fewer than 300 (*2026 EU Justice Scoreboard*, Figure 5, from the CEPEJ study of the Council of Europe).

```{r protection_numbers}
protection_eu <- protection[protection$geo %in% eu_codes, ]
unconfident <- function(code) {
  row <- protection[protection$geo == code, ]
  row$fairly_unconfident + row$very_unconfident
}
```

Companies see it. Asked in 2026 how well the law and the courts protect their investments, `r percent(greece(protection))` of Greek companies said that they were confident, `r place(protection)` share in the EU, where it is `r percent(median_eu(protection))` in the median country; `r percent(unconfident("EL"))` were not confident, and `r percent(protection$very_unconfident[protection$geo == "EL"])` *very* unconfident, more than in any other country.

## So, is Greece a good place to invest?

It depends on what an investor needs, and the data show which needs Greece meets:

1. **Financial risk is low again**: the bonds pay about what the EU's pay, and the rating agencies call them investment grade, though the debt, `r percent(greece(debt))` of GDP, is the EU's highest.
2. **Costs are low**: labour costs €`r one(greece(labour))` an hour against €`r one(eu(labour))` in the EU, and electricity is at about the EU's price.
3. **Investors are coming back, but not enough**: foreign investment has risen, yet the economy invests `r percent(greece(investment))` of its GDP, `r place(investment)` share in the EU.
4. **The state is the weak point**: the public administration, regulation, the rule of law and the control of corruption are all in the bottom part of the EU.
5. **And the courts most of all**: about `r court_days[["EL"]]` days for a first judgment, the longest in the EU, and `r percent(greece(protection))` of Greek companies confident that the law protects their investments, `r place(protection)` share.

For an investor who needs cheap labour and a growing market, and seldom goes to court, Greece has become a reasonable bet. For one whose investment depends on contracts and permits, the slow courts and the bureaucracy are the risk to price in.
