Greece at Work: Education, Skills, Jobs and Crime Compared with the EU

  • Show All Code
  • Hide All Code
  • View Source
Published

November 11, 2026

What is this?

Are Greeks good workers? How much schooling do they have, do they know maths, can they use a computer, do they find work, and is there much crime? None of these questions has a single number for an answer, but each has measures that every EU country collects in the same way, so Greece can be compared with the rest of the EU:

  1. How much schooling do Greeks have?
  2. What do they know? Maths, reading and science at 15, computer skills, and learning as adults.
  3. Do they find work?
  4. How hard do they work, and how much do they produce?
  5. Do their jobs use their education?
  6. Is there much crime?

The data come from Eurostat, the statistical office of the EU. They are downloaded when the document is knitted, so the charts show the latest figures. The charts of countries show the 27 EU countries, with Greece in red and the EU as a whole in blue.

What these numbers can and cannot say. They describe what the schools, the firms and the courts of Greece produce, not what Greeks are born with: no statistic measures how intelligent or how hard-working a people is. A test at 15 measures what a school system has taught by then. Output per hour measures the firms, the machines and the way the economy is organised as much as the people who work in it. And recorded crime depends on how often people go to the police, and on how each country counts offences.

eurostat_values <- function(id, filters) {
  x <- get_eurostat(id, filters = filters, time_format = "num", cache = FALSE)
  x <- as.data.frame(x[!is.na(x$values), ])
  x[order(x$time), ]
}

# the EU countries and the EU in the latest year with data for Greece and for most EU countries
latest <- function(x) {
  x <- x[x$geo %in% c(eu_codes, "EU27_2020"), ]
  for (y in sort(unique(x$time[x$geo == "EL"]), decreasing = TRUE)) {
    if (sum(x$geo %in% eu_codes & x$time == y) >= 20) return(x[x$time == y, ])
  }
  stop("No year with data for Greece and for most EU countries")
}
greece <- function(x) x$values[x$geo == "EL"]
# the EU: its own figure where Eurostat publishes one, otherwise the median of the countries
eu <- function(x) if (any(x$geo == "EU27_2020")) x$values[x$geo == "EU27_2020"] else median(x$values[x$geo %in% eu_codes])
countries <- function(x) sum(x$geo %in% eu_codes)
ordinal <- function(k) {
  paste0(k, if (k %% 100 %in% 11:13) "th" else c("th", "st", "nd", "rd", rep("th", 6))[k %% 10 + 1])
}
# the place of Greece among the EU countries, counted from the nearer end: "the highest",
# "the 3rd highest", "the 2nd lowest", ...
place <- function(x) {
  v <- x$values[x$geo %in% eu_codes]
  from_top <- sum(v > greece(x)) + 1
  from_bottom <- sum(v < greece(x)) + 1
  k <- min(from_top, from_bottom)
  end <- if (from_top <= from_bottom) "highest" else "lowest"
  paste("the", if (k == 1) end else paste(ordinal(k), end))
}

# the source of a chart, as a note under it, and the common layout
chart <- function(p, title, source, y_title = "", y_axis = list(), x_axis = list(), annotations = list(), margin = list(t = 70, b = 90), note_y = -0.16, ...) {
  note <- list(
    text = paste("Source:", source), xref = "paper", yref = "paper", x = 0, y = note_y,
    xanchor = "left", yanchor = "top", showarrow = FALSE, font = list(size = 11, color = dark_gray)
  )
  layout(p,
    title = list(text = title, x = 0.02, xanchor = "left", y = 0.97, yanchor = "top"),
    yaxis = modifyList(list(title = y_title), y_axis),
    xaxis = modifyList(list(title = ""), x_axis),
    margin = margin,
    annotations = c(annotations, list(note)),
    ...
  ) %>% config(displaylogo = FALSE)
}
legend_top <- list(orientation = "h", x = 0, y = 1.02, yanchor = "bottom")

# the EU countries from the highest to the lowest, Greece in red and the EU in blue; where Eurostat
# publishes no figure for the EU, a dotted line marks the median country
ranking <- function(x, title, source, suffix = "%", digits = 1) {
  x$name <- eu_name[x$geo]
  x <- x[order(x$values), ]
  x$name <- factor(x$name, levels = x$name)
  lines <- list()
  notes <- list()
  if (!any(x$geo == "EU27_2020")) {
    m <- median(x$values[x$geo %in% eu_codes])
    lines <- list(list(type = "line", x0 = m, x1 = m, y0 = 0, y1 = 1, yref = "paper", line = list(color = blue, width = 2, dash = "dot")))
    notes <- list(list(x = m, y = 1, yref = "paper", text = "Median EU country", xanchor = "left", yanchor = "bottom",
                       xshift = 4, showarrow = FALSE, font = list(color = blue)))
  }
  # the source 45 px under the plot, below the numbers of the axis: in a chart this tall a fixed
  # fraction of the plot would put it below the bottom of the chart
  height <- knitr::opts_current$get("out.height.px")
  if (!is.numeric(height)) height <- 864
  plot_ly(x,
    x = ~values, y = ~name, type = "bar", orientation = "h",
    marker = list(color = ifelse(x$geo == "EL", greek_red, ifelse(x$geo == "EU27_2020", blue, gray))),
    hovertemplate = paste0("%{y}: %{x:.", digits, "f}", suffix, "<extra></extra>")
  ) %>%
    chart(paste0(title, ", ", x$time[1]), source, x_axis = list(ticksuffix = suffix), shapes = lines,
          annotations = notes, margin = list(l = 130, t = 70, b = 90), note_y = -45 / (height - 70 - 90))
}

1. How much schooling do Greeks have?

About as many university graduates as the rest of the EU, and almost no one leaves school early.

In 2025, 42.8% of Greeks aged 25 to 34 had a university degree or another tertiary qualification, against 44.8% in the EU: the 11th lowest share of the 27 countries.

Code 
ranking(tertiary, "People aged 25 to 34 with tertiary education, %", "Eurostat, edat_lfse_03")

Almost every young Greek finishes secondary school. Only 3.0% of Greeks aged 18 to 24 left education with at most lower secondary school and are not in any education or training, the 2nd lowest share in the EU, where it is 9.1%. The older generations had less schooling: 18.0% of Greeks aged 25 to 64 have no more than lower secondary education, against 18.8% in the EU.

Code 
ranking(early, "Early leavers from education and training, % of people aged 18 to 24", "Eurostat, edat_lfse_14")

2. What do they know?

Maths, reading and science at 15

Code 
pisa_year <- pisa$EF461$time[1]
maths <- pisa_all[pisa_all$field == "EF461" & pisa_all$geo %in% c("EL", "EU27_2020"), ]
first_year <- min(intersect(maths$time[maths$geo == "EL"], maths$time[maths$geo == "EU27_2020"]))
maths_then <- function(geo) maths$values[maths$geo == geo & maths$time == first_year]

50% of Greek 15-year-olds are below the basic level in maths, against 34% in the EU.

PISA, the OECD’s test of 15-year-olds, measures whether students can use what they have learned. Below level 2, its basic level, a student can at most answer questions about a familiar, clearly stated situation with all the information given: in maths, for example, apply a simple formula when told which one. In 2025, 50% of Greek 15-year-olds were below that level in maths, against 34% in the EU, the 4th highest share of the 27 countries. In reading the shares are 44% and 31%, and in science 41% and 26%. The EU’s target for 2030 is fewer than 15% in each.

Computer skills

51% of Greek adults have at least basic computer skills, against 60% in the EU.

Eurostat counts people as having at least basic digital skills when they can do at least one basic task in each of five areas: finding and judging information, communicating online, making digital content, using a device safely, and solving problems with it. In 2025, 51% of Greeks aged 16 to 74 could, against 60% in the EU, the 6th lowest share of the 27 countries; 27% had above basic skills, against 31%. Few Greeks work with computers for a living: ICT specialists are 2.5% of the people in work, the lowest share in the EU, where they are 5.0%.

Code 
ranking(digital, "People aged 16 to 74 with at least basic digital skills, %", "Eurostat, isoc_sk_dskl_i21")

Learning as adults

Greeks rarely go back to learning once they work. In 2025, 5.2% of Greeks aged 25 to 64 had taken part in a course or other training in the four weeks before the survey, against 13.7% in the EU: the lowest share.

Code 
ranking(learning, "People aged 25 to 64 in education or training in the last four weeks, %", "Eurostat, trng_lfse_01")

3. Do they find work?

Code 
greek_rates <- unemployment_all[unemployment_all$geo == "EL" & unemployment_all$age == "Y15-74", ]

More of them are out of work than in most of the EU, and for longer. Unemployment in Greece rose to 27.8% of the labour force in 2013, in the debt crisis, and has fallen to 8.9% in 2025. That is still the 3rd highest rate in the EU, where it is 6.0%. Among the young, aged 15 to 24, it is 19.1%, against 15.2%.

Unemployment in Greece lasts: 56% of the unemployed have been looking for work for a year or longer, against 32% in the EU, which makes the long-term unemployed 5.0% of the labour force, the highest share in the EU. 13.6% of Greeks aged 15 to 29 are neither in work nor in education or training, against 11.0% in the EU.

4. How hard do they work, and how much do they produce?

Hours of work: the highest in the EU. Output per hour: the lowest.

Greeks in work usually work 41.0 hours a week, the highest in the EU, where the average is 37.0. Yet an hour of work in Greece produces 54% of what an hour produces on average in the EU, the lowest in the EU, and a person in work, with the longer hours, 67%. These figures count output in purchasing power standards, which allow for the lower prices of Greece.

Output per hour depends less on how hard people work than on what they work with, and where. A large share of Greeks work for themselves or in very small firms: 24.3% of Greeks in work are self-employed, the highest share in the EU, where it is 12.9%. They run farms, shops, taxis, cafés and workshops, often with no employees. Small businesses like these have less machinery and technology behind each hour of work than large firms, and long opening hours add hours more than they add output.

5. Do their jobs use their education?

Often not. 31.4% of the Greeks with tertiary education who work have jobs that do not need it, such as clerical, sales or manual jobs, the 2nd highest share in the EU, where it is 21.4%. The schools and universities produce graduates; the economy has too few jobs that need them.

Code 
ranking(overqualified, "People in work with tertiary education in jobs that do not need it, %", "Eurostat, lfsa_eoqgan")

6. Is there much crime?

Recorded crime is around the middle of the EU, but the share of Greeks who see crime around them is the highest in the EU.

Crime is hard to compare between countries. The police can only count the offences that people report, and people report more where they trust the police or need a report for their insurance; and each country defines and counts offences in its own way. Eurostat therefore warns against comparing the levels of most offences between countries. The exception is intentional homicide, which is almost always recorded, and recorded in the same way.

if (is.na(greek_citizens)) greek_citizens <- citizens$values[match(prison_year, citizens$time)]
greek_rate <- 1e5 * held("NAT") / greek_citizens

Greece holds 111 people in prison for every 100,000 inhabitants, against 111 in the median EU country (the 14th highest rate of 27). Of the 11,484 people held in Greek prisons in 2024, 5,511 were Greek citizens: 57 for every 100,000 Greek citizens living in Greece, or one in 1,748. The other 52% were foreign citizens, a group that also includes people who did not live in Greece, so it cannot be turned into a rate in the same way.

A prison count is not a count of criminals: it includes people waiting for their trial, and most people who commit an offence are never caught, or are fined or given a suspended sentence instead of prison.

ranking(prisoners, "People held in prison, per 100,000 inhabitants", "Eurostat, crim_pris_cap", suffix = "", digits = 0)

How safe do Greeks feel?

Less safe than anyone else in the EU. In 2023, 20.9% of Greeks said that there is crime, violence or vandalism in the area where they live, against 10.0% of people in the EU: the highest share. The gap between the crime that is recorded and the crime that people see around them can have many causes, among them petty crime and vandalism that are never reported, and trust in the police.

Code 
ranking(area, "People who say that their area has crime, violence or vandalism, %", "Eurostat, ilc_mddw03 (EU-SILC)")

So, are they good workers?

The data cannot say whether Greeks are good workers, but they can say what Greek workers bring and what the economy does with it:

  1. They work long hours: 41.0 hours a week, the highest in the EU.
  2. They stay in education: the 2nd lowest share of early school leavers in the EU, and about as many graduates as the EU, 43% of people aged 25 to 34.
  3. But what they learn at school is weak: 50% of 15-year-olds are below the basic level in maths, against 34% in the EU; fewer adults have basic computer skills (51%, against 60%), and almost none go back to learning (5.2%, the lowest share in the EU).
  4. And the economy does not use what they have: an hour of work produces 54% of the EU average, the lowest; 24% of the people in work are self-employed, mostly in very small businesses; 31% of the graduates in work have jobs that do not need a degree; and 9% of the labour force cannot find work.
  5. Crime is not the problem it is felt to be: the homicide rate and the prison population are around the middle of the EU, and 57 in every 100,000 Greek citizens are in prison, yet 21% of Greeks say that there is crime where they live, the highest share in the EU.

The picture is of people who work hard and stay in school, in an economy of small businesses that turns their hours into little output and leaves much of their education unused, and with schools that teach less than those of most of the EU.

## What is this?

Are Greeks good workers? How much schooling do they have, do they know maths, can they use a computer, do they find work, and is there much crime? None of these questions has a single number for an answer, but each has measures that every EU country collects in the same way, so Greece can be compared with the rest of the EU:

1. **How much schooling do Greeks have?**
2. **What do they know?** Maths, reading and science at 15, computer skills, and learning as adults.
3. **Do they find work?**
4. **How hard do they work, and how much do they produce?**
5. **Do their jobs use their education?**
6. **Is there much crime?**

The data come from **Eurostat**, the statistical office of the EU. They are downloaded when the document is knitted, so the charts show the latest figures. The charts of countries show the 27 EU countries, with Greece in red and the EU as a whole in blue.

**What these numbers can and cannot say.** They describe what the schools, the firms and the courts of Greece produce, not what Greeks are born with: no statistic measures how intelligent or how hard-working a people is. A test at 15 measures what a school system has taught by then. Output per hour measures the firms, the machines and the way the economy is organised as much as the people who work in it. And recorded crime depends on how often people go to the police, and on how each country counts offences.

```{r data}
}
```

```{r chart_style}
  if (!is.numeric(height)) height <- 864
```

## 6. Is there much crime?

**Recorded crime is around the middle of the EU, but the share of Greeks who see crime around them is `r place(area)` in the EU.**

Crime is hard to compare between countries. The police can only count the offences that people report, and people report more where they trust the police or need a report for their insurance; and each country defines and counts offences in its own way. Eurostat therefore warns against comparing the levels of most offences between countries. The exception is **intentional homicide**, which is almost always recorded, and recorded in the same way.

```{r crime_numbers}
homicide <- offences$ICCS0101
median_eu <- function(x) median(x$values[x$geo %in% eu_codes])
```

In `r homicide$time[1]`, the police in Greece recorded `r two(greece(homicide))` intentional homicides for every 100,000 inhabitants, against `r two(median_eu(homicide))` in the median EU country: `r place(homicide)` rate of `r countries(homicide)` countries.

```{r homicide, fig.height = 9}
ranking(homicide, "Intentional homicides recorded by the police, per 100,000 inhabitants", "Eurostat, crim_off_cat",
        suffix = "", digits = 2)
```

For the other offences, with the warning above, Greece is near the middle or below it:

### How many are in prison?

```{r prison_numbers}
prison_year <- max(prisoners_ctz$time)
held <- function(citizen) prisoners_ctz$values[prisoners_ctz$citizen == citizen & prisoners_ctz$time == prison_year]
# the Greek citizens living in Greece on 1 January of the next year, or of the same year
greek_citizens <- citizens$values[match(prison_year + 1, citizens$time)]
if (is.na(greek_citizens)) greek_citizens <- citizens$values[match(prison_year, citizens$time)]
greek_rate <- 1e5 * held("NAT") / greek_citizens
```

Greece holds `r round(greece(prisoners))` people in prison for every 100,000 inhabitants, against `r round(median_eu(prisoners))` in the median EU country (`r place(prisoners)` rate of `r countries(prisoners)`). Of the `r thousands(held("TOTAL"))` people held in Greek prisons in `r prison_year`, `r thousands(held("NAT"))` were Greek citizens: `r round(greek_rate)` for every 100,000 Greek citizens living in Greece, or one in `r thousands(1e5 / greek_rate)`. The other `r percent(100 * held("FOR") / held("TOTAL"))` were foreign citizens, a group that also includes people who did not live in Greece, so it cannot be turned into a rate in the same way.

A prison count is not a count of criminals: it includes people waiting for their trial, and most people who commit an offence are never caught, or are fined or given a suspended sentence instead of prison.


## So, are they good workers?

The data cannot say whether Greeks are good workers, but they can say what Greek workers bring and what the economy does with it:

1. **They work long hours**: `r one(greece(hours))` hours a week, `r place(hours)` in the EU.
2. **They stay in education**: `r place(early)` share of early school leavers in the EU, and about as many graduates as the EU, `r percent(greece(tertiary))` of people aged 25 to 34.
3. **But what they learn at school is weak**: `r percent(greece(pisa$EF461))` of 15-year-olds are below the basic level in maths, against `r percent(eu(pisa$EF461))` in the EU; fewer adults have basic computer skills (`r percent(greece(digital))`, against `r percent(eu(digital))`), and almost none go back to learning (`r percent(greece(learning), 1)`, `r place(learning)` share in the EU).
4. **And the economy does not use what they have**: an hour of work produces `r round(greece(per_hour))`% of the EU average, `r place(per_hour)`; `r percent(greece(self_employed))` of the people in work are self-employed, mostly in very small businesses; `r percent(greece(overqualified))` of the graduates in work have jobs that do not need a degree; and `r percent(greece(unemployment))` of the labour force cannot find work.
5. **Crime is not the problem it is felt to be**: the homicide rate and the prison population are around the middle of the EU, and `r round(greek_rate)` in every 100,000 Greek citizens are in prison, yet `r percent(greece(area))` of Greeks say that there is crime where they live, `r place(area)` share in the EU.

The picture is of people who work hard and stay in school, in an economy of small businesses that turns their hours into little output and leaves much of their education unused, and with schools that teach less than those of most of the EU.
