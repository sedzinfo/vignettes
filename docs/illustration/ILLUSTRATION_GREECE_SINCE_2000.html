Greece Since 2000: Boom, Crisis and Recovery

  • Show All Code
  • Hide All Code
  • View Source

What is this?

If you compare Greece in 2000 with Greece in 2020, you get a confusing picture. Both years are unusual: in 2000 Greece did not yet use the euro, and 2020 was the year COVID shut the world down. In between, Greece went through a boom, a very deep crisis and a slow recovery, and two snapshots cannot show that.

This data story follows Greece year by year, in plain words, through the World Bank’s numbers on:

  • income — how much the country produces per person,
  • jobs — how many people who want work cannot find it,
  • investment — what the country spends on its future,
  • people — who moves in and out, and how old the population is,
  • energy — where the electricity comes from.

All the data comes from golemworldbank, an R package and Shiny app for exploring World Bank indicators. The page carries its own copy of the Greek data and of the one function it uses, so it runs without installing anything from GitHub; install golemworldbank to do the same for any other country, or to explore the data in the app.

The data

golemworldbank ships the World Bank’s World Development Indicators as one long table, mfi: one row per country, indicator and year. R/mfi_greece.rds holds its rows for Greece, every indicator and year. We keep the years from 2000 onwards and the indicators this story needs, each with a short name:

year Year of observation

Two of these need a word of explanation:

  • Income is the value of everything Greece produces in a year, divided by the number of people who live there, in US dollars with price rises removed, so that years can be compared fairly. It is a rough measure of how well off the average person is.
  • Investment is the money spent on things that help a country earn more later: new buildings, factories, machines, roads and equipment, as a share of everything the economy produces.

Every chart below shades the two shocks of the period — the debt crisis (2008 to 2013) and COVID (2020) — and writes the latest value at the end of each line:

  if (unit == "$") paste0("$", big(v)) else paste0(round(v, 1), unit)

shocks <- list(list(from = 2008,   to = 2013,   label = "Debt crisis"),
               list(from = 2019.5, to = 2020.5, label = "COVID"))

# chart height in pixels, set on the widget itself (width stays 100% of the
# page), so the chart always fills the box it is drawn in — no scroll bars.
# Returned inside a tagList: printed straight from a chunk, a widget's height
# is overridden by the chunk's figure size; inside a tagList it is kept
# The plotly toolbar goes down the right edge, so it never covers a long title
sized <- function(p, h) {
  p <- plotly::layout(p, modebar = list(orientation = "v"))
  p$height <- h
  htmltools::tagList(p)
}

# title, shaded shocks, end labels and the data source in one layout() call
# (a second layout(annotations = ...) would replace the first one's). The
# source sits at the bottom of the bottom margin `b`, in pixels, so it lands
# in the same place whatever the chart's height; the x axis range is fixed,
# because plotly would otherwise widen it to make room for the end labels
finish <- function(p, title, ytitle, labels, unit = "", legend = TRUE, b = if (legend) 150 else 110) {
  shapes <- lapply(shocks, function(s) {
    list(type = "rect", xref = "x", yref = "paper", x0 = s$from, x1 = s$to, y0 = 0, y1 = 1,
         fillcolor = "gray92", line = list(width = 0), layer = "below")
  })
  tags <- lapply(shocks, function(s) {
    list(x = (s$from + s$to) / 2, y = 1, xref = "x", yref = "paper", yanchor = "bottom",
         text = s$label, showarrow = FALSE, font = list(size = 12, color = "gray40"))
  })
  source_note <- list(
    text = "Source: World Bank, World Development Indicators, via <a href='https://github.com/sedzinfo/golemworldbank'>golemworldbank</a>",
    xref = "paper", yref = "paper", x = 1, y = 0, yshift = -(b - 22),
    xanchor = "right", yanchor = "top", showarrow = FALSE,
    font = list(size = 11, color = "gray50"))
  plotly::layout(p,
    title  = list(text = title, x = 0.02, xanchor = "left", y = 0.97, yanchor = "top"),
    margin = list(t = 90, r = 130, b = b),
    xaxis  = list(title = "", tickangle = -90, range = c(1999.5, max(df_greece$year) + 0.5)),
    yaxis  = list(title = ytitle, ticksuffix = if (unit == "%") "%" else "", rangemode = "tozero"),
    legend = list(orientation = "h", y = -0.2),
    showlegend = legend,
    shapes = shapes,
    annotations = c(tags, labels, list(source_note)),
    font   = list(size = 13, color = "gray25"))
}

# one line per measure, each with its value written at the end; `nudge` lifts
# a label (in pixels) off a line it would otherwise be written over
story_chart <- function(measures, names, short, colors, title, ytitle, unit = "", h = 520,
                        nudge = rep(0, length(measures))) {
  p <- plot_ly()
  ends <- list()
  for (i in seq_along(measures)) {
    d <- df_greece[df_greece$measure == measures[i], ]
    p <- add_trace(p, data = d, x = ~year, y = ~value, name = names[i],
                   type = "scatter", mode = "lines+markers",
                   line = list(color = colors[i], width = 2),
                   marker = list(color = colors[i], size = 7),
                   text = paste0(names[i], " · ", d$year, "<br>", fmt(d$value, unit)),
                   hoverinfo = "text")
    ends[[i]] <- list(x = last_year(measures[i]), y = latest(measures[i]), xref = "x", yref = "y",
                      xanchor = "left", xshift = 8, yshift = nudge[i], showarrow = FALSE,
                      text = trimws(paste(short[i], fmt(latest(measures[i]), unit))),
                      font = list(size = 13, color = "gray25"))
  }
  finish(p, title, ytitle, ends, unit, legend = length(measures) > 1) %>% sized(h)
}

The line has five chapters:

  1. 2000 to 2008: boom. Joining the euro made borrowing cheap for the government and for families, and money flowed in. Income per person grew by 33%. Part of that growth was paid for with borrowed money.
  2. 2008 to 2013: crisis. In late 2009 it came out that the government’s finances were far worse than it had reported. From 2010 Greece needed rescue loans from other euro countries and the International Monetary Fund, and in return it had to cut wages, pensions and public spending and raise taxes. Income per person fell by 26% in five years.
  3. 2013 to 2019: slow recovery. The economy grew again, slowly. The last rescue programme ended in 2018.
  4. 2020: COVID. Tourists stopped coming and the economy fell again.
  5. 2021 onwards: rebound. Growth returned, but in 2025 income per person was still 8% below 2008.

Jobs: the deepest wound, now healing

The unemployment rate counts people who want a job and are looking for one, but cannot find one.

Code 
story_chart(c("unemployment", "youth_unemployment"),
            names  = c("Everyone", "Young people (15 to 24)"),
            short  = c("Everyone", "Young"),
            colors = c("#0082c8", "#E74C3C"),
            title  = "Greece: people looking for work who cannot find it (%)",
            ytitle = "% of people looking for work", unit = "%")

In 2013, 28% of people looking for work could not find a job — more than 1 in 4. Among young people it was 58%, almost 6 in 10. Since then unemployment has fallen every year, and by 2025 it was back near its level before the crisis (8.5%, against 7.7% in 2008).

Investment: what has not come back

Code 
story_chart("investment", names = "Investment", short = "",
            colors = "#0082c8",
            title  = "Greece: investment in buildings, machines and roads (% of the economy)",
            ytitle = "% of the economy", unit = "%")

Before the crisis Greece invested about a quarter of what it produced. During the crisis this fell to about a tenth (11.5% in 2013) and stayed there until 2019. It is rising again (16.9% in 2025), but it is still well below where it was. A decade of low investment is one reason incomes have not fully recovered.

People: fewer and older

Net migration is the number of people who moved into the country minus the number who moved out. Blue bars mean more people arrived than left; red bars mean more people left than arrived.

During the crisis many people, often young and well educated, moved abroad to find work: between 2011 and 2015 about 250,000 more people left Greece than arrived. Treat the latest years with care — the World Bank’s estimates for them jump sharply from one year to the next.

At the same time, Greek families have few children: about 1.2 per woman, while about 2 are needed to keep a population steady. Together these explain why there are fewer Greeks now (10.4 million in 2025, down from 11.1 million around 2010) and why they are older: people aged 65 and over were 17% of the population in 2000 and 24% in 2025.

Energy: much less coal

Most of Greece’s electricity used to come from lignite, a cheap and dirty kind of coal. Those power stations are being closed, and solar parks, wind farms and power stations that burn natural gas have taken their place.

Code 
story_chart(c("coal", "renewables", "gas"),
            names  = c("Coal", "Renewable (sun, wind, water)", "Natural gas"),
            short  = c("Coal", "Renewable", "Gas"),
            colors = c("#E74C3C", "#0082c8", "#999999"),
            title  = "Greece: where the electricity comes from (% of all electricity)",
            ytitle = "% of all electricity", unit = "%",
            nudge  = c(0, 14, 0))   # renewables stop in 2021, above the gas line

In 2000 coal made 64% of Greece’s electricity; by 2025 it made 5%. Renewable sources went from 8% to 41% (2021 is the last year the World Bank reports), and natural gas from 11% to 39%.

Comparing two years with indicator_change()

golemworldbank’s indicator_change() compares every indicator a country has in two years and splits them into those that went up and those that went down, each sorted by percentage change — the same comparison as the app’s Change (%) tab. The result depends entirely on which two years you pick. Comparing 2000 with 2020 mixes twenty years of change with one very bad year: in 2019 tourists spent $23 billion in Greece, in 2020 $6 billion, a fall of 73% in one year.

These pairs each answer one clear question:

Question From To
What did the boom look like? 2000 2008
How bad was the crisis? 2008 2013
How strong was the recovery? 2013 2019
Is Greece back to where it was? 2008 2024

Avoid 2020 and 2021 as end points, because COVID makes almost everything look worse than the real trend, and use 2024 as the latest year, because the 2025 numbers are still incomplete. The crisis, for example:

Because it compares hundreds of indicators automatically, some odd ones end up at the top of the list. These ones do not mean what they seem to:

  • Fossil fuels “fall to 0%”. From 2017 the World Bank stopped reporting this figure for Greece, and the gap shows up as 0.
  • The exchange rate “falls 99.8%” between 2000 and any later year. In 2000 it was counted in drachmas, and from 2001 in euros: nothing collapsed, the currency changed.
  • “Children out of school” jumps 50 times. This figure moves up and down from year to year because of changes in how it is measured.
  • University enrolment above 100%. It counts everyone enrolled, including older students and students who stay registered for many years, and divides them by the number of people of student age.
  • Huge percentages on small numbers. Going from a few hundred to a few thousand is a big percentage, even when the numbers themselves are small.

  • Income: up 33% in the boom, down 26% in the crisis, and in 2025 still 8% below 2008.
  • Jobs: unemployment peaked at 28% in 2013 (58% for young people) and is now back near pre-crisis levels.
  • Investment: fell from about a quarter of the economy to about a tenth, and has only partly come back.

Each row is one indicator in one year:

| Column | Description |
|--------|-------------|
| `measure` | Short name of the indicator (the names of `indicators` above) |
| `year` | Year of observation |
| `value` | The World Bank's value for Greece in that year |

Two of these need a word of explanation:

- **Income** is the value of everything Greece produces in a year, divided by the number of people who live there, in US dollars with price rises removed, so that years can be compared fairly. It is a rough measure of how well off the average person is.
- **Investment** is the money spent on things that help a country earn more later: new buildings, factories, machines, roads and equipment, as a share of everything the economy produces.

Every chart below shades the two shocks of the period — the debt crisis (2008 to 2013) and COVID (2020) — and writes the latest value at the end of each line:

```{r helpers}
# the latest value of a measure, and its value in a given year
at <- function(m, y) df_greece$value[df_greece$measure == m & df_greece$year == y]
last_year <- function(m) max(df_greece$year[df_greece$measure == m])
latest <- function(m) at(m, last_year(m))
change_pct <- function(from, to) round((to - from) / from * 100)
big <- function(v) format(round(v), big.mark = ",")

# "$21,922" for dollars, "8.5%" for percentages
fmt <- function(v, unit) {
  if (unit == "$") paste0("$", big(v)) else paste0(round(v, 1), unit)
}

shocks <- list(list(from = 2008,   to = 2013,   label = "Debt crisis"),
               list(from = 2019.5, to = 2020.5, label = "COVID"))

# chart height in pixels, set on the widget itself (width stays 100% of the
# page), so the chart always fills the box it is drawn in — no scroll bars.
# Returned inside a tagList: printed straight from a chunk, a widget's height
# is overridden by the chunk's figure size; inside a tagList it is kept
# The plotly toolbar goes down the right edge, so it never covers a long title
sized <- function(p, h) {
  p <- plotly::layout(p, modebar = list(orientation = "v"))
  p$height <- h
  htmltools::tagList(p)
}

# title, shaded shocks, end labels and the data source in one layout() call
# (a second layout(annotations = ...) would replace the first one's). The
# source sits at the bottom of the bottom margin `b`, in pixels, so it lands
# in the same place whatever the chart's height; the x axis range is fixed,
# because plotly would otherwise widen it to make room for the end labels
finish <- function(p, title, ytitle, labels, unit = "", legend = TRUE, b = if (legend) 150 else 110) {
  shapes <- lapply(shocks, function(s) {
    list(type = "rect", xref = "x", yref = "paper", x0 = s$from, x1 = s$to, y0 = 0, y1 = 1,
         fillcolor = "gray92", line = list(width = 0), layer = "below")
  })
  tags <- lapply(shocks, function(s) {
    list(x = (s$from + s$to) / 2, y = 1, xref = "x", yref = "paper", yanchor = "bottom",
         text = s$label, showarrow = FALSE, font = list(size = 12, color = "gray40"))
  })
  source_note <- list(
    text = "Source: World Bank, World Development Indicators, via <a href='https://github.com/sedzinfo/golemworldbank'>golemworldbank</a>",
    xref = "paper", yref = "paper", x = 1, y = 0, yshift = -(b - 22),
    xanchor = "right", yanchor = "top", showarrow = FALSE,
    font = list(size = 11, color = "gray50"))
  plotly::layout(p,
    title  = list(text = title, x = 0.02, xanchor = "left", y = 0.97, yanchor = "top"),
    margin = list(t = 90, r = 130, b = b),
    xaxis  = list(title = "", tickangle = -90, range = c(1999.5, max(df_greece$year) + 0.5)),
    yaxis  = list(title = ytitle, ticksuffix = if (unit == "%") "%" else "", rangemode = "tozero"),
    legend = list(orientation = "h", y = -0.2),
    showlegend = legend,
    shapes = shapes,
    annotations = c(tags, labels, list(source_note)),
    font   = list(size = 13, color = "gray25"))
}

# one line per measure, each with its value written at the end; `nudge` lifts
# a label (in pixels) off a line it would otherwise be written over
story_chart <- function(measures, names, short, colors, title, ytitle, unit = "", h = 520,
                        nudge = rep(0, length(measures))) {
  p <- plot_ly()
  ends <- list()
  for (i in seq_along(measures)) {
    d <- df_greece[df_greece$measure == measures[i], ]
    p <- add_trace(p, data = d, x = ~year, y = ~value, name = names[i],
                   type = "scatter", mode = "lines+markers",
                   line = list(color = colors[i], width = 2),
                   marker = list(color = colors[i], size = 7),
                   text = paste0(names[i], " · ", d$year, "<br>", fmt(d$value, unit)),
                   hoverinfo = "text")
    ends[[i]] <- list(x = last_year(measures[i]), y = latest(measures[i]), xref = "x", yref = "y",
                      xanchor = "left", xshift = 8, yshift = nudge[i], showarrow = FALSE,
                      text = trimws(paste(short[i], fmt(latest(measures[i]), unit))),
                      font = list(size = 13, color = "gray25"))
  }
  finish(p, title, ytitle, ends, unit, legend = length(measures) > 1) %>% sized(h)
}
```

## Greece at a glance

```{r income}

       legend = FALSE) %>%
```

The line has five chapters:

1. **2000 to 2008: boom.** Joining the euro made borrowing cheap for the government and for families, and money flowed in. Income per person grew by **`r change_pct(at("income", 2000), at("income", 2008))`%**. Part of that growth was paid for with borrowed money.
2. **2008 to 2013: crisis.** In late 2009 it came out that the government's finances were far worse than it had reported. From 2010 Greece needed rescue loans from other euro countries and the International Monetary Fund, and in return it had to cut wages, pensions and public spending and raise taxes. Income per person fell by **`r abs(change_pct(at("income", 2008), at("income", 2013)))`%** in five years.
3. **2013 to 2019: slow recovery.** The economy grew again, slowly. The last rescue programme ended in 2018.
4. **2020: COVID.** Tourists stopped coming and the economy fell again.
5. **2021 onwards: rebound.** Growth returned, but in `r last_year("income")` income per person was still **`r abs(change_pct(at("income", 2008), latest("income")))`%** below 2008.

## People: fewer and older

Net migration is the number of people who moved into the country minus the number who moved out. Blue bars mean more people arrived than left; red bars mean more people left than arrived.

```{r migration}

  filter(measure == "net_migration") %>%
  mutate(color = ifelse(value >= 0, "#0082c8", "#E74C3C"),
         what  = ifelse(value >= 0, "more arrived than left", "more left than arrived"))

p <- plot_ly(d, x = ~year, y = ~value, type = "bar",
             marker = list(color = ~color),
             text = ~paste0("Greece · ", year, "<br>", big(value), " people: ", what),

finish(p, "Greece: people who moved in, minus people who moved out, per year", "people per year",
       labels = list(), legend = FALSE) %>%
  sized(520)
```

During the crisis many people, often young and well educated, moved abroad to find work: between 2011 and 2015 about **`r big(round(-sum(d$value[d$year %in% 2011:2015]), -4))`** more people left Greece than arrived. Treat the latest years with care — the World Bank's estimates for them jump sharply from one year to the next.

At the same time, Greek families have few children: about **`r round(latest("fertility"), 1)`** per woman, while about 2 are needed to keep a population steady. Together these explain why there are fewer Greeks now (**`r round(latest("population") / 1e6, 1)` million** in `r last_year("population")`, down from `r round(max(df_greece$value[df_greece$measure == "population"]) / 1e6, 1)` million around 2010) and why they are older: people aged 65 and over were **`r round(at("aged_65", 2000))`%** of the population in 2000 and **`r round(latest("aged_65"))`%** in `r last_year("aged_65")`.

## Energy: much less coal

Most of Greece's electricity used to come from lignite, a cheap and dirty kind of coal. Those power stations are being closed, and solar parks, wind farms and power stations that burn natural gas have taken their place.

## Comparing two years with `indicator_change()`

golemworldbank's `indicator_change()` compares every indicator a country has in two years and splits them into those that went up and those that went down, each sorted by percentage change — the same comparison as the app's **Change (%)** tab. The result depends entirely on which two years you pick. Comparing 2000 with 2020 mixes twenty years of change with one very bad year: in 2019 tourists spent **$`r round(at("tourism", 2019) / 1e9)` billion** in Greece, in 2020 **$`r round(at("tourism", 2020) / 1e9)` billion**, a fall of `r abs(change_pct(at("tourism", 2019), at("tourism", 2020)))`% in one year.

These pairs each answer one clear question:

| Question | From | To |
|----------|------|----|
| What did the boom look like? | 2000 | 2008 |
| How bad was the crisis? | 2008 | 2013 |
| How strong was the recovery? | 2013 | 2019 |
| Is Greece back to where it was? | 2008 | 2024 |

Avoid 2020 and 2021 as end points, because COVID makes almost everything look worse than the real trend, and use 2024 as the latest year, because the 2025 numbers are still incomplete. The crisis, for example:

```{r change}
crisis <- indicator_change(mfi, country = "Greece", year1 = 2008, year2 = 2013)
c(increased = nrow(crisis$increased), decreased = nrow(crisis$decreased))

# the indicators of this story, by their short names
headline <- function(tab) {
  tab <- tab[tab$Indicator %in% indicators, ]
  tab$Indicator <- names(indicators)[match(tab$Indicator, indicators)]
  # 3 significant digits, with thousands separators and no scientific notation
  tab[, 2:4] <- lapply(tab[, 2:4], function(x) {
    vapply(x, function(v) format(signif(v, 3), big.mark = ",", scientific = FALSE), "")
  })
  tab
}
headline(crisis$increased)
headline(crisis$decreased)
```

Because it compares hundreds of indicators automatically, some odd ones end up at the top of the list. These ones do not mean what they seem to:

- **Fossil fuels "fall to 0%".** From 2017 the World Bank stopped reporting this figure for Greece, and the gap shows up as 0.
- **The exchange rate "falls 99.8%"** between 2000 and any later year. In 2000 it was counted in drachmas, and from 2001 in euros: nothing collapsed, the currency changed.
- **"Children out of school" jumps 50 times.** This figure moves up and down from year to year because of changes in how it is measured.
- **University enrolment above 100%.** It counts everyone enrolled, including older students and students who stay registered for many years, and divides them by the number of people of student age.
- **Huge percentages on small numbers.** Going from a few hundred to a few thousand is a big percentage, even when the numbers themselves are small.

- **Income:** up **`r change_pct(at("income", 2000), at("income", 2008))`%** in the boom, down **`r abs(change_pct(at("income", 2008), at("income", 2013)))`%** in the crisis, and in `r last_year("income")` still **`r abs(change_pct(at("income", 2008), latest("income")))`%** below 2008.
- **Jobs:** unemployment peaked at **`r round(at("unemployment", 2013))`%** in 2013 (**`r round(at("youth_unemployment", 2013))`%** for young people) and is now back near pre-crisis levels.
- **Investment:** fell from about a quarter of the economy to about a tenth, and has only partly come back.

- **Poverty** here is the World Bank's *societal* poverty line, which moves with what is normal in each country: the share of people living well below the usual Greek standard of living. It rose during the crisis and has since come back down.
